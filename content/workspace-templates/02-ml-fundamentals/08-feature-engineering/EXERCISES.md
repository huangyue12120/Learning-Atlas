# 特征工程与选择：练习指南

- 课程路径：`phases/02-ml-fundamentals/08-feature-engineering`
- 可运行 Python 文件：`features.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 在数值变换中加入稳健缩放（中位数和四分位距代替均值和标准差），并在极端离群数据上与标准缩放比较。
2. 实现留一法目标编码：每行计算类别目标均值时排除自身目标值，展示它如何比朴素目标编码减少过拟合。
3. 构建结合方差阈值、相关性过滤和互信息排序的自动特征选择流水线，在房屋数据上比较全部特征与选择特征下简单线性回归的表现。

## 运行与验证

在课程目录下执行：

```bash
python3 features.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
