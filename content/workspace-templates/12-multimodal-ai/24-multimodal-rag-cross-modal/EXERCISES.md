# 多模态 RAG 与跨模态检索：练习指南

- 课程路径：`phases/12-multimodal-ai/24-multimodal-rag-cross-modal`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 提出一个医疗分诊多模态 RAG：查询 = 损伤照片 + 文本症状。各模态从什么知识库检索？

2. 分数融合只是简单加权和。它有什么失败模式，是 MoE 融合能够避免的？

3. 阅读 Abootorabi 等人的分类法（第 3 节）。三个经典子问题是什么？它们如何对应你选择的产品？

4. 为旅行规划多模态 RAG 设计评估规格。哪些指标能覆盖图像召回、音频召回和综合正确性？

5. 智能体式多跳 RAG 每次往返都有延迟税。在什么查询难度下，准确率收益值得这份延迟？

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
