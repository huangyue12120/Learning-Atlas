# LLaVA-OneVision：一个模型统一单图像、多图像与视频：练习指南

- 课程路径：`phases/12-multimodal-ai/08-llava-onevision-single-multi-video`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 你的产品支持 80% 单图像、10% 多图像（2–4 张图像）、10% 视频（8–16 帧）。设计词元预算。由于不需要重度多图像处理而节省的预算，你会把它放在哪里？

2. 阅读 LLaVA-OneVision 第 4.3 节（涌现能力）。提出一个课程很可能解锁、但论文没有报告的第四种涌现技能。

3. 调换课程顺序——先训练多图像，再训练单图像，最后视频。预测哪些基准会下降，以及原因。

4. 论文报告视频基准每个样本只使用 8 帧训练。这能泛化到推理时的 30 秒视频吗？首先会破坏什么——词元预算还是时间推理？

5. 将 24x24 图像块双线性池化到 12x12，相当于每个维度缩小 4 倍。用标准库 Python 实现池化，并验证每个 2x2 块的均值与双线性输出一致。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
