# 具身 VLA：RT-2、OpenVLA、π0、GR00T：练习指南

- 课程路径：`phases/12-multimodal-ai/21-embodied-vlas-openvla-pi0-groot`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 10-DOF 机械臂以 30 Hz 控制。256 分箱的离散分词每秒输出多少词元？7B VLM 能跟上吗？

2. FAST 分词将 30 步轨迹压缩到约 10 个词元。如果轨迹包含高频运动（例如打鼓），学习者会失去什么？

3. π0 的流匹配头约 5 步去噪。与 OpenVLA 4–5 Hz 的自回归解码比较吞吐量。

4. GR00T 的系统 1 / 系统 2 分工对应 Kahneman。提出一种可能帮助双足行走的不同分工（系统 3？）。

5. 阅读 Open X-Embodiment 第 4 节关于数据集整理的内容。说出防止域泄漏的三条整理规则。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
