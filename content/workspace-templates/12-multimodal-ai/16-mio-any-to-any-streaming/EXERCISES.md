# MIO 与任意到任意的流式多模态模型：练习指南

- 课程路径：`phases/12-multimodal-ai/16-mio-any-to-any-streaming`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 你的产品接收语音输入并返回语音输出。端到端延迟预算目标是多少？列出消耗时间的组件。

2. SpeechTokenizer 残差 VQ 使用 8 个码本。说明为什么残差层必须并行解码（而不是顺序解码），以及这能节省多少延迟。

3. 词汇有 32k 文本 + 4k 图像 + 4k 语音。再加入 8k 音乐和约 10 个分隔符。在隐藏维度 4096 时，嵌入矩阵的参数成本是多少？

4. 视觉思维链会输出中间图像。哪些问题会受益？哪些问题会因额外词元而受损？

5. 阅读 Moshi（arXiv:2410.00037）。描述它的“内心独白”技巧，并与 MIO 的视觉思维链比较。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
