# 视觉 Transformer 与图像块词元原语：练习指南

- 课程路径：`phases/12-multimodal-ai/01-vision-transformer-patch-tokens`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 计算 Qwen2.5-VL 在原生 1280x720 输入、图像块大小为 14 时的图像块词元序列长度。它与只有 CLS 的表示相比如何？

2. 一帧 1080p 图像（1920x1080）使用图像块 14 时会产生多少个词元？以 30 FPS 处理 5 分钟视频时，总共有多少视觉词元？在池化、帧抽样和词元合并中，哪一项最能节省成本？

3. 用纯 Python 实现图像块词元的平均池化。验证 DINOv2 输出的 196 个词元做平均池化后，与调用模型 `forward` 获取池化嵌入时返回的结果一致。

4. 阅读《Vision Transformers Need Registers》（arXiv:2309.16588）的第 3 节。用两句话说明寄存器吸收了什么伪影，以及这为什么对下游稠密预测很重要。

5. 修改 `main.py` 以支持 patch-n'-pack：给定一个不同分辨率图像组成的列表，生成一个打包后的序列和块对角注意力掩码。到达第 12.06 课时与其对照验证。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
