# InternVL3：原生多模态预训练：练习指南

- 课程路径：`phases/12-multimodal-ai/10-internvl3-native-multimodal`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 估计 InternVL3-8B（原生预训练）与 LLaVA-OneVision-7B（事后方案）之间的算力差异。GPU 小时大约相差多少倍？差距由什么解释？

2. InternVL3 报告 40% 文本 / 35% 交错 / 20% 标题 / 5% 视频。如果目标任务偏重视频，提出一个新配比，并说明为什么基础模型仍需要大量文本和标题数据。

3. 阅读 MM1.5 第 4 节关于遗忘的内容。说出事后训练退化最大的确切基准，以及退化了多少。

4. ViR 将 60% 的流量路由到低分辨率编码。它会误路由哪些查询（本应需要高分辨率却被送到低分辨率）？提出三种路由器失败模式。

5. DvD 将视觉和 LLM 拆到不同 GPU 上。在什么流量模式下，DvD 会损害吞吐量而不是提升它？

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
