# 异步与 Hogwild! 推理：练习指南

- 课程路径：`phases/10-llms-from-scratch/22-async-hogwild-inference`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 使用默认设置运行 `main.py`。确认在相同墙钟时间内，N=2 的 Hogwild! 配置比 N=1 基线生成更多工作词元。

2. 降低协调启发式强度（设置 `coordination_weight=0.1`），重新运行。展示加速比崩溃，并解释原因：worker 无法协调时会重复劳动。

3. 计算 50k 词元推理任务在 `p=0.8, c=500`、N=4 时的预期 Hogwild! 加速比；再计算 1k 词元聊天任务在 `p=0.3, c=200`、N=4 时的结果。为什么一个获益而另一个受损？

4. 阅读 Hogwild! 论文第 4 节（初步评估），找出作者报告的两个失败模式，并说明更好的协调提示如何缓解它们。

5. 在玩具实现中将 Hogwild! 与推测解码结合：每个 worker 内部使用 2 词元推测解码。报告乘法加速比。当两个 worker 都想扩展同一共享缓存前缀时，会出现什么记账问题？

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
