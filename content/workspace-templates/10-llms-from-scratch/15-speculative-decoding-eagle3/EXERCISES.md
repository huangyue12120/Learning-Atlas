# 推测解码与 EAGLE-3：练习指南

- 课程路径：`phases/10-llms-from-scratch/15-speculative-decoding-eagle3`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 运行 `main.py`。确认 50,000 个样本上的 Leviathan 分布检查，其卡方统计量低于 95% 临界值。

2. 在 `α` 固定为 0.9、`c` 固定为 0.04 时，将 `N` 从 1 扫描到 10。绘制每次验证器调用的期望词元数和每词元的实际挂钟时间。找出使挂钟时间最小的 `N`，并解释曲线形状。

3. 修改代码以模拟 EAGLE-2 树搜索：每一步让草稿提出形状为 `[2, 2, 2]` 的树（八条候选路径）。验证器运行一次，概率最高的接受路径获胜。计算每个叶子的 `α` 和每次验证器调用的总词元数，并与计算量相当的线性链推测解码比较。

4. 为两个并发序列实现一个批处理 KV 回滚模拟器。序列 A 接受全部草稿；序列 B 在位置 2 拒绝。展示每个序列的 `kv_length` 都能正确更新，且没有工作被浪费。

5. 阅读 EAGLE-3 论文第 4 节（Training-Time Test）。用两句话解释为什么没有 TTT 的朴素草稿训练会遭受暴露偏差，以及为什么在训练期间将草稿自己的预测反馈为输入可以修复它。将其与 seq2seq 文献中的 scheduled sampling 联系起来。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
