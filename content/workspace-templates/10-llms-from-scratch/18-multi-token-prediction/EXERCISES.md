# 多词元预测（MTP）：练习指南

- 课程路径：`phases/10-llms-from-scratch/18-multi-token-prediction`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 运行 `main.py`。展示当合成信号增强时，每深度损失单调下降。将合成数据改为固定模式，验证深度 1 和深度 2 的损失都会收敛。

2. 对一个稠密 70B 模型（隐藏维度 8192、80 层、D=1 个 MTP 模块）计算参数开销，并与 DeepSeek-V3 报告的 14B 开销比较。解释 DeepSeek 数字更高的原因：MTP Transformer 块继承了相同的 MoE 结构，增加了每个模块的参数量。

3. 在玩具实现中加入 D=2：增加第二个 MTP 模块，让它接收 `h^(1)` 并预测 `t_{i+2}`。验证联合损失和参数核算符合 DeepSeek 论文的公式 19–21。

4. 切换到并行 MTP（Gloeckle 风格）：在主模型隐藏状态上增加 D 个输出头，每个头预测不同偏移量。在同一个合成信号上比较各深度损失。由于顺序版本会以中间预测为条件，k > 1 时它应产生更低的深度 k 损失。

5. 将训练好的 MTP 模块用作 EAGLE 风格草稿器：在推理时调用模块 k 提议 `t_{i+k}`，再在留出序列上将这些草稿词元与主模型预测比较并测量接受率。如果玩具实现达到 50% 以上，就复现了 MTP 作为草稿器的经验性质。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
