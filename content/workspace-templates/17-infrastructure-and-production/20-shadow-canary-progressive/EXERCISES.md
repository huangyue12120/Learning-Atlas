# 影子流量、金丝雀与渐进式部署：练习指南

- 课程路径：`phases/17-infrastructure-and-production/20-shadow-canary-progressive`
- 可运行 Python 文件：`main.py`

## 练习目标

用影子 smoke test、金丝雀闸门和快速回滚控制 LLM 发布风险，并把质量、成本和延迟放在同一决策中。

## 动手练习

1. 运行 `code/main.py`，注入 25% 成本回归，找出金丝雀在哪个阶段停止。
2. 新模型离线准确率增加 3% 但每请求成本增加 18% 时，分别写出上线与拒绝路径。
3. 设计端到端低于 60 秒的回滚，列出策略开关、固定模型 digest 和观测依赖。
4. 评估显示非确定性 ±7% 时，设置避免误报的金丝雀闸门乘数。
5. 为影子模式捕获 40% 成本尖峰设计告警规则和升级动作。

## 运行与验证

```bash
python3 code/main.py
```

确认脚本显示各阶段、闸门和回滚结果，并记录一份可审计的发布判定。
