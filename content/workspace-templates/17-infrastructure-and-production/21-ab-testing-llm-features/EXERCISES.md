# LLM 功能的 A/B 测试：练习指南

- 课程路径：`phases/17-infrastructure-and-production/21-ab-testing-llm-features`
- 可运行 Python 文件：`main.py`

## 练习目标

区分离线评估与在线实验，使用 CUPED、序贯边界和多重比较校正控制 LLM 非确定性。

## 动手练习

1. 运行 `code/main.py`，在基线转化率 3%、预期提升 5% 和 80% 功效下计算所需样本。
2. 为医疗监管且需要本地部署的客户在 Statsig 与 GrowthBook 之间做选择并说明依据。
3. 设计 GPT-4 对 GPT-3.5 的实验：定义每张已解决工单成本这一主指标，以及质量、延迟和错误护栏。
4. 金丝雀通过但 A/B 转化率下降 1.2% 时，写出停止、升级和继续收集数据的标准。
5. 前期方差为后期 60% 时应用 CUPED，计算有效样本量增益并注明假设。

## 运行与验证

```bash
python3 code/main.py
```

确认程序输出固定样本与序贯边界的差异，并记录一次不把“感觉更好”当结论的实验。
