# 作为降本原语的模型路由：练习指南

- 课程路径：`phases/17-infrastructure-and-production/16-model-routing`
- 可运行 Python 文件：`main.py`

## 练习目标

用任务分类、提示词长度、困难集合相似度和模型自信度构建可控的级联路由。

## 动手练习

1. 运行 `code/main.py`，求出级联在什么准确率下限开始胜过预路由。
2. 为 30% 企业复杂查询和 70% 免费简单查询设计路由比例，并选出在线闸门指标。
3. 分析质量下降 2%、成本节省 40% 的两种产品决策，写出上线和拒绝的条件。
4. 用 logprobs 设计置信度检查，说明初始阈值和校准方法。
5. 诊断六个月内升级率从 8% 升到 22% 的三个可能原因，并为每个提出修复。

## 运行与验证

```bash
python3 code/main.py
```

确认脚本输出路由、升级和成本对照，并记录一次带质量护栏的路由策略。
