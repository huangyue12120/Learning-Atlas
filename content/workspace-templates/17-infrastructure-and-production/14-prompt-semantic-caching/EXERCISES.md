# 提示词缓存与语义缓存经济学：练习指南

- 课程路径：`phases/17-infrastructure-and-production/14-prompt-semantic-caching`
- 可运行 Python 文件：`main.py`

## 练习目标

通过稳定前缀、TTL、并行查询和相似度阈值计算缓存的真实收益与错误风险。

## 动手练习

1. 运行 `code/main.py` 并切换并行化标志，记录账单变化及其原因。
2. 把系统提示词中的日期移出可缓存前缀，比较前后的命中率。
3. 在给定请求速率下比较 1 小时 TTL（2 倍写入）与 5 分钟 TTL（1.25 倍写入）的盈亏平衡。
4. 面对 0.95 阈值命中 20%、0.85 阈值命中 50% 但错误响应增加的情况，选择阈值并设置质量闸门。
5. 将每个问题的 10 个并行子查询改写成缓存友好的批次，不增加端到端延迟。

## 运行与验证

```bash
python3 code/main.py
```

确认脚本能区分缓存命中、写入成本和错误响应，并记录一项 TTL 或前缀布局实验。
