# OpenAI Preparedness Framework 与 DeepMind FSF：练习指南

- 课程路径：phases/15-autonomous-systems/20-openai-preparedness-deepmind-fsf
- 可运行 Python 文件：main.py

## 练习目标

比较三套前沿安全政策如何分类同一能力，并练习从政策文本提取可验证条件。

## 动手练习

1. 运行 main.py，确认至少两项能力的三方分类差异。
2. 为 OpenAI 的每个 Research Category 写出它尚未进入 Tracked 的理由。
3. 为 DeepMind ML R&D autonomy level 1 设计外部测量。
4. 设计能迫使 sandbagging 模型显露能力的评估，并连接评估上下文博弈。
5. 选一个能力，引用政策条款比较三套框架的严谨程度。

## 运行与验证

运行：python3 code/main.py

确认输出按 capability 分组展示 classification 和 action，不把三套框架合并成一个结论。
