# MCP 一致性工程：版本、证据与运维：练习指南

- 课程路径：`phases/13-tools-and-protocols/31-mcp-conformance-versioning-and-operations`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

本课没有单独的练习段落，以下清单依据课程主题和代码文件整理。

- 阅读并运行 `main.py`，记录其输入、输出和关键中间结果。
- 修改一个与主题相关的参数或小函数，比较修改前后的结果。
- 为主要函数补充一个边界输入，验证程序仍能给出可解释结果。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
