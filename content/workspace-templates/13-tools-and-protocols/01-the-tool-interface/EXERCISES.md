# 工具接口——智能体为何需要结构化 I/O：练习指南

- 课程路径：`phases/13-tools-and-protocols/01-the-tool-interface`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. 在 `main.py` 中添加第四个工具 `get_stock_price(ticker)`。将描述写成“当用户按 ticker 询问当前股价时使用。不要用于历史价格或市场概览”。运行测试工具，确认提到 ticker 的查询会被假的决策器路由到新工具。

2. 破坏 schema 校验器。传入一个缺少必填字段的调用，确认宿主在执行前拒绝它；再传入一个带额外未知字段的调用。做出判断：宿主应该拒绝还是忽略？用安全性论证你的选择。

3. 将测试工具中的每个工具分类为纯工具或后果性工具。给需要的注册表条目添加 `consequential: true` 标志，并修改循环：每当选中后果性工具时，打印一行“将向用户确认”。这就是每个生产级宿主都需要的确认闸门形状。

4. 在纸上画出上面的四步循环，并为你最喜欢的客户端（Claude Desktop、Cursor、ChatGPT 或自定义技术栈）填写提供商列的表格。与 Phase 13 · 06 中 MCP 特有的变体交叉对照。

5. 从头到尾阅读 OpenAI 的函数调用指南。找出一个位于请求中、但不在这里呈现的四步循环中的字段。解释它增加了什么，以及为什么它是便利功能而非必需品。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
