# 视频生成：练习指南

- 课程路径：`phases/08-generative-ai/10-video-generation`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. **简单。** 在 `main.py` 中比较（a）逐帧独立采样与（b）联合序列采样的帧间差值。报告差值的均值和方差。
2. **中等。** 添加第一帧条件：把第 0 帧固定为给定值，采样其余帧。测量固定值如何向后传播。
3. **困难。** 使用 Hugging Face diffusers 在本地 GPU 上运行 CogVideoX-2B。为一段 6 秒、720p 片段执行 20 个推理步骤并计时。分析时空注意力，找出瓶颈。

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
