# 缩放定律：练习指南

- 课程路径：`phases/07-transformers-deep-dive/13-scaling-laws`
- 可运行 Python 文件：`main.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. **简单。** 运行 `main.py`。输出算力预算为 `1e20`、`1e22`、`1e24` 时 Chinchilla 最优的 `(N, D)`，并与真实模型表比较。
2. **中等。** 实现 Hoffmann 的损失—算力曲线。在计算最优前沿上绘制损失关于 `log10(C)` 的曲线。找出该定律预测下一次将交叉熵降低 0.1 需要 `>10^28` FLOPs 的位置。
3. **困难。** 在同一数据集上训练 5 个微型模型（参数量从 100K 到 10M），拟合你自己的缩放定律。估计 `α` 和 `E`。你的指数与已发表结果有多接近？

## 运行与验证

在课程目录下执行：

```bash
python3 main.py
```

逐个确认命令正常退出，并检查输出是否符合练习中的预期；若代码依赖额外包，按上游课程说明先完成环境安装。
