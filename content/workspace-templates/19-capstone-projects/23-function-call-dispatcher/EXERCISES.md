# 函数调用分发器：Python 练习指南

- 课程路径：`phases/19-capstone-projects/23-function-call-dispatcher`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

验证超时、重试、幂等去重与并发上限。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
python3 -m unittest discover -s code/tests -v
```

## 动手练习

1. 记录正常、瞬时失败、超时和重复调用的结果与 attempts。
2. 对同一幂等键并发发起两次调用，计数底层副作用次数，再换键确认请求独立执行。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

重复请求共享结果且副作用不重复；永久参数错误不会进入无意义的重试。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
