# 毕业项目 07——端到端微调流水线（从数据到 SFT、DPO 再到服务）：Python 练习指南

- 课程路径：`phases/19-capstone-projects/07-end-to-end-fine-tuning-pipeline`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

追踪微调流水线的阶段依赖与产物身份。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 按 manifest 列出 data、SFT、DPO、量化、服务与评估产物的内容哈希和生产者。
2. 修改一项训练配置重新运行，检查哪些下游产物应变化，并构造缺少前置产物的失败情况。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

阶段产物和评估可追溯；模拟产物不证明真实 SFT/DPO 训练提升。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
