# 毕业项目 10——多智能体软件工程团队：Python 练习指南

- 课程路径：`phases/19-capstone-projects/10-multi-agent-software-team`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

核对多角色交接与协调成本。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 approved、tested passed、handoffs、各角色词元与 token amplification。
2. 改变 n_coders，使用匹配种子比较团队与单智能体结果，检查失败审阅是否仍流入最终完成状态。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

交接结果可追溯且成本有基线；更多角色不自动带来更高正确率。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
