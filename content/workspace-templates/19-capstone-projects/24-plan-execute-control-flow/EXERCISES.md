# 计划—执行控制流：Python 练习指南

- 课程路径：`phases/19-capstone-projects/24-plan-execute-control-flow`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

核对计划失败、重规划与双预算停止。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
python3 -m unittest discover -s code/tests -v
```

## 动手练习

1. 比较默认运行与失败后恢复运行的 plan diff、revision 和事件序列。
2. 把恢复策略改为绕行或停止，降低回合/成本预算，确认旧计划的已完成步骤不会重复执行。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

每次重规划有原因与差异，预算耗尽不会被记为任务成功。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
