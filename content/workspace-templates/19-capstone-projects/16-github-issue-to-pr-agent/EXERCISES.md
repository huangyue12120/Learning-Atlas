# 毕业项目 16——从 GitHub Issue 到 PR 的自治智能体：Python 练习指南

- 课程路径：`phases/19-capstone-projects/16-github-issue-to-pr-agent`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

验证 Issue 到 PR 的预算、沙箱状态和验证门。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 PRs opened、failed、failure reasons、每仓库预算与平均成本。
2. 降低一个仓库预算，并构造验证失败任务，确认不会被标记成已发布 PR。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

失败原因和状态转移相符；本地运行仅模拟 GitHub 调度，不创建远端分支或 PR。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
