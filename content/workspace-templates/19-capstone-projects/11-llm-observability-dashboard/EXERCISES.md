## 练习目标

连接 span、成本、评测和漂移信号。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 spans by model、cost by user、告警与 PSI，选一个请求重建父子 span 链。
2. 改变 tail sampling 或注入泄漏的比例，检查错误轨迹是否仍被保留，并比较总体统计。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。
