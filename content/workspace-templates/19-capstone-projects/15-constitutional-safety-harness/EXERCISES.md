# 毕业项目 15——宪法式安全工作台与红队靶场：Python 练习指南

- 课程路径：`phases/19-capstone-projects/15-constitutional-safety-harness`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

同时衡量攻击阻断和良性误拒绝。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 按攻击族记录 successes/attacks 与 false-positive rate，查看一个 blocked trace。
2. 调整一个分类或域检查规则，在固定攻击集与良性集上比较两类错误，并保留未用于调参的样本。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

每项指标有分母和切片；规则分类器演示不构成普遍安全保证。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
