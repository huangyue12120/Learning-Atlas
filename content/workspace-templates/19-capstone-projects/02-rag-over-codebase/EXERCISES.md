# 毕业项目 02——代码库上的 RAG（跨仓库语义搜索）：Python 练习指南

- 课程路径：`phases/19-capstone-projects/02-rag-over-codebase`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

比较代码检索的召回、融合与重排阶段。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 为同一问题列出 dense、sparse、fused、rerank 的 top 结果，核对正确片段在哪一步出现。
2. 向小语料增加包含精确符号名的干扰片段，比较 BM25 与稠密检索排序，并核对最终文件引用。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

能区分召回失败与排序失败；哈希嵌入演示不能代替真实嵌入模型的检索评估。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
