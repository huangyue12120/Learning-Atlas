# 毕业项目 09——代码迁移智能体（仓库级语言 / 运行时升级）：Python 练习指南

- 课程路径：`phases/19-capstone-projects/09-code-migration-agent`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

比较确定性迁移、智能体修复和质量门。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 passed、失败 taxonomy、每仓库成本、回合数和覆盖率差值。
2. 禁用 recipe 或降低修复预算，在同一随机种子下比较失败分类，补一个覆盖率保持但行为错误的反例。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

能说明每个验证门拦截什么；合成 benchmark 的通过率不是实际代码迁移成功率。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
