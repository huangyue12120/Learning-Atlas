# 毕业项目 03——实时语音助手（从 ASR 到 LLM 再到 TTS）：Python 练习指南

- 课程路径：`phases/19-capstone-projects/03-realtime-voice-assistant`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

沿时间线解释话轮检测、工具调用和首音频延迟。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 turn_complete、first_llm_tok、first_audio_out 与 barge_ins，计算每段等待时间。
2. 延长合成输入的句中停顿，并改变轮次阈值，比较误截断与等待的变化。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

能指出延迟来自哪一阶段，并验证抢话后旧响应的取消；模拟毫秒值不是设备上的实测结果。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
