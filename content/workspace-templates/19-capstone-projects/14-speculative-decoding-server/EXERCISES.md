# 毕业项目 14——推测解码推理服务器：Python 练习指南

- 课程路径：`phases/19-capstone-projects/14-speculative-decoding-server`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

验证草稿提议、目标验证与吞吐成本。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 baseline target calls，与不同 alignment/k 下的接受率及 target calls 对照。
2. 固定随机种子，改变草稿长度和匹配度，比较加速条件；另用重复采样频率检查目标分布保持。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

接受率与目标调用次数可解释；合成概率和时延不保证真实服务获得相同加速。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
