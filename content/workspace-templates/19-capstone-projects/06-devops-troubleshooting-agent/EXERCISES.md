# 毕业项目 06——面向 Kubernetes 的 DevOps 故障排查智能体：Python 练习指南

- 课程路径：`phases/19-capstone-projects/06-devops-troubleshooting-agent`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

把根因排序连接到证据与审批状态。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 ranked hypotheses 的分数与 citations，追溯首位假设依赖的集群节点和遥测。
2. 比较未审批和审批后的修复返回值；移除一项关键证据，再检查排序与审计日志。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

每个结论能指向证据，修复权限与诊断权限分开；该演示不会连接真实集群或发送审批消息。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
