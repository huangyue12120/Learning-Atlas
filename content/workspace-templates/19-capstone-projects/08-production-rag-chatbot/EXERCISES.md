## 练习目标

验证权限过滤、证据引用与提示词缓存边界。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 比较 analyst/GDPR 和 counsel/HIPAA 的引用集合，并重复查询观察 cache_hit。
2. 增加一个仅允许单一角色读取的片段，确认其他角色答案不引用它；改变稳定前缀检查缓存失效。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

重复请求与跨权限请求有清楚的缓存行为；演示命中率不能外推到生产成本节省。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
