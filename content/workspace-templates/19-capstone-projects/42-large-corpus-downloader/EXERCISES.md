# 大规模语料下载器：Python 练习指南

- 课程路径：`phases/19-capstone-projects/42-large-corpus-downloader`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

验证可恢复下载、压缩流、去重与清单。

## 运行与验证

需要 data 依赖组中的 zstandard；演示压缩和下载本地合成分片。

```bash
python3 code/main.py
python3 -m unittest discover -s code/tests -v
```

## 动手练习

1. 记录分片摘要、kept/duplicates、逐分片哈希与 manifest 哈希；演示使用本地 file://，无需下载大语料。
2. 模拟中断后让 partial 文件长度与检查点不一致，确认前缀验证拒绝或重下载；改变去重阈值比较保留量。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

恢复必须同时检查长度和 SHA-256；清单哈希可检错，但没有可信来源或签名时不能防止主动篡改。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
