# 实验运行器：Python 练习指南

- 课程路径：`phases/19-capstone-projects/52-experiment-runner`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

验证实验子进程、指标解析与资源终态。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
python3 -m unittest discover -s code/tests -v
```

## 动手练习

1. 记录正常、崩溃、超时、内存超限的状态与最终/中间指标，检查 code/experiments 一并保留。
2. 在私人实验脚本中先输出指标再非零退出，确认仍判 crash；为一个参数做固定种子消融对照。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

终态与退出码一致，软内存轮询的延迟边界明确；同种子复现仍要求实验遵守种子契约。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
