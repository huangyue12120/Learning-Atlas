# 毕业项目 01——终端原生编码智能体：Python 练习指南

- 课程路径：`phases/19-capstone-projects/01-terminal-native-coding-agent`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

观察计划、工具反馈与预算如何共同决定停止。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录 turns、tokens 和 trace events，沿一次工具调用找到对应观察与计划变化。
2. 降低 Budget 中的回合上限，确认在未完成任务时以预算原因停止；不要把失败退出记为成功。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

trace 能解释每次行动及停止原因；这里的 shell 包装与钩子不构成操作系统级沙箱。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
