# 文献检索：Python 练习指南

- 课程路径：`phases/19-capstone-projects/51-literature-retrieval`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

组合词面检索与两跳引文图。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
python3 -m unittest discover -s code/tests -v
```

## 动手练习

1. 记录两路命中、paper id 去重结果和 graph_score，手工追踪一个两跳候选。
2. 把一篇基础论文改成不同词汇但保留引用，比较只用 BM25 和混合结果；再加入重复 id 检查合并。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

图深度和候选数量有界，排名证据可追溯；两跳是可调策略，不是普遍最佳深度。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
