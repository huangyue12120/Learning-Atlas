# 毕业项目 12——视频理解流水线（场景、问答与搜索）：Python 练习指南

- 课程路径：`phases/19-capstone-projects/12-video-understanding-pipeline`
- 运行位置：本课私人工作区根目录；保留 `code/`、测试和数据子目录。

## 练习目标

检查场景检索与时间窗口细化的接口。

## 运行与验证

Python 标准库即可。

```bash
python3 code/main.py
```

Python 入口是离线架构模拟；课程正文中的云服务、模型训练和生产部署属于后续扩展。其他语言实现只从上游链接访问。

## 动手练习

1. 记录每个查询的 scene、原始起止时间与 grounded window，确认窗口位于对应场景内。
2. 修改一个 scene 的 caption/frame/transcript，使三路证据冲突，比较融合后候选与最终窗口。
3. 把改动、运行命令、关键输出与解释记录在私人工作区，保留一组可复现的默认/修改后对照。

## 完成判据

时间单位与边界一致；合成嵌入和窗口不代表真实视频定位精度。

输出写入本课工作区或程序创建的临时目录；不要在只读上游源目录中执行实验。重新准备工作区只补齐缺失文件，不覆盖你的改动。
