# 评估与测试 LLM 应用：练习指南

- 课程路径：`phases/11-llm-engineering/10-evaluation`
- 可运行 Python 文件：`eval_framework.py`

## 练习目标

理解本课核心概念，并能独立运行、修改和验证对应的 Python 实作。

## 建议步骤

1. **添加 BERTScore。** 使用词嵌入余弦相似度实现简化版 BERTScore。创建一个字典，把 100 个常见词映射到随机的 50 维向量。计算参考答案词元与假设答案词元之间的成对余弦相似度矩阵。使用贪心匹配（每个假设词元匹配最相似的参考词元）计算 precision、recall 和 F1。

2. **构建两两比较。** 修改评估器，让它并排比较两个模型输出，而不是分别打分。给定同一输入和两个输出，评估器应返回哪个更好以及原因。在测试套件中对 baseline-v1 与 baseline-v2 进行两两比较，并计算带置信区间的胜率。

3. **实现分层分析。** 按类别（事实、技术、安全、代码、摘要）分组测试用例，计算各类别带置信区间的分数。找出两个提示词版本之间哪些类别变好、哪些变差。系统整体变好时，某个类别仍然可能退化。

4. **加入评估者一致性。** 对每个测试用例运行 LLM 评估器 3 次，模拟不同的评估者。计算三次运行之间的 Cohen kappa 或 Krippendorff alpha。如果一致性低于 0.7，说明评分标准太含糊，需要重写。

5. **构建成本追踪器。** 追踪每次评估器调用的词元用量和成本。每次输入包含原始提示词、模型输出和评分标准（约 500 个输入词元、100 个输出词元）。计算测试套件的总评估成本，并假设每周运行 10 次评估来估算月成本。
