# A2A——智能体到智能体协议：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/12-a2a-protocol`
- 可运行 Python 文件：`main.py`

## 练习目标

从智能体卡片发现到任务生命周期，观察 HTTP JSON 服务如何支持跨进程的任务委派与状态查询。

## 动手练习

1. 运行 `main.py`，记录 agent card、任务创建、查询和取消请求的 JSON。
2. 给任务增加一个失败状态，确保客户端能区分 HTTP 错误和业务失败。
3. 为重复的 `task_id` 增加幂等处理，并比较重复创建前后的存储内容。
4. 为任务结果加入版本字段，模拟客户端与服务端模式漂移。
5. 写出 A2A 与 MCP 的边界：哪个负责发现工具，哪个负责委派任务？

## 运行与验证

```bash
python3 code/main.py
```

确认内置 HTTP 服务能启动并完成默认客户端流程；记录任务状态转移和最终响应。
