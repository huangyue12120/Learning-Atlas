# 群聊与发言者选择：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/10-group-chat-speaker-selection`
- 可运行 Python 文件：`main.py`

## 练习目标

理解轮询、基于状态的选择和 LLM 风格选择器如何改变群聊的发言顺序与终止条件。

## 动手练习

1. 运行 `main.py`，记录 coder、reviewer 和 manager 的发言次数。
2. 将轮询选择器改成“上一位发言者不能连续发言”，检查循环是否仍能结束。
3. 增加一个永远返回“需要更多信息”的角色，设计防饥饿和最大轮数保护。
4. 比较全量消息池与按角色投影的上下文，说明信息泄漏和成本差异。
5. 为每次选择输出理由、候选集合和停止信号，便于重放调试。

## 运行与验证

```bash
python3 code/main.py
```

确认两种选择器都能结束默认对话，并保存一份发言计数与停止原因。
