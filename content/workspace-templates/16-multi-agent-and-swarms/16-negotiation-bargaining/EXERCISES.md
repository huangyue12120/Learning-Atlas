# 协商与议价：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/16-negotiation-bargaining`
- 可运行 Python 文件：`main.py`

## 练习目标

比较叙事式 LLM 议价与显式效用约束，观察合同网如何把报价、接受和失败变成可审计状态。

## 动手练习

1. 运行 `main.py`，记录不同买方策略的成交率与最终价格。
2. 改变买卖双方的底价和折扣，绘制成交区间而不是只看平均值。
3. 为报价增加截止时间，处理迟到或重复响应。
4. 在 Contract Net 中加入第二个竞标者，并保存所有未中标报价的原因。
5. 写出一个不能交给自由文本模型决定的约束（预算、权限或安全边界）。

## 运行与验证

```bash
python3 code/main.py
```

确认议价基准与 Contract Net 演示都能运行，并记录一次无成交的诊断结果。
