# 层级架构及其失效模式：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/06-hierarchical-architecture`
- 可运行 Python 文件：`main.py`

## 练习目标

理解嵌套主管如何形成组织树，以及上下文漂移、重复委派和管理循环如何吞噬收益。

## 动手练习

1. 运行 `main.py`，检查顶层经理、子经理和 worker 的输入输出摘要。
2. 修改一个子经理的摘要，观察顶层综合是否放大了错误。
3. 给每个节点加入最大委派次数和完成条件，避免无限管理循环。
4. 把同一任务改成扁平主管流水线，比较层级树增加的调用与延迟。
5. 为一次错误分派写出最小可观测字段：任务、负责人、证据和重试原因。

## 运行与验证

```bash
python3 code/main.py
```

确认层级示例与失败示例都能运行，并记录哪一层最先出现任务漂移。
