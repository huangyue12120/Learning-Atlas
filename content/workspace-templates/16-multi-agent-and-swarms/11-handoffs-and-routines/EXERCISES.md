# 交接与例程——无状态编排：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/11-handoffs-and-routines`
- 可运行 Python 文件：`main.py`

## 练习目标

用显式路由和结构化 handoff 在客服、退款与销售角色之间传递控制，同时保持每轮上下文边界清晰。

## 动手练习

1. 运行 `main.py`，跟踪 triage 到 specialist 的每次交接和用户消息。
2. 为未知意图增加安全的人工升级分支，不要静默回到 triage。
3. 让退款例程要求订单号字段，验证缺失字段时不会执行副作用。
4. 将路由记录序列化，使用同一输入重放并比较历史输出。
5. 设置最大交接次数，记录循环被截断时应交给谁处理。

## 运行与验证

```bash
python3 code/main.py
```

确认默认脚本退出码为 0，并把一条完整的 handoff 链和一条升级链写入学习记录。
