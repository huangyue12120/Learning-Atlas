# 投票、自一致性与辩论拓扑：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/15-voting-debate-topology`
- 可运行 Python 文件：`main.py`

## 练习目标

用星形、链形、树形和图形拓扑比较信息覆盖、里程碑成功率、延迟与协调税。

## 动手练习

1. 运行 `main.py`，记录四种拓扑在同一批试验中的分数和通信代价。
2. 将智能体从同质改为异质，比较多样性对多数投票的影响。
3. 增加一轮图形辩论，检查新增信息是否超过协调成本。
4. 画出每种拓扑的邻接关系，标记中心瓶颈、孤立节点和错误传播路径。
5. 设计一个停止条件，避免共识已经稳定后继续付出调用成本。

## 运行与验证

```bash
python3 code/main.py
```

确认脚本输出四种拓扑的对照，并保存一项“最佳拓扑取决于任务”的证据。
