# 心智社会与多智能体辩论：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/07-society-of-mind-debate`
- 可运行 Python 文件：`main.py`

## 练习目标

比较独立采样、多轮互读辩论与多数投票，区分智能体数量和交互轮数的贡献。

## 动手练习

1. 运行 `main.py`，记录每轮的一致率、与真值的误差和最终多数答案。
2. 分别改变 agent 数量和辩论轮数，绘制质量与调用成本的简单表格。
3. 注入一个共享的错误先验，观察相关样本如何让多数投票失效。
4. 让一个 agent 负责提出反例，比较同质团队与异质团队的结果。
5. 为停止辩论写一个阈值，并说明它如何避免没有收益的追加轮次。

## 运行与验证

```bash
python3 code/main.py
```

确认输出包含单轮多数与多轮辩论对照，并保存一项“更多轮次没有带来收益”的观察或反例。
