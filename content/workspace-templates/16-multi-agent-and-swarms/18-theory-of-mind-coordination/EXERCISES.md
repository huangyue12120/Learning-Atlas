# 心智理论与涌现协调：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/18-theory-of-mind-coordination`
- 可运行 Python 文件：`main.py`

## 练习目标

比较没有 ToM、一级 ToM 与更高阶信念模型的协作效率，区分真正的信念推理和提示词装饰。

## 动手练习

1. 运行 `main.py`，比较不同 ToM 设置的成功率、回合数和错误类型。
2. 改变盒子数量与智能体数量，观察局部观察不确定性如何扩大。
3. 构造一个错误信念场景，检查智能体是否会更新对他人状态的模型。
4. 为每次通信记录“自己的观察”和“对他人信念的推断”，防止两者混淆。
5. 设计一个不需要 ToM 的基线任务，避免把所有协调收益归因于心智建模。

## 运行与验证

```bash
python3 code/main.py
```

确认基线和 ToM 实验都能运行，记录至少一个高阶推断反而增加成本的情况。
