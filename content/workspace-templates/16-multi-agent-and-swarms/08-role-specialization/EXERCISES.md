# 角色专业化——规划者、批评者、执行者、验证者：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/08-role-specialization`
- 可运行 Python 文件：`main.py`

## 练习目标

把主观批评与确定性验证分开，观察验证者如何捕捉批评者遗漏的运行时错误。

## 动手练习

1. 运行 `main.py`，比较正确执行者和有 bug 执行者的 critic/verifier 报告。
2. 增加静态检查（例如统计 `return` 次数），记录它捕捉到的另一类问题。
3. 为规格加入一个边界条件，让验证测试覆盖空输入或极值输入。
4. 实现最多两轮执行者修订，并在预算耗尽后交给人工处理。
5. 为每个角色写出输入、输出和不可承担的责任，检查是否存在重叠。

## 运行与验证

```bash
python3 code/main.py
```

确认批评者可能通过而验证者失败的案例仍然可见，并把确定性证据保存下来。
