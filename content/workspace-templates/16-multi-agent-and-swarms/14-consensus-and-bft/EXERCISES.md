# 面向智能体的共识与拜占庭容错：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/14-consensus-and-bft`
- 可运行 Python 文件：`main.py`

## 练习目标

区分简单多数、加权共识与拜占庭容错，理解恶意或失联智能体如何改变决策安全性。

## 动手练习

1. 运行 `main.py`，比较各场景中 plurality、CP-WBFT 和 decentralized LLMs 的结果。
2. 增加一个恶意投票者，观察阈值变化如何影响安全性与可用性。
3. 让一个节点缺席，记录系统是返回无决定、降级还是继续推进。
4. 为每个投票保存权重、签名或来源，避免只记录最终赢家。
5. 写出“多数通过”不等于“事实正确”的一个具体反例。

## 运行与验证

```bash
python3 code/main.py
```

确认所有默认场景退出码为 0，并记录安全阈值与可用性之间的一项取舍。
