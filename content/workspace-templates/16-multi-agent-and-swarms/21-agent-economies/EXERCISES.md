# 智能体经济、Token 激励与声誉：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/21-agent-economies`
- 可运行 Python 文件：`main.py`

## 练习目标

用 Shapley 归因、二价拍卖和声誉加权路由理解共同产值如何转化为个体激励。

## 动手练习

1. 运行 `main.py`，记录精确与采样 Shapley 值、获胜报价和路由选择。
2. 增加一个边际贡献为零的 agent，检查它是否仍获得不应得的奖励。
3. 改变二价拍卖的报价，验证赢家支付的是第二高价而非自己的报价。
4. 让一个 agent 的声誉下降，观察路由权重和探索机会如何变化。
5. 写出链上身份、声誉与实际质量之间可能脱钩的一个风险。

## 运行与验证

```bash
python3 code/main.py
```

确认三个演示都能运行，并将一次归因、拍卖和声誉决策的输入与输出保存下来。
