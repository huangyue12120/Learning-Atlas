# 并行 / 群体 / 网络化架构：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/09-parallel-swarm-networks`
- 可运行 Python 文件：`main.py`

## 练习目标

用固定分配、共享队列和群体网络比较并发吞吐、负载均衡、饥饿与热点。

## 动手练习

1. 运行 `main.py`，比较顺序、固定分配和动态 swarm 的耗时与任务归属。
2. 改变任务时长分布，观察固定分片何时被长任务拖慢。
3. 限制队列容量，记录生产者遇到背压时的行为。
4. 为领取操作加入幂等任务 ID，验证同一任务不会被两个 worker 重复确认。
5. 画出本课队列拓扑，并标出中心热点和潜在饥饿路径。

## 运行与验证

```bash
python3 code/main.py
```

确认三种策略都返回有效结果，记录一次负载不均衡或共享队列竞争的证据。
