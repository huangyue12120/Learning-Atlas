# 共享记忆与黑板模式：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/13-shared-memory-blackboard`
- 可运行 Python 文件：`main.py`

## 练习目标

比较消息池和黑板的读取视图，练习 provenance、并发写入、验证与记忆投毒检测。

## 动手练习

1. 运行 `main.py`，比较没有验证者和加入验证者时的结论。
2. 让两个线程同时更新同一个键，记录锁、版本检查或主题分区如何处理冲突。
3. 为每条消息增加来源 URI 和时间戳，追踪一条被摘要放大的错误。
4. 将验证者改为只读，确认它能报告问题但不能覆盖黑板内容。
5. 为黑板设计保留策略，说明何时压缩、归档或拒绝低可信记忆。

## 运行与验证

```bash
python3 code/main.py
```

确认输出包含黑板演示与投毒前后对照，并记录一条可复现的 provenance 链。
