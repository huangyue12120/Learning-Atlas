# 生成式智能体与涌现模拟：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/17-generative-agents-simulation`
- 可运行 Python 文件：`main.py`

## 练习目标

把记忆流、反思和计划三个组件放进小型模拟，观察局部规则怎样产生可见的群体行为。

## 动手练习

1. 运行 `main.py`，记录每个 tick 的检索记忆、计划和行动。
2. 改变 top-k、记忆重要性和新近度权重，比较行为是否改变。
3. 移除反思或计划组件，写下消融实验暴露的失效模式。
4. 注入一条错误记忆，追踪它如何在后续计划中传播。
5. 为涌现行为增加可重复的指标，而不是只凭故事判断“像人”。

## 运行与验证

```bash
python3 code/main.py
```

确认模拟和检索演示都退出码为 0，并保存一条从记忆到行动的完整轨迹。
