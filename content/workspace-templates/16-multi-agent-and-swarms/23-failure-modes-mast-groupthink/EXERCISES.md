# 失效模式：MAST、群体迷思、单一文化与级联错误：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/23-failure-modes-mast-groupthink`
- 可运行 Python 文件：`main.py`

## 练习目标

把规范问题、协调失败和验证缺口映射到可观测症状，并用断路器抑制重试风暴。

## 动手练习

1. 运行 `main.py`，记录 incident 分类、群体迷思检测和断路器状态。
2. 调整下游失败率与请求量，比较启用和禁用断路器时的级联负载。
3. 为共享记忆投毒加入来源可信度和隔离区，观察诊断时间是否缩短。
4. 让两个角色共享同一错误模型，写出单一文化与普通随机错误的区别。
5. 为每个 MAST 类别建立一项上线前验收指标和一项运行时告警。

## 运行与验证

```bash
python3 code/main.py
```

确认分类与 retry-storm 演示都退出码为 0，并保存断路器打开前后的请求量对照。
