# 案例研究与 2026 年技术现状：练习指南

- 课程路径：`phases/16-multi-agent-and-swarms/25-case-studies-2026-sota`
- 可运行 Python 文件：`main.py`

## 练习目标

把 Anthropic Research、MetaGPT/ChatDev 和 OpenClaw/Moltbook 三类案例映射到架构、风险与治理决策。

## 动手练习

1. 运行 `main.py`，记录三个案例的模式、规模、成本和主要风险。
2. 为一个给定任务选择参考案例，明确哪些条件让该映射成立。
3. 将案例中的成功指标改写成可复现实验，而不是只引用宣传数字。
4. 为人口规模扩展的系统列出身份、提示注入、审计和停止控制。
5. 写出一个“从简单开始”的最小架构，并说明何时有证据支持增加编排层。

## 运行与验证

```bash
python3 code/main.py
```

确认案例映射和框架清单均有输出，并保存一份带约束条件的架构选择说明。
