# Learning Atlas Content

This directory contains versioned Chinese adaptations and human-approved contextual theory links owned by Learning Atlas. Its structure and metadata contract are defined in [`docs/content-schema.md`](../docs/content-schema.md).

The v0.27.0 content snapshot (2026-10-23) tracks `ai-engineering-from-scratch` at `f7aadc1d61a9fbbe2bdb107d1e2bf0a6caeea299` and `maths-cs-ai-compendium` at `9850ee574a370bc1cde59de98b394e953775b67d`. It contains 542 reviewed practice translations across Phase 0-19, 307 reviewed Chinese assessments for the open Phase 0-18 scope, 449 Python workspace guides, 311 approved theory links, and eighty-nine reviewed Chinese theory notes covering all 311 theory-card associations. This release adds the Phase 13 reverse engineering track (lessons 32-45): fourteen practice translations, fourteen assessments, and fourteen workspace guides, so every upstream lesson now has a reviewed Chinese adaptation. Learner workspaces now receive each lesson's complete `code/` directory, including fixtures, tests, and graded labs. The home page lists every practice Phase and all 20 theory chapters. The practice reader exposes the 457 reviewed lessons in Phase 0-18; the 85 reviewed adaptations for Phase 19 remain staged. P16's two TypeScript-only exceptions remain linked to their upstream implementations. P15's 22 Python workspaces and 13 rich contextual theory cards remain published, and its upstream lessons have no `quiz.json`, so no assessments are fabricated. The reviewed sampling note, eleven T1 high-association notes, thirteen T2 medium-association notes, thirteen T3 medium-association notes, nineteen T4 long-tail notes, sixteen T5 independent notes, and sixteen T6 independent notes are published internally against the locally synchronized `main` snapshot, while the remaining 15 theory notes link to the official upstream English `main`.

Use [`docs/translation-glossary.md`](../docs/translation-glossary.md) as the Chinese terminology baseline when editing or adding adaptations.
