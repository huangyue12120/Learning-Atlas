This directory contains versioned Chinese adaptations and human-approved contextual theory links owned by Learning Atlas. Its structure and metadata contract are defined in [`docs/content-schema.md`](../docs/content-schema.md).

The v0.13.1 content snapshot tracks `ai-engineering-from-scratch` at `a56b4b8ad43a3767c771953d217036813f697bc7`. It contains 511 reviewed practice translations across Phase 0-19, 174 reviewed Chinese assessments for the open Phase 0-13 scope, 311 theory links (all approved), and one reviewed Chinese theory note. The upstream practice source now contains 523 lessons; 12 new Phase 14 lessons have no Chinese adaptation and remain outside the reader. The home page lists every practice Phase and all 20 theory chapters. The practice reader exposes the 279 reviewed lessons in Phase 0-13; the 232 reviewed adaptations for Phase 14-19 remain staged. The reviewed sampling note is published internally against the locally synchronized `main` snapshot, while theory notes without a current reviewed Chinese translation link to the official upstream English `main`.

Use [`docs/translation-glossary.md`](../docs/translation-glossary.md) as the Chinese terminology baseline when editing or adding adaptations.

Do not store progress, notes, conversations, review items, learner workspaces, API keys, or database files here. Those are learner-owned local data.
