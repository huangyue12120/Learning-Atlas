# 优化

*优化是模型训练的核心问题之一：寻找能使损失函数变小的参数。本文件介绍临界点、凸性、梯度下降、牛顿法、拉格朗日乘子法和 SGD、Adam 等优化器。*

- 训练神经网络、拟合回归线、调整超参数：几乎每种机器学习算法的核心都是一个**优化问题**。

- 我们有一个函数（损失、成本、目标）并希望找到使它最小（或最大）的输入。

- 优化之前，我们需要理解函数的**零点**。函数的零点是 $f(x)$ 的值 $x$，使得 $f(x) = 0$。图示上，这些是 x 轴的交点。

- 例如，$f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ 在 $x = 1$ 和 $x = 2$ 处有零点。在零点之间，函数为负（$f(1.5) = -0.25$）；在零点之外，函数为正。零点将数轴分为具有常数符号的区域。

- **零点的重数**是对应因子出现的次数。

- 在单根（重数为 1）处，图形与 x 轴相交。在二重根（重数为 2）处，图形接触 x 轴后反弹，在该点看起来“平坦”。

- 找到零点很重要，因为导数 $f'(x)$ 的零点是 $f(x)$ 的**临界点**，也是寻找极大值或极小值的候选点。

- 在最大值或最小值处，切线为平的（斜率为 0），因此 $f'(x) = 0$。

![临界点：导数为零时，函数有峰、谷或鞍点](../images/critical_points.svg)


- 不是每个临界点都是最大值或最小值。满足 $f'(x) = 0$ 的点也可能是 **拐点**（例如 $f(x) = x^3$ 的 $x = 0$），函数会暂时变平，但方向并未改变。

- **二阶导数判别法**可帮助判断临界点的类型。设临界点为 $x=c$，且 $f'(c)=0$：

    - 如果 $f''(c) > 0$：曲线是凹向上的（就像一个碗），所以 $c$ 是一个 **局部最小值**。
    - 如果 $f''(c) < 0$：曲线是凹向下的（就像一个山峰），所以 $c$ 是一个 **局部最大值**。
    - 如果 $f''(c) = 0$：测试结果不明确；需要更高阶导数或其他方法来判断。

- 例如，$f(x) = x^3 - 3x$。导数是$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，所以临界点在$x = -1$和$x = 1$。二阶导数是$f''(x) = 6x$。在$x = -1$：$f''(-1) = -6 < 0$（局部最大）。在$x = 1$：$f''(1) = 6 > 0$（局部最小）。

- 若连接函数图像上任意两点的线段都位于图像上方或图像上，该函数就是**凸函数**。当 $f$ 二阶可导时，$f$ 为凸函数当且仅当 $f''(x) \geq 0$ 对定义域内所有 $x$ 成立。

![凸函数的每个局部最小值都是全局最小值；非凸函数可能有多个局部最小值](../images/convex_nonconvex.svg)


- 凸函数的每个局部最小值都是全局最小值，因此不会出现高于全局最低点的局部低谷。**编者注：**凸函数的全局最小值不一定唯一；原文图注中的 “unique” 不准确。

- 若 $-f$ 是凸函数，则 $f$ 是**凹函数**。凹凸性发生变化的点称为**拐点**。若 $f''$ 连续，拐点处有 $f''(x)=0$；反过来，$f''(x)=0$ 只说明该点可能是拐点。

- 牛顿法使用切线来找到函数的零点（也可将其应用于导数，以寻找原函数的临界点）。从初始猜测 $x_0$ 开始，它迭代地改进：

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$
![牛顿法：沿切线寻找更好的根近似值](../images/newtons_method.svg)


- 思路是：在 $x_n$ 处画切线，并找到它与 x 轴的交点。该交点成为 $x_{n+1}$。对于性质良好且初始点合适的函数，牛顿法收敛非常迅速（二次收敛，即每次迭代中正确数字的数量大致翻倍）。

- 例如，要找到 $\sqrt{5}$（$f(x) = x^2 - 5$的零点）： $f'(x) = 2x$，所以 $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$。从 $x_0 = 2$ 开始： $x_1 = 2.25$， $x_2 = 2.2361\ldots$，已经精确到四位小数。

- 牛顿法在初始猜测远离根、根附近有 $f'(x) = 0$，或函数附近存在拐点时可能失败。此外，它还需要计算导数，这可能很昂贵。

- 要寻找极小值，可以用牛顿法求解驻点方程 $f'(x)=0$，得到以下更新式：

$$x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}$$
- 该更新要求 $f''(x_n)\neq0$。多维牛顿更新为 $\mathbf{x}_{n+1} = \mathbf{x}_n - H^{-1} \nabla f(\mathbf{x}_n)$，其中 $H$ 是 Hessian 矩阵，必须可逆。这相当于用二阶泰勒展开近似原函数，再跳到近似二次函数的极小点。**编者注：**牛顿法求出的驻点不一定是极小值，还需进一步判断。

- **拉格朗日乘子法**用于约束优化：在满足 $g(x,y)=c$ 的条件下，寻找 $f(x,y)$ 的最优值。搜索范围由整个 $\mathbb{R}^n$ 缩小到满足约束的集合（曲线或曲面）。

- 几何上，在约束最优点处，$f$ 和 $g$ 的梯度会平行。若约束梯度非零且函数满足可微等条件，这是最优点的必要条件；梯度不平行时，还能沿约束集合移动并改进 $f$。

- 引入变量 $\lambda$（拉格朗日乘子），定义**拉格朗日函数**：

$$\mathcal{L}(x, y, \lambda) = f(x, y) - \lambda(g(x, y) - c)$$
- 将所有偏导数设为零，得到约束优化问题的驻点候选：

$$\frac{\partial \mathcal{L}}{\partial x} = 0, \quad \frac{\partial \mathcal{L}}{\partial y} = 0, \quad \frac{\partial \mathcal{L}}{\partial \lambda} = 0$$
![拉格朗日乘子法：在最优解时，f 和 g 的梯度平行](../images/lagrange_multiplier.svg)


- 例如，最大化 $f(x,y) = x^2 y$ 对于 $x^2 + y^2 = 1$。拉格朗日函数是 $\mathcal{L} = x^2 y - \lambda(x^2 + y^2 - 1)$。取偏导数：

$$2xy - 2\lambda x = 0, \quad x^2 - 2\lambda y = 0, \quad x^2 + y^2 = 1$$
- 由第一个方程（假设 $x \neq 0$）得 $\lambda=y$。代入第二个方程得 $x^2=2y^2$；再结合约束 $x^2+y^2=1$，可得 $y=\pm\frac{1}{\sqrt{3}}$。取正值时，$f$ 达到最大值 $\frac{2}{3\sqrt{3}}$。

- 对于不等式约束（$g(x,y) \leq c$ 而非 $=c$），Karush–Kuhn–Tucker（KKT）条件推广了拉格朗日乘子法。约束可以是活跃的（解位于边界）或不活跃的（解位于内部）。**编者注：**KKT 条件还包括驻点、可行性和互补松弛等要求，不能只靠判断约束是否活跃。

- 实际上，我们很少手动优化。以下是主要的算法族：

    - **一阶方法**（只用梯度）：梯度下降、随机梯度下降（SGD）和 Adam。每步计算成本较低，但在病态问题上可能收敛较慢。

    - **二阶方法**（同时使用梯度和 Hessian）：牛顿法收敛速度快，但显式计算 Hessian 并求逆的成本很高；稠密矩阵求逆对 $n$ 个参数的成本为 $O(n^3)$。**拟牛顿方法**（如 BFGS 和 L-BFGS）仅使用梯度信息近似 Hessian，比一阶方法收敛更快，而无需承担完整二阶方法的成本。

    - **共轭梯度法**：适用于大型稀疏系统，仅使用矩阵–向量乘积，避免存储完整的 Hessian。

    - **高斯–牛顿法**和**勒文伯格–马夸特法**：主要用于最小二乘问题（常见于回归），通过雅可比矩阵近似 Hessian。

    - **自然梯度下降**：利用了参数空间的几何结构，使用 Fisher 信息矩阵，对于概率模型更为有效。

- 优化器的选择取决于问题。对于深度学习，一阶方法（尤其是 Adam）占主导地位，因为参数数量巨大（数百万到数十亿），使 Hessian 计算变得不切实际。对于目标函数光滑的较小问题，二阶方法可能快得多。

## 编程任务（使用 Colab 或笔记本）

1. 实现牛顿法来找到 $\sqrt{7}$（$f(x) = x^2 - 7$的零点）。观察快速收敛。
```python
import jax.numpy as jnp

f = lambda x: x**2 - 7
df = lambda x: 2*x

x = 3.0  # initial guess
for i in range(6):
    x = x - f(x) / df(x)
    print(f"step {i+1}: x = {x:.10f}  (error: {abs(x - jnp.sqrt(7.0)):.2e})")
```

2. 使用梯度下降法最小化 $f(x, y) = (x - 3)^2 + (y + 1)^2$。最小值出现在 $(3, -1)$ 处。尝试不同的学习率。
```python
import jax
import jax.numpy as jnp

def f(params):
    x, y = params
    return (x - 3)**2 + (y + 1)**2

grad_f = jax.grad(f)
params = jnp.array([0.0, 0.0])
lr = 0.1

for i in range(20):
    g = grad_f(params)
    params = params - lr * g
    if i % 5 == 0 or i == 19:
        print(f"step {i:2d}: ({params[0]:.4f}, {params[1]:.4f})  loss={f(params):.6f}")
```

3. 数值求解约束优化问题：在 $x+y=10$ 的约束下最大化 $f(x,y)=xy$。令 $y=10-x$，再求单变量函数的最大值。
```python
import jax
import jax.numpy as jnp

# Substitute constraint: y = 10 - x, so f = x(10 - x) = 10x - x²
f = lambda x: x * (10 - x)
df = jax.grad(f)

# Gradient ascent (we want maximum, so add gradient)
x = 1.0
lr = 0.1
for i in range(20):
    x = x + lr * df(x)
print(f"x={x:.4f}, y={10-x:.4f}, f={f(x):.4f}")  # should be x=5, y=5, f=25
```

**编者注：**固定学习率下只迭代 20 次会逐渐逼近 $(5,5)$，结果不会恰好等于理论最大值。
