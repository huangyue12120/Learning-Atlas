# 优化

*优化是模型训练的核心数学，找到损失函数最小的参数。本文件涵盖了关键点、凸性、梯度下降、牛顿方法、带有拉格朗日乘数的约束优化以及推动现代深度学习的优化器（SGD、Adam）等重要概念。*

- 训练神经网络、拟合回归线、调整超参数：几乎每种机器学习算法的核心都是一个**优化问题**。

- 我们有一个函数（损失、成本、目标）并希望找到使它最小（或最大）的输入。

- 优化之前，我们需要理解函数的**零点**。函数的零点是 $f(x)$ 的值 $x$，使得 $f(x) = 0$。图示上，这些是 x 轴的交点。

- 例如，$f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ 在 $x = 1$ 和 $x = 2$ 处有零点。在零点之间，函数为负（$f(1.5) = -0.25$）；在零点之外，函数为正。零点将数轴分为具有常数符号的区域。

- **零点的重数**是对应因子出现的次数。

- 在简单零（重数为 1）处，图形与 x 轴相交。在双零（重数为 2）处，图形接触 x 轴但反弹回来，看起来“平坦”在该点。

- 找到零点很重要，因为函数导数 $f'(x)$ 的零点是 $f(x)$ 的**临界点**，候选的最大值和最小值。

- 在最大值或最小值处，切线为平的（斜率为 0），因此 $f'(x) = 0$。

![临界点：导数为零时，函数有峰、谷或鞍点](../images/critical_points.svg)


- 不是每个临界点都是最大值或最小值。一个 $f'(x) = 0$ 也可能是一个 **拐点**（就像 $x = 0$ 对于 $f(x) = x^3$），函数暂时平缓但方向没有改变。

- 二阶导数测试可以解决这个问题。在临界点 $x = c$ 处，当 $f'(c) = 0$：

    - 如果 $f''(c) > 0$：曲线是凹向上的（就像一个碗），所以 $c$ 是一个 **局部最小值**。
    - 如果 $f''(c) < 0$：曲线是凹向下的（就像一个山峰），所以 $c$ 是一个 **局部最大值**。
    - 如果 $f''(c) = 0$：测试结果不明确；需要更高阶导数或其他方法来判断。

- 例如，$f(x) = x^3 - 3x$。导数是$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，所以临界点在$x = -1$和$x = 1$。二阶导数是$f''(x) = 6x$。在$x = -1$：$f''(-1) = -6 < 0$（局部最大）。在$x = 1$：$f''(1) = 6 > 0$（局部最小）。

- 函数是凸的，如果连接其图上任意两点的线段都位于该图上方（或与之相交）。想象一下它是一个碗形曲线，曲率向上。数学上，函数 $f$ 是凸的，当且仅当 $f''(x) \geq 0$ 对于所有 $x$ 成立。

![凸函数只有一个全局最小值；非凸函数可以有多个局部最小值](../images/convex_nonconvex.svg)


- 凸性非常强大，因为凸函数具有一个令人惊讶的性质：每个局部最小值都是全局最小值。没有欺骗性的局部山谷可以陷进去。如果你把球滚进一个凸碗里，它总是会到达底部。

- 函数是凹的（向下弯曲），如果 $-f$ 是凸的。函数从凹到凸的过渡点称为 **拐点**，发生在 $f''(x) = 0$ 处。

- 牛顿法使用切线来找到函数的零点（以及它们导数的临界点）。从初始猜测 $x_0$ 开始，它迭代地改进：

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$
![牛顿方法：沿着切线寻找更好的根的近似值](../images/newtons_method.svg)


- 理想：在 $x_n$ 处画切线，并找到它与 x 轴的交点。该交点成为 $x_{n+1}$。对于具有良好起始点的良好行为函数，牛顿方法收敛非常迅速（以平方速度进行，即每次迭代中正确数字的数量大致翻倍）。

- 例如，要找到 $\sqrt{5}$（$f(x) = x^2 - 5$的零点）： $f'(x) = 2x$，所以 $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$。从 $x_0 = 2$ 开始： $x_1 = 2.25$， $x_2 = 2.2361\ldots$，已经精确到四位小数。

- 牛顿法在初始猜测远离根时可能会失败，如果 $f'(x) = 0$ 接近根，或者函数附近有弯曲点。此外，它还需要计算导数，这可能很昂贵。

- 为了优化（找到最小值而不是零），我们使用牛顿法来处理 $f'(x) = 0$，这给出了更新：

$$x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}$$
- 在多维空间中，这变成了 $\mathbf{x}_{n+1} = \mathbf{x}_n - H^{-1} \nabla f(\mathbf{x}_n)$，其中 $H$ 是 Hessian 矩阵。这是从上一个文件中的二阶泰勒近似动作：将函数近似为二次函数，跳到该二次函数的最小值，重复。

- 拉格朗日乘数解约束优化：在满足约束 $g(x, y) = c$ 的条件下，找到 $f(x, y)$ 的最优值。我们不再需要搜索 $\mathbb{R}^n$ 中的所有元素，而是被限制在满足约束的曲面或表面上。

- 关键洞察是几何的：在约束最优解时，$f$的梯度必须与$g$的梯度平行。如果它们不平行，我们可以在保持约束的情况下沿某个方向继续改善$f$，因此我们还没有达到最优解。

- 我们引入一个新的变量 $\lambda$（拉格朗日乘数），并定义了 **拉格朗日函数**：

$$\mathcal{L}(x, y, \lambda) = f(x, y) - \lambda(g(x, y) - c)$$
- 将所有偏导数设为零，形成一个方程组，其解是约束条件下的最优解：

$$\frac{\partial \mathcal{L}}{\partial x} = 0, \quad \frac{\partial \mathcal{L}}{\partial y} = 0, \quad \frac{\partial \mathcal{L}}{\partial \lambda} = 0$$
![拉格朗日乘数法：在最优解时，f和g的梯度平行](../images/lagrange_multiplier.svg)


- 例如，最大化 $f(x,y) = x^2 y$ 对于 $x^2 + y^2 = 1$。拉格朗日函数是 $\mathcal{L} = x^2 y - \lambda(x^2 + y^2 - 1)$。取偏导数：

$$2xy - 2\lambda x = 0, \quad x^2 - 2\lambda y = 0, \quad x^2 + y^2 = 1$$
- 从第一个方程（假设 $x \neq 0$）： $\lambda = y$。将第二个代入其中： $x^2 = 2y^2$。结合约束条件： $2y^2 + y^2 = 1$，所以 $y = \frac{1}{\sqrt{3}}$。最大值为 $f = \frac{2}{3\sqrt{3}}$。

- 对于不等式约束（$g(x,y) \leq c$而不是 $= c$），KKT 条件一般化了拉格朗日乘数。约束要么是活跃的（绑定，视为相等）要么是 inactive 的（解位于内部，约束无关）。

- 实际上，我们很少手动优化。以下是主要的算法族：

    - **一阶方法**（仅使用梯度）：梯度下降、随机梯度下降（SGD）、Adam。这些方法每步成本较低但收敛速度较慢，尤其是在条件差的问题上。

    - **二阶方法**（同时使用梯度和Hessian）：牛顿法收敛速度快，但计算和逆Hessian昂贵（$O(n^3)$ for $n$参数）。**拟牛顿方法**（如BFGS和L-BFGS）仅使用梯度信息近似Hessian，比一阶方法更快收敛，而无需第二阶方法的全成本。

    - **共轭梯度法**：适用于大型稀疏系统，仅使用矩阵向量乘积代替存储完整的Hessian。

    - **高斯-牛顿法**和**勒文伯格-马夸特法**：专用于最小二乘问题（常见于回归），通过雅各比近似Hessian。

    - **自然梯度下降**：利用了参数空间的几何结构，使用了Fisher信息矩阵，对于概率模型更为有效。

- 优化器的选择取决于问题。对于深度学习，首先阶方法（尤其是Adam）主导，因为参数数量巨大（数百万到数十亿），使得Hessian计算不切实际。对于具有平滑目标的较小问题，第二阶方法可以显著更快地进行。

## 编程任务（使用CoLab或笔记本）

1. 实现牛顿法来找到 $\sqrt{7}$（$f(x) = x^2 - 7$的零点）。观察快速收敛。
```python
import jax.numpy as jnp

f = lambda x: x**2 - 7
df = lambda x: 2*x

x = 3.0  # initial guess
for i in range(6):
    x = x - f(x) / df(x)
    print(f"step {i+1}: x = {x:.10f}  (error: {abs(x - jnp.sqrt(7.0)):.2e})")
```

2. 使用梯度下降法最小化 $f(x, y) = (x - 3)^2 + (y + 1)^2$。最小值出现在 $(3, -1)$ 处。尝试不同的学习率。
```python
import jax
import jax.numpy as jnp

def f(params):
    x, y = params
    return (x - 3)**2 + (y + 1)**2

grad_f = jax.grad(f)
params = jnp.array([0.0, 0.0])
lr = 0.1

for i in range(20):
    g = grad_f(params)
    params = params - lr * g
    if i % 5 == 0 or i == 19:
        print(f"step {i:2d}: ({params[0]:.4f}, {params[1]:.4f})  loss={f(params):.6f}")
```

3. 数字上求解约束优化问题。最大化 $f(x,y) = xy$，受 $x + y = 10$ 约束，通过参数化 $y = 10 - x$ 并找到单变量函数的最优值。
```python
import jax
import jax.numpy as jnp

# Substitute constraint: y = 10 - x, so f = x(10 - x) = 10x - x²
f = lambda x: x * (10 - x)
df = jax.grad(f)

# Gradient ascent (we want maximum, so add gradient)
x = 1.0
lr = 0.1
for i in range(20):
    x = x + lr * df(x)
print(f"x={x:.4f}, y={10-x:.4f}, f={f(x):.4f}")  # should be x=5, y=5, f=25
```
