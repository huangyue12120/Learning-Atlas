# 优化

*优化是模型训练的数学核心：寻找使损失函数最小的参数。本篇涵盖临界点、凸性、梯度下降、Newton 方法、使用拉格朗日乘子的约束优化，以及推动现代深度学习的优化器（SGD、Adam）。*

- 训练神经网络、拟合回归直线、调节超参数：几乎每种机器学习算法的核心都是一个**优化**问题。

- 我们有一个函数（损失、代价或目标函数），希望找到让它尽可能小（或大）的输入。

- 在优化之前，需要理解函数的**零点**（或根）。$f(x)$ 的一个零点，是使 $f(x) = 0$ 的 $x$ 值。在图像上，它们就是与 $x$ 轴的交点。

- 例如，$f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ 的零点是 $x = 1$ 和 $x = 2$。在两个零点之间，函数为负（$f(1.5) = -0.25$）；在零点之外，函数为正。零点把数轴划分成函数符号保持不变的区域。

- 零点的**重数**是对应因子出现的次数。

- 对于简单零点（重数为 1），图像会穿过 $x$ 轴；对于二重零点（重数为 2），图像会接触 $x$ 轴后反弹，不会穿过，看起来在该点“变平”。

- 找零点很重要，因为导数 $f'(x)$ 的零点就是 $f(x)$ 的**临界点**，也是极大值和极小值的候选点。

- 在极大值或极小值处，切线是水平的（斜率 = 0），因此 $f'(x) = 0$。

![临界点：导数等于零的位置，函数可能有峰值、谷值或鞍点](../images/critical_points.svg)

- 但不是每个临界点都是极大值或极小值。$f'(x) = 0$ 的点也可能是**拐点**（例如 $f(x) = x^3$ 在 $x = 0$ 处），函数会短暂变平，却不会改变方向。

- **二阶导数检验**可以解决这个问题。在满足 $f'(c) = 0$ 的临界点 $x = c$ 处：

    - 如果 $f''(c) > 0$：曲线向上凹（像碗），所以 $c$ 是**局部极小值**。
    - 如果 $f''(c) < 0$：曲线向下凹（像山），所以 $c$ 是**局部极大值**。
    - 如果 $f''(c) = 0$：检验无法得出结论，需要更高阶导数或其他方法。

- 例如，$f(x) = x^3 - 3x$。其导数为 $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$，因此临界点为 $x = -1$ 和 $x = 1$。二阶导数为 $f''(x) = 6x$。在 $x = -1$ 处，$f''(-1) = -6 < 0$（局部极大值）；在 $x = 1$ 处，$f''(1) = 6 > 0$（局部极小值）。

- 如果任意两点之间的线段都位于函数图像上方（或图像上），那么函数是**凸函数**。可以把它想成处处向上弯曲的碗形。数学上，如果对所有 $x$ 都有 $f''(x) \geq 0$，则 $f$ 是凸函数。

![凸函数有唯一的全局最小值；非凸函数可能有多个局部最小值](../images/convex_nonconvex.svg)

- 凸性之所以强大，是因为凸函数有一个重要性质：每个局部最小值同时也是**全局最小值**，不存在会让你陷入其中的虚假局部谷底。如果把球滚进凸碗，它总能滚到碗底。

- 如果 $-f$ 是凸函数，则函数是**凹函数**（向下弯曲）。函数从凹变凸或从凸变凹的点是**拐点**，出现在 $f''(x) = 0$ 的位置。

- **Newton 方法**使用切线寻找函数的零点（进而寻找其导数的临界点）。从初始猜测 $x_0$ 开始，它迭代细化：

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

![Newton 方法：沿切线寻找更好的根近似](../images/newtons_method.svg)

- 思路是：在 $x_n$ 处画切线，寻找切线与 $x$ 轴的交点。这个交点成为 $x_{n+1}$。对于性质良好且初始点合适的函数，Newton 方法收敛非常快（平方收敛，即每一步正确数字的数量大致翻倍）。

- 例如，要计算 $\sqrt{5}$（即函数 $f(x) = x^2 - 5$ 的零点）：$f'(x) = 2x$，所以 $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$。从 $x_0 = 2$ 开始：$x_1 = 2.25$，$x_2 = 2.2361\ldots$，已经精确到小数点后四位。

- 如果初始猜测离根太远、根附近有 $f'(x) = 0$，或附近存在拐点，Newton 方法可能失败。它还要求计算导数，而计算导数可能很昂贵。

- 对于优化（寻找极小值而不是零点），把 Newton 方法应用于 $f'(x) = 0$，得到更新式：

$$x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}$$

- 在多维情况下，它变成 $\mathbf{x}_{n+1} = \mathbf{x}_n - H^{-1} \nabla f(\mathbf{x}_n)$，其中 $H$ 是 Hessian 矩阵。这正是前一篇中的二阶 Taylor 近似：把函数近似成一个二次函数，跳到该二次函数的最小值，再重复。

- **拉格朗日乘子**用于解决**约束优化**：寻找满足约束 $g(x, y) = c$ 时 $f(x, y)$ 的最优值。我们不再搜索整个 $\mathbb{R}^n$，而只在满足约束的集合（曲线或曲面）中搜索。

- 关键洞见是几何上的：在约束最优点，$f$ 的梯度必须与 $g$ 的梯度平行。如果两者不平行，我们就能沿约束移动，同时继续改善 $f$，所以还没有达到最优点。

- 引入新变量 $\lambda$（拉格朗日乘子），定义**拉格朗日函数**：

$$\mathcal{L}(x, y, \lambda) = f(x, y) - \lambda(g(x, y) - c)$$

- 令所有偏导数为零，就得到一个方程组，其解是约束条件下的最优点：

$$\frac{\partial \mathcal{L}}{\partial x} = 0, \quad \frac{\partial \mathcal{L}}{\partial y} = 0, \quad \frac{\partial \mathcal{L}}{\partial \lambda} = 0$$

![拉格朗日乘子：在最优点，f 与 g 的梯度平行](../images/lagrange_multiplier.svg)

- 例如，在约束 $x^2 + y^2 = 1$ 下最大化 $f(x,y) = x^2 y$。拉格朗日函数为 $\mathcal{L} = x^2 y - \lambda(x^2 + y^2 - 1)$。求偏导：

$$2xy - 2\lambda x = 0, \quad x^2 - 2\lambda y = 0, \quad x^2 + y^2 = 1$$

- 由第一个方程（假设 $x \neq 0$）可得：$\lambda = y$。代入第二个方程：$x^2 = 2y^2$。结合约束：$2y^2 + y^2 = 1$，所以 $y = \frac{1}{\sqrt{3}}$。最大值为 $f = \frac{2}{3\sqrt{3}}$。

- 对于不等式约束（$g(x,y) \leq c$ 而不是 $= c$），**Karush–Kuhn–Tucker（KKT）条件**推广了拉格朗日乘子。约束要么是活跃的（绑定，按等式处理），要么是不活跃的（解位于内部，约束不起作用）。

- 实际上，我们很少手算优化。下面是主要的算法家族：

    - **一阶方法**（只使用梯度）：梯度下降、随机梯度下降（SGD）和 Adam。每一步成本低，但可能收敛缓慢，尤其是面对病态问题时。

    - **二阶方法**（使用梯度和 Hessian）：Newton 方法收敛快，但计算和求逆 Hessian 的成本很高（对 $n$ 个参数为 $O(n^3)$）。**拟 Newton 方法**（如 BFGS 和 L-BFGS）只用梯度信息近似 Hessian，在不承担二阶方法全部成本的情况下，比一阶方法收敛更快。

    - **共轭梯度**：适用于大型稀疏系统，只使用矩阵—向量乘法，而不是存储完整 Hessian。

    - **Gauss–Newton** 和 **Levenberg–Marquardt**：专用于最小二乘问题（回归中很常见），通过 Jacobian 近似 Hessian。

    - **自然梯度下降**：使用 Fisher 信息矩阵考虑参数空间的几何，在概率模型中可能更有效。

- 优化器的选择取决于问题。对深度学习而言，一阶方法（尤其是 Adam）占主导地位，因为参数数量巨大（从数百万到数十亿），计算 Hessian 不切实际。对于目标函数平滑的小型问题，二阶方法可能快得多。

## 编程任务（使用 CoLab 或 notebook）

1. 实现 Newton 方法，求 $\sqrt{7}$（即函数 $f(x) = x^2 - 7$ 的零点）。观察它快速收敛的过程。
```python
import jax.numpy as jnp

f = lambda x: x**2 - 7
df = lambda x: 2*x

x = 3.0  # initial guess
for i in range(6):
    x = x - f(x) / df(x)
    print(f"step {i+1}: x = {x:.10f}  (error: {abs(x - jnp.sqrt(7.0)):.2e})")
```

2. 使用梯度下降最小化 $f(x, y) = (x - 3)^2 + (y + 1)^2$。最小值位于 $(3, -1)$。尝试不同的学习率。
```python
import jax
import jax.numpy as jnp

def f(params):
    x, y = params
    return (x - 3)**2 + (y + 1)**2

grad_f = jax.grad(f)
params = jnp.array([0.0, 0.0])
lr = 0.1

for i in range(20):
    g = grad_f(params)
    params = params - lr * g
    if i % 5 == 0 or i == 19:
        print(f"step {i:2d}: ({params[0]:.4f}, {params[1]:.4f})  loss={f(params):.6f}")
```

3. 数值求解一个约束优化问题。在约束 $x + y = 10$ 下最大化 $f(x,y) = xy$：参数化 $y = 10 - x$，再寻找单变量函数的最优值。
```python
import jax
import jax.numpy as jnp

# Substitute constraint: y = 10 - x, so f = x(10 - x) = 10x - x²
f = lambda x: x * (10 - x)
df = jax.grad(f)

# Gradient ascent (we want maximum, so add gradient)
x = 1.0
lr = 0.1
for i in range(20):
    x = x + lr * df(x)
print(f"x={x:.4f}, y={10-x:.4f}, f={f(x):.4f}")  # should be x=5, y=5, f=25
```
