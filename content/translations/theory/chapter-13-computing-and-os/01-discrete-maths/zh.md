# 离散数学

*离散数学研究可数、彼此分离的结构，是计算机科学的数学基础。本篇介绍命题逻辑与谓词逻辑、证明方法、集合、关系、函数、图论基础和递推关系。*

- 前几章讨论了连续数学：微积分（第 3 章）、概率分布（第 5 章），以及实值参数上的优化（第 6 章）。计算机则以离散方式运行：存储位（0 或 1）、处理整数、执行条件分支，并操作有限的数据结构。**离散数学**提供了描述和分析这些结构的形式语言。

- 本章涉及的许多计算机科学概念都以离散数学为基础：处理器逻辑门遵循布尔代数，调度算法需要正确性证明，内存管理会用到集合运算，算法分析则常用递推关系。

## 命题逻辑

- **命题逻辑**研究真假陈述及其组合。在经典逻辑中，一个**命题**具有确定真值：要么为真（T），要么为假（F），不能同时为真和为假。“正在下雨”是命题；“现在几点？”是疑问句，没有真值，因此不是命题。

- 命题可以用**逻辑连接词**组合：

    - **与**（合取，$p \wedge q$）：仅当 $p$ 和 $q$ 都为真时为真。
    - **或**（析取，$p \vee q$）：$p$ 和 $q$ 至少有一个为真时为真。
    - **非**（否定，$\neg p$）：将真值取反。
    - **蕴含**（$p \to q$）：仅当 $p$ 为真而 $q$ 为假时为假。“如果下雨，地面就会湿”这一蕴含只会在下雨而地面没湿时为假。
    - **当且仅当**（双条件，$p \leftrightarrow q$）：当两个命题的真值相同时为真。

- **真值表**列出所有可能的输入组合及对应结果。$n$ 个命题共有 $2^n$ 种真值组合。真值表可用于验证逻辑等价式：

| $p$ | $q$ | $p \wedge q$ | $p \vee q$ | $p \to q$ |
|-----|-----|--------------|------------|-----------|
| T | T | T | T | T |
| T | F | F | T | F |
| F | T | F | T | T |
| F | F | F | F | T |

- 注意前件 $p$ 为假的情况：无论 $q$ 是什么，$F \to q$ 都为真。这称为**空真**。例如，“如果猪会飞，那么我是英格兰国王”在经典命题逻辑中为真，因为前件为假。它不符合日常语言直觉，但在形式推理中有明确作用。

- **逻辑等价式**是对所有真值赋值都成立的恒等式：

    - **德摩根定律**：$\neg(p \wedge q) \equiv \neg p \vee \neg q$，且 $\neg(p \vee q) \equiv \neg p \wedge \neg q$。否定合取时，要分别否定两个部分并将“与”改为“或”，反过来也一样。编程中也会用到这一规则：<code>!(a && b)</code> 等价于 <code>(!a || !b)</code>。

    - **逆否命题**：$p \to q \equiv \neg q \to \neg p$。在形式逻辑中，“如果下雨，地面就会湿”与“如果地面没湿，就没有下雨”表示等价的蕴含关系。逆否命题常用于证明。

    - **双重否定**：$\neg(\neg p) \equiv p$。

    - **分配律**：$p \wedge (q \vee r) \equiv (p \wedge q) \vee (p \wedge r)$。

- 对所有真值赋值都为真的公式称为**永真式**；对所有赋值都为假的公式称为**矛盾式**；有时为真、有时为假的公式称为**偶然式**。例如，$p \vee \neg p$ 是永真式，$p \wedge \neg p$ 是矛盾式。

## 谓词逻辑和量词

- 命题逻辑无法直接表达关于某个集合中“所有”或“至少一个”元素的陈述。“所有大于 2 的素数都是奇数”需要用到**谓词逻辑**。谓词逻辑在命题逻辑上引入变量、谓词和量词。

- **谓词**是依赖变量的陈述。例如，$P(x)$ 表示“$x$ 是偶数”。给 $x$ 指定具体值后，谓词便成为命题：$P(4)$ 为真，$P(7)$ 为假。

- **量词**用于说明变量的取值范围：

    - **全称量词**（$\forall$）表示“对所有”。$\forall x \, P(x)$ 表示“定义域中的每个 $x$ 都使 $P(x)$ 为真”。
    - **存在量词**（$\exists$）表示“存在”。$\exists x \, P(x)$ 表示“至少存在一个 $x$，使得 $P(x)$ 为真”。

- 否定量词时，全称量词与存在量词会互换：$\neg(\forall x \, P(x)) \equiv \exists x \, \neg P(x)$。“并非所有人都通过了”表示“至少有一个人没通过”。同理，$\neg(\exists x \, P(x)) \equiv \forall x \, \neg P(x)$。“不存在完美算法”表示“每个算法都有缺陷”。

- 嵌套量词可以表达更复杂的关系。$\forall x \, \exists y \, (y > x)$ 表示“每个数都有一个比它大的数”，对整数成立。量词顺序会改变含义：$\exists y \, \forall x \, (y > x)$ 表示“存在一个数大于所有其他数”，对整数不成立。

- 谓词逻辑可用于形式化描述程序规格。例如，算法正确性可表达为：对定义域内的每个输入 $x$，算法都满足预期的输入输出关系；算法对所有输入都会终止，则可写为 $\forall x \, \exists t \, \text{halts}(x, t)$，其中 $t$ 表示某个有限的终止时间。

## 证明方法

- **证明**通过逻辑推导，在给定假设下确立命题。经验测试只能展示有限个样例；严格证明则能覆盖命题所声明的全部情况。这是计算机科学论证算法正确性的常用标准。

- **直接证明**：从假设出发，经由逻辑步骤推出结论。要证明“若 $n$ 为偶数，则 $n^2$ 也为偶数”，令 $n = 2k$，其中 $k$ 为整数。于是 $n^2 = 4k^2 = 2(2k^2)$，所以 $n^2$ 是偶数。

- **反证法**：先假设命题的否定成立，再推出矛盾。证明 $\sqrt{2}$ 是无理数时，假设 $\sqrt{2} = a/b$，其中 $a/b$ 已约成最简分数。于是 $a^2 = 2b^2$，因此 $a^2$ 是偶数，进而 $a$ 是偶数。令 $a = 2c$，代入可得 $b^2 = 2c^2$，所以 $b$ 也是偶数。这与 $a/b$ 已经最简矛盾。

- **数学归纳法**用于证明关于自然数的命题。通常分两步：（1）验证**基础情形**成立，常取 $n=0$ 或 $n=1$；（2）验证**归纳步骤**：假设命题在 $n=k$ 时成立（归纳假设），再由此推出命题在 $n=k+1$ 时成立。

- 例如，用归纳法证明 $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$：
    - 基础情形：$n=1$ 时，$1 = \frac{1 \cdot 2}{2} = 1$，命题成立。
    - 归纳步骤：假设 $\sum_{i=1}^{k} i = \frac{k(k+1)}{2}$。那么
      $\sum_{i=1}^{k+1} i = \frac{k(k+1)}{2} + (k+1)
      = \frac{k(k+1)+2(k+1)}{2}
      = \frac{(k+1)(k+2)}{2}$，
      这正是将 $n$ 替换为 $k+1$ 后的公式。

- 归纳法常用于证明递归算法和数据结构的性质，但递归本身并不自动构成正确性证明。证明时需要明确基础情形，并证明在归纳假设成立时，递归步骤能保持目标性质；还要确认算法会终止。

- **强归纳法**假设命题对不超过 $k$ 的所有值都成立，再证明它对 $k+1$ 成立。当前一步依赖多个较小值（而不只是 $k$）时，这种方法很有用。

- **鸽巢原理**：将 $n+1$ 个对象放入 $n$ 个盒子，至少有一个盒子包含两个或更多对象。由此可知，13 个人中至少有两个人的生日月份相同。在网络中，如果放入桶的项目多于桶的数量，那么至少有两个项目会落入同一个桶，因此哈希碰撞不可避免。

## 集合

- **集合**是由互不相同的元素组成的无序整体。集合是数学中的基础结构，也用于类型系统、数据库查询等计算机科学领域。

- **集合运算**（第 5 章曾在概率论中使用）：

    - **并集** $A \cup B$：属于 $A$、$B$ 或两者的元素。
    - **交集** $A \cap B$：同时属于 $A$ 和 $B$ 的元素。
    - **补集** $\bar{A}$：相对于给定全集，不属于 $A$ 的元素。
    - **差集** $A \setminus B$：属于 $A$ 但不属于 $B$ 的元素。
    - **笛卡尔积** $A \times B$：所有有序对 $(a,b)$ 的集合，其中 $a \in A$ 且 $b \in B$。

- **幂集** $\mathcal{P}(A)$ 是 $A$ 的所有子集组成的集合。若 $|A|=n$，则 $|\mathcal{P}(A)|=2^n$。例如，若 $A=\{1,2\}$，则 $\mathcal{P}(A)=\{\emptyset,\{1\},\{2\},\{1,2\}\}$。

- **基数**表示集合的大小。有限集合的基数是非负整数；无限集合也有不同的基数。自然数集 $\mathbb{N}$ 和有理数集 $\mathbb{Q}$ 是**可数无限集**，也就是其元素可以排成序列；实数集 $\mathbb{R}$ 则是**不可数无限集**，无法这样列举，康托尔对角线论证可证明这一点。这一区别与可计算性有关：从自然数到 {0,1} 的所有函数构成不可数集，但有限程序只有可数多个，因此其中大多数函数不能由程序计算。

## 关系

- 集合 $A$ 上的**关系** $R$ 是笛卡尔积 $A \times A$ 的一个子集，用有序对表示哪些元素彼此相关。例如，整数上的关系 $\leq$ 可写为 $\{(a,b):a\leq b\}$。

- 关系常见的性质包括：

    - **自反性**：每个元素都与自身相关，即对所有 $a$ 都有 $aRa$。例如，$\leq$ 是自反的。
    - **对称性**：若 $aRb$，则 $bRa$。例如，“是……的兄弟姐妹”关系是对称的。
    - **反对称性**：若 $aRb$ 且 $bRa$，则 $a=b$。例如，$\leq$ 是反对称的。
    - **传递性**：若 $aRb$ 且 $bRc$，则 $aRc$。例如，$<$、$\leq$ 和“是……的祖先”关系具有传递性。

- **等价关系**同时满足自反、对称和传递。它将集合划分为若干**等价类**：同一类中的元素彼此等价，不同类中的元素不等价。对正整数 $n$，同余关系 $a \equiv b \pmod{n}$ 将整数划分为 $n$ 个等价类。编程语言中的类型等价也可构成等价关系。

- **偏序**满足自反、反对称和传递；它允许存在无法相互比较的元素。目录的包含关系是一个例子：两个互不包含的同级目录不可比较。**全序**是在偏序基础上还要求任意两个元素都可比较，例如整数上的 $\leq$。

- 并发理论中的“先发生于”关系通常是严格偏序；给它补上自反关系后可得到偏序。若两个事件之间没有先后关系，它们就是并发的，执行时可以处于不同的相对顺序。

## 函数

- 函数 $f:A\to B$ 将集合 $A$（定义域）中的每个元素映射到集合 $B$（陪域）中的唯一一个元素。函数是确定性计算的数学模型：输入给定后，输出唯一确定。

- **单射**：不同的输入映射到不同的输出，即 $f(a)=f(b)\implies a=b$。无损压缩必须是单射：如果两个不同输入压缩成同一个结果，就无法唯一恢复原数据。

- **满射**：陪域 $B$ 中的每个元素都至少是某个 $A$ 中元素的像，也就是像集等于陪域。哈希函数把字符串映射到 256 位摘要，并不能仅凭输出位数判断它是否满射；满射与否取决于像集是否覆盖全部 $2^{256}$ 个可能摘要。字符串的数量多于摘要值的数量，只能推出存在碰撞，不能单独推出函数非满射。

- **双射**：既是单射也是满射，因而在定义域与陪域之间建立一一对应，并且存在逆函数。对固定密钥而言，加密至少要能从密文唯一恢复明文，因此必须对明文单射；若将陪域定义为实际可达的密文集合，这一映射才是双射，其逆函数就是解密。

- **复合函数** $(g \circ f)(x)=g(f(x))$ 表示先应用 $f$，再应用 $g$。函数复合满足结合律，这与矩阵乘法的结合律相同，但通常不满足交换律。软件处理管线也可以看成一连串函数复合：数据依次经过多个变换。

## 图论基础

- 第 12 章介绍过邻接矩阵、图的类型、图拉普拉斯矩阵和谱理论等内容。本节聚焦计算机科学中常见的图结构与算法性质。

- **树**是连通且无环的无向图。对有限树，若有 $n$ 个节点，就有 $n-1$ 条边。树可用于表示文件系统、XML/HTML 文档、决策过程和递归分解。**有根树**指定一个根节点，其余每个节点都有唯一的父节点。

- 图 $G$ 的**生成树**是由 $G$ 的部分边构成、并包含 $G$ 所有节点的一棵树。对连通加权图，**最小生成树**（MST）是总边权最小的生成树。Kruskal 算法将边按权重排序，并依次加入不会形成环的最轻边；Prim 算法从一个起始节点出发，每次把权重最小、连接新节点的边加入树中。对简单连通图，用二叉堆实现 Prim、用比较排序实现 Kruskal 时，两者的时间复杂度均为 $O(|E|\log|V|)$。

- **平面图**可以在平面上绘制，且边之间没有交叉。根据**欧拉公式**，连通平面图满足 $|V|-|E|+|F|=2$，其中 $|F|$ 是面（包括外部面）的数量。对至少有 3 个节点的简单平面图，这推出 $|E|\leq 3|V|-6$，因此其边数相对于节点数是稀疏的。电路板布线和地图着色都会涉及平面性。

- **图着色**是给节点分配颜色，使任意相邻节点颜色不同。所需的最少颜色数称为**色数** $\chi(G)$。**四色定理**指出，任意平面图都满足 $\chi(G)\leq4$。在计算机科学中，图着色可用于建模寄存器分配：同时存活的变量需要分配到不同 CPU 寄存器；也可用于调度：存在冲突的任务不能安排在同一时段。

- **欧拉通路**恰好经过图中的每条边一次。对连通无向图（忽略孤立点），当奇度节点数为 0 或 2 时，且仅当如此，欧拉通路存在。**哈密顿路径**恰好经过每个节点一次。判定哈密顿路径是否存在是 NP 完全问题。两类问题看似相似，复杂度却不同：欧拉通路可在线性时间内判定，哈密顿路径判定则是经典的 NP 完全问题。

## 递推关系

- **递推关系**用前面的项定义数列中的当前项，常见于递归算法的分析。

- 一个简单例子是 $T(n)=T(n-1)+1$，初值为 $T(0)=0$。逐步展开可得 $T(n)=T(n-1)+1=T(n-2)+2=\cdots=n$。因此 $T(n)$ 为 $O(n)$，与简单循环的时间复杂度相同。

- 归并排序满足 $T(n)=2T(n/2)+O(n)$：将数组分成两半，递归排序两个大小为 $n/2$ 的子数组，再用 $O(n)$ 时间合并。其时间复杂度为 $O(n\log n)$。

- **主定理**可用于求解 $T(n)=aT(n/b)+\Theta(n^d)$ 形式的递推式；这里默认递归规模整除，并满足相应的正则性条件：

    - 若 $d>\log_b a$，则 $T(n)=\Theta(n^d)$，每层的非递归工作占主导。
    - 若 $d=\log_b a$，则 $T(n)=\Theta(n^d\log n)$，各层工作的总量同阶。
    - 若 $d<\log_b a$，则 $T(n)=\Theta(n^{\log_b a})$，子问题数量的增长占主导。

- 归并排序中 $a=2$、$b=2$、$d=1$，而 $d=\log_2 2=1$，所以属于第二种情况，得到 $T(n)=\Theta(n\log n)$。

- **斐波那契递推**为 $F(n)=F(n-1)+F(n-2)$，初值是 $F(0)=0$、$F(1)=1$。其闭式解为
  $F(n)=\frac{\phi^n-\psi^n}{\sqrt{5}}$，
  其中 $\phi=\frac{1+\sqrt{5}}{2}$（黄金比例），$\psi=\frac{1-\sqrt{5}}{2}$。斐波那契数列的数值按 $\Theta(\phi^n)$ 增长。朴素递归算法会重复计算子问题，其运行时间也按指数级增长。

- 第 5 章（概率论）讨论了组合数学，包括排列、组合、二项式定理和容斥原理。这些计数方法也用于分析算法，例如估算输入数量和比较次数，本篇不再重复。

## 可计算性

- 并非所有问题都可计算。可计算性理论刻画了计算机所能解决问题的边界。

- **图灵机**是抽象的计算模型，由一条可无限延伸的纸带（每格存放一个符号）、读写头、有限个状态和状态转移规则组成。图灵机是对计算能力的理论抽象；它不受现实机器有限内存的限制。**丘奇–图灵论题**认为，任何可有效计算的函数都能由图灵机计算。这是论题而非已证明的数学定理。

- 具备通用计算能力的编程语言（如 Python、C 和 Haskell）是**图灵完备**的：它们能够模拟图灵机，从而计算所有可计算函数。并非每种编程语言都具有这种能力；不同语言在便利性、速度和安全性方面也有差异。

- **停机问题**问的是：给定程序及其输入，程序最终会停机，还是会无限运行？图灵在 1936 年证明，不存在能对所有程序和输入都正确判断这一问题的算法。反证思路如下：假设存在停机判定器 $H(P,x)$，能判断程序 $P$ 在输入 $x$ 时是否停机。构造程序 $D$，让它运行 $H(D,D)$，然后采取相反行为：若 $H$ 判断 $D$ 会停机，$D$ 就无限循环；若 $H$ 判断 $D$ 会循环，$D$ 就停机。两种情况下都与判定结果矛盾。

- 这不是现有技术的限制，而是数学上的不可判定性。不存在对所有程序都适用的完美停机检测算法。不过，对受限的程序语言或特定程序集合，仍可能进行精确分析。这与哥德尔不完备定理有相似之处，但两者并非同一结论。

- 这一结论也限制了通用程序分析工具：若要求工具对任意程序的停机行为、死锁或恶意行为都作出完备且无误的判断，就会遇到不可判定问题。实际工具通常依靠启发式方法和近似分析，在常见场景中有效，但不能保证对所有输入都正确。

- 一个问题是**可判定的**，当且仅当存在一种算法，能总是终止并给出正确的是/否答案；否则称为**不可判定的**。停机问题不可判定，素性测试可判定。多数常见编程语言的类型检查也可判定。

## 复杂性理论

- 即使问题可计算，解决它们所需的资源也可能相差很大。**复杂性理论**根据输入规模增长时所需的时间和空间等资源，对问题进行分类。

![P、NP 与 NP 完全：P 包含于 NP；NP 完全问题是 NP 中最难的一类；P 是否等于 NP 仍是开放问题](../images/p_np_complexity.svg)

- **P**（多项式时间）包含能在 $O(n^k)$ 时间内求解的问题，其中 $k$ 为某个常数。例如，比较排序可在 $O(n\log n)$ 时间内完成；边权非负时，用数组实现的 Dijkstra 算法可在 $O(|V|^2)$ 时间内完成；经典矩阵乘法的复杂度为 $O(n^3)$。多项式时间通常被视为“高效”或“可处理”，但实际效率也取决于指数和常数。

- **NP**（非确定性多项式时间）包含这样的问题：给出一个候选解后，可以在多项式时间内验证其正确性；但找到解本身可能需要指数时间。例如，给定一条哈密顿路径，可以在 $O(n)$ 时间内检查节点是否各出现一次，以及相邻节点之间是否有边；然而，找到这样的路径可能需要尝试指数数量的候选方案。

- 每个 P 问题都属于 NP：若问题能被快速求解，就能快速验证解。核心开放问题是 $P$ 是否等于 $NP$，也就是所有能被快速验证解的问题是否也都能被快速求解。这是计算机科学中的重要未解问题，克雷数学研究所为其设有 100 万美元的千禧年大奖。

- 许多研究者猜测 $P\neq NP$，即有些问题的求解比验证更难。若 $P=NP$，基于计算困难性的许多密码学安全假设会受到根本影响，优化、调度和药物设计等问题也可能获得高效算法；具体后果取决于问题的形式化定义和实际算法复杂度。

- **NP 完全问题**是 NP 中最难的一类。若一个问题（1）属于 NP，且（2）NP 中每个问题都能在多项式时间内归约到它，那么它就是 NP 完全问题。若任意一个 NP 完全问题能被高效求解，NP 中的所有问题都能被高效求解，因此有 $P=NP$。

- **归约**将一个问题转化为另一个问题。如果问题 A 能在多项式时间内归约到问题 B，那么 B 至少与 A 一样难。Cook 在 1971 年证明 SAT（布尔可满足性问题：给定逻辑公式，判断是否存在一种变量赋值使公式为真）是 NP 完全问题。Karp 在 1972 年通过将 SAT 归约到其他问题，证明了另外 21 个经典问题也是 NP 完全问题。

- 常见的 NP 完全问题包括：
    - **旅行商问题**（决策版本）：给定城市间距离和上限，判断是否存在一条访问每座城市一次且总长度不超过上限的路线。求最短路线的优化版本是 NP 难问题。
    - **图着色**：给节点着 $k$ 种颜色，使相邻节点不同色；当 $k\geq3$ 时，判定是否能完成着色是 NP 完全问题。
    - **子集和问题**：给定整数集合和目标值，判断是否存在一个子集，其元素之和等于目标值。
    - **布尔可满足性问题**（SAT）：判断一个逻辑公式是否存在满足它的真值赋值。
    - **哈密顿路径问题**：前文已介绍。

- 实际上，大规模 NP 完全问题通常不做精确求解，而会采用**近似算法**（在适用条件下保证解与最优解之间的界）、**启发式方法**（如贪心、局部搜索和模拟退火），或针对特殊情形的求解器。许多 NP 完全问题在受限输入上容易处理。现代 SAT 求解器可以借助实际实例的结构，解决某些含有数百万变量的实例；最坏情况下仍可能需要指数时间。

- **NP 难问题**是指 NP 中的每个问题都能在多项式时间内归约到它的问题；它不一定属于 NP，也不一定是可在多项式时间内验证候选解的判定问题。NP 完全问题的优化版本通常是 NP 难问题：找到最短旅行商路线是 NP 难的，而判断是否存在长度小于 $k$ 的路线是 NP 完全问题。

1. 编写真值表生成器。给定逻辑表达式，枚举所有输入组合并计算输出。

```python
import itertools

def truth_table(n_vars, expr_fn):
    """Generate truth table for a boolean function of n_vars variables."""
    headers = [f"p{i}" for i in range(n_vars)]
    print(" | ".join(headers + ["result"]))
    print("-" * (len(headers) * 4 + 10))
    for vals in itertools.product([False, True], repeat=n_vars):
        result = expr_fn(*vals)
        row = [str(v)[0] for v in vals] + [str(result)[0]]
        print(" | ".join(f"{r:>2}" for r in row))

# De Morgan's law: NOT(p AND q) == (NOT p) OR (NOT q)
print("De Morgan's Law verification:")
truth_table(2, lambda p, q: (not (p and q)) == ((not p) or (not q)))
```

这段代码对每组输入计算两边是否相等，因此会逐项检查德摩根等价式。它展示了固定公式的验证；真值表生成器本身可接收其他布尔函数。

3. 用主定理求解归并排序的递推式，并通过操作计数作经验性核对。

```python
import jax.numpy as jnp

def merge_sort_ops(n):
    """Count comparisons in merge sort (recurrence: T(n) = 2T(n/2) + n)."""
    if n <= 1:
        return 0
    half = n // 2
    return merge_sort_ops(half) + merge_sort_ops(n - half) + n

for n in [8, 64, 512, 4096, 32768]:
    ops = merge_sort_ops(n)
    predicted = n * jnp.log2(n)
    ratio = ops / predicted
    print(f"n={n:5d}  ops={ops:>10d}  n log n={int(predicted):>10d}  ratio={ratio:.3f}")
```

原代码把每次合并的 $n$ 记作“比较次数”，但它实际直接累加递推式中的线性工作量，并未模拟归并过程或统计实际比较次数。给出的 $n$ 都是 2 的幂，避免了递归划分不均的问题。代码中的 JAX 仅用于计算 $\log_2 n$。
