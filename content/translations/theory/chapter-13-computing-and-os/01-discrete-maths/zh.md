# 离散数学

*离散数学是基于可计数、分离结构的数学，这是计算机科学的基础。本文件涵盖了命题逻辑和谓词逻辑、证明技术、集合、关系、函数、图论基础以及递归关系等内容。*

- 在前面章节中，我们处理了连续数学：微积分（第3章）、概率分布（第5章）和实值参数优化（第6章）。但计算机本质上是**离散**机器。它们存储位（0或1），处理整数，遵循分支逻辑，并操作有限数据结构。**离散数学**提供了关于这些结构的正式语言。

- 本章中的所有内容都依赖于离散数学：处理器逻辑门是布尔代数，调度算法需要证明正确性，内存管理使用集合运算，算法分析要求递归关系。

## 命题逻辑

- **命题逻辑**是真值为真或假的陈述的代数。一个**命题**是一个要么是真的（T），要么是假（F）的陈述，既不能同时为真也不能同时为假。“它正在下雨”是一个命题。 “现在几点？”不是（因为它是一个问题，而不是具有真假值的陈述）。

- 命题可以使用**逻辑连接符**组合：

    - **与**（合取，$p \wedge q$）：只有当 $p$ 和 $q$ 都为真时才为真。
    - **或**（析取，$p \vee q$）：至少有一个 $p$ 或 $q$ 为真时为真。
    - **非**（否定，$\neg p$）：翻转真假值。
    - **如果则**（蕴含，$p \to q$）：只有当 $p$ 为真且 $q$ 为假时才为假。 “如果下雨，地面就湿”只有在下雨且地面干的时候才会违反。
    - **如果且仅则**（双条件，$p \leftrightarrow q$）：当两者具有相同的真假值时为真。

- **真值表**全面地列举了所有可能的输入组合及其结果。对于 $n$ 命题，表格有 $2^n$ 行。这是如何验证逻辑等价性的方法：

| $p$ | $q$ | $p \wedge q$ | $p \vee q$ | $p \to q$ |
|-----|-----|--------------|------------|-----------| T | T | T | T | T |
| T | F | F | T | F |
| F | T | F | T | T |
| F | F | F | F | T |

- 与 $p$ 为假相关的行 deserves注意： $F \to q$ 总是为真，无论 $q$ 如何。这是 **空值真**。 “如果猪飞，那么我是英格兰的国王”在数学上是逻辑正确的，因为前提为假。这似乎与直觉相悖，但对数学推理至关重要。

- **逻辑等价式**是恒等式，适用于所有真假值：

    - **德摩根定律**： $\neg(p \wedge q) \equiv \neg p \vee \neg q$ 和 $\neg(p \vee q) \equiv \neg p \wedge \neg q$。要否定一个 AND，否定每个部分并切换到 OR（反之亦然）。这些在编程中直接出现： `!(a && b)` 等价于 `(!a || !b)`。

    - **逆否命题**：$p \to q \equiv \neg q \to \neg p$。如果下雨，地面湿润。这等同于“如果地面不湿润，就没有下雨。”这是一个强大的证明方法。

    - 双重否定：$\neg(\neg p) \equiv p$。

    - 分配律：$p \wedge (q \vee r) \equiv (p \wedge q) \vee (p \wedge r)$。

- 一个总是为真的公式（对于所有真赋值）是“永真”。另一个总是为假的公式是“矛盾”。另一个有时为真有时为假的是“ contingent”。例如，$p \vee \neg p$ 是永真，$p \wedge \neg p$ 是矛盾。

## 谓词逻辑和量词

- 命题逻辑不能表达关于集合中所有或某些元素的陈述。"大于2的所有素数都是奇数"需要**谓词逻辑**，它扩展了命题逻辑，引入变量、谓词和量词。

- 一个谓语是一个依赖于变量的陈述： $P(x)$ = "$x$ 它是偶数。它成为命题时， $x$ 给定一个特定的值： $P(4)$ 是的， $P(7)$ 是错误的。

- **量词**表示范围：

    - **全称量词**（$\forall$）："对于所有。" $\forall x \, P(x)$表示“在域中，$P(x)$对每个$x$都为真。”
    - **存在量词**（$\exists$）："存在一个。" $\exists x \, P(x)$表示“至少有一个$x$，使得$P(x)$为真。”

- 质量否定翻转：$\neg(\forall x \, P(x)) \equiv \exists x \, \neg P(x)$。"没有人通过"意味着"有人失败。"而$\neg(\exists x \, P(x)) \equiv \forall x \, \neg P(x)$。"没有完美的算法"意味着"每个算法都有缺陷。"

- 复合量词表达复杂关系。$\forall x \, \exists y \, (y > x)$表示“对于每一个数，都有一个更大的数”（对整数为真）。顺序很重要：$\exists y \, \forall x \, (y > x)$表示“有比其他所有数都大的数”（对整数为假）。

- 命题逻辑是形式化规格语言。当我们说一个算法“正确”时，我们指的是$\forall \text{inputs} \, x, \, \text{output}(x) = \text{desired}(x)$。当我们说它“终止”时，我们指的是$\forall x \, \exists t \, \text{halts}(x, t)$。

## 证明技术

- **证明**是一个逻辑论证，用于建立陈述的真确性，而不仅仅是通过测试案例来显示其有效性。在计算机科学中，这是正确性的标准。

- **直接证明**：假设前提，通过逻辑步骤推导出结论。要证明“如果$n$是偶数，则$n^2$也是偶数”：假设$n = 2k$为某个整数$k$，然后$n^2 = 4k^2 = 2(2k^2)$，它是偶数。

- **反证法**：假设陈述为假，推导出矛盾。要证明 $\sqrt{2}$ 无理数：假设 $\sqrt{2} = a/b$（化简完全）。则 $2 = a^2/b^2$，所以 $a^2 = 2b^2$，意味着 $a^2$ 是偶数，所以 $a$ 是偶数，设 $a = 2c$。然后 $4c^2 = 2b^2$，所以 $b^2 = 2c^2$，意味着 $b$ 也是偶数。但我们在假设 $a/b$ 化简完全时说的 -- 矛盾。

- **数学归纳法**：通过证明一个陈述对于所有自然数都成立来证明它。这通常涉及两个步骤：（1）验证基础情况（通常是 $n = 0$ 或 $n = 1$），以及（2）递推步骤：如果在 $n = k$ 假设下该陈述成立，则在 $n = k + 1$ 时也成立。

- 例如，证明 $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$：
    - 基本情况： $n = 1$: $1 = \frac{1 \cdot 2}{2} = 1$。 真。
    - 递推步骤：假设 $\sum_{i=1}^{k} i = \frac{k(k+1)}{2}$。 则 $\sum_{i=1}^{k+1} i = \frac{k(k+1)}{2} + (k+1) = \frac{k(k+1) + 2(k+1)}{2} = \frac{(k+1)(k+2)}{2}$。 这是公式中包含的 $n = k+1$。 完成。

- 递归算法和数据结构的正确性通常通过归纳法来证明。每个递归算法都有一个隐式的归纳证明：基本情况是终止条件，递归调用是归纳步骤。

- 强归纳法假设陈述对所有值都成立。 $k$ (不只) $k$然后证明它。 $k + 1$当递归依赖于不止一个前值时，这很有用。

- **鸽巢原理**：如果$n+1$个对象被放置在$n$个盒子里，至少有一个盒子里有两个对象。简单但令人惊讶地强大。它证明了在任何13个人的群体中，至少有两个人共享同一个生日月份。在网络领域，它证明当物品的数量多于桶的数量时，哈希碰撞是不可避免的。

## 集合

- **集合** 是一个无序的元素集合，其中每个元素都是唯一的。集合是数学中最基本的数据结构之一，它们在类型系统和数据库查询中起着至关重要的作用。

- **集合操作**（连接到第5章，我们使用这些进行概率）：

    - **并集** $A \cup B$：元素在 $A$ 或 $B$ 或两者中。
    - **交集** $A \cap B$：元素在 $A$ 和 $B$ 中都存在。
    - **补集** $\bar{A}$：不在 $A$ 中的元素（相对于一个全集）。
    - **差集** $A \setminus B$：在 $A$ 中但不在 $B$ 中的元素。
    - **笛卡尔积** $A \times B$：所有有序对 $(a, b)$，其中 $a \in A, b \in B$。

- 集合的幂集 $\mathcal{P}(A)$ 是所有子集的集合 $A$如果 $|A| = n$然后 $|\mathcal{P}(A)| = 2^n$. 对 $A = \{1, 2\}$。 $\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}$。

- **集合大小**衡量集合的规模。有限集合具有整数大小。无限集合有不同的大小：自然数 $\mathbb{N}$ 和有理数 $\mathbb{Q}$ 是可数无限（可以列出），而实数 $\mathbb{R}$ 是不可数无限（不能列出，通过 Cantor 的对角线论证证明）。这种区别在计算理论中很重要：存在不可数多的函数，但只有可数多的程序，因此大多数函数是不可计算的。

## 关系

- 一个 **关系** $R$ 在集合 $A$ 上是一个子集于 $A \times A$：一组有序对，指定哪些元素是相关的。例如，$\leq$ 对整数是集合 $\{(a, b) : a \leq b\}$。

- 关系的重要属性：

    - **反射性**：每个元素都与自身相关。 $a R a$ 对于所有 $a$例如： $\leq$ （每个数字是 $\leq$ 它本身。
- **对称性**：如果 $a R b$ 然后 $b R a$例如：“是同卵双胞胎。”
- **反对称**：如果 $a R b$ 和 $b R a$ 然后 $a = b$例如： $\leq$- **可传递性**：如果 $a R b$ 和 $b R c$ 然后 $a R c$例如： $<$， $\leq$是祖先。

- 一个 **等价关系** 是自反的、对称的和传递的。它将集合划分为 **等价类**，其中每个类内的所有元素彼此相关，但与其他类中的元素无关。模算术是等价关系：$a \equiv b \pmod{n}$ 将整数划分为 $n$ 类。在编程语言中类型等价是一个等价关系。

- 一个 **偏序关系** 是自反的、反对称的和传递的。它定义了一个“小于或等于”的结构，可能会留下一些元素不可比较。文件系统目录形成一个偏序关系（父子），但同级目录是不可比较的。一个 **全序关系** 是一个偏序关系，其中每一对都是可比的（就像 $\leq$ 在整数上）。

- 线程间顺序关系是并发的核心：事件之间的“发生于”关系是一个部分序。不被“发生于”关系排序的事件是并发的，它们可能以任何相对顺序执行。

## 函数

- 一个 **函数** $f: A \to B$ 将 $A$（域）中的每个元素映射到 $B$（目标空间）中的恰好一个元素。 函数是确定性计算的数学模型：给定输入，有且只有一个输出。

- **单射**（一对一）：不同的输入总是给出不同的输出。$f(a) = f(b) \implies a = b$。无损压缩是单射的：不同的输入必须压缩到不同的输出（否则你无法唯一解压）。

- **满射**（覆盖）：$B$中的每个元素都被$A$中的某个元素映射到。范围等于codomain。将字符串映射到256位哈希的哈希函数不是满射，如果可能的字符串数量少于哈希的数量。

- **双射**：既是单射又是满射。$A$和$B$之间的完美一对一对应。双射有逆函数。加密必须是双射的：每个明文映射到唯一的密文，解密函数是逆函数。

- **组合** $(g \circ f)(x) = g(f(x))$：首先应用 $f$，然后应用 $g$。函数组合是可交换的（第2章：与矩阵乘法相同）。软件中的管道也是函数组合：数据通过一系列变换流过。

## 图论基础

- 在第12章（图神经网络）中，我们广泛讨论了图的概念，包括邻接矩阵、图类型、拉普拉斯算子和谱理论。在这里，我们将重点探讨与计算机科学相关的**算法学**和**结构学**属性。

- **树**是一个不包含环的连通图。 equivalently，它有 $n$ 个节点和 $n-1$ 条边。树是文件系统、XML/HTML文档、决策过程和递归分解的结构。一个**根树**有一个指定的根节点；每个其他节点恰好有一个父节点。

- 一个图的**生成树** $G$ 是一个包含所有节点的树。 $G$ 使用其边的子集。**最小生成树（MST）**最小化总边权重。克鲁斯卡尔算法（按边排序，贪婪地添加不创建循环的最轻者）和普里姆算法（从起始节点开始生长树，总是向新节点添加最轻的边）都找到MST。 $O(|E| \log |V|)$。

- **平面性**：一个图是平面的，如果它可以在平面上绘制，而没有边相交。根据欧拉公式，对于一个连通的平面图：$|V| - |E| + |F| = 2$，其中 $|F|$ 是面（包括外部面）的数量。这表明 $|E| \leq 3|V| - 6$ 对于平面图成立，因此平面图是稀疏的。电路板路由和地图着色利用了平面性。

- **图着色**将颜色分配给节点，使得相邻节点不共享颜色。所需的最小颜色数是**染色数**$\chi(G)$。四色定理指出$\chi(G) \leq 4$对于任何平面图成立。在计算机科学中，图着色模型了寄存器分配（将变量分配到CPU寄存器以确保同时存在的变量使用不同的寄存器）和调度（将任务分配到时间槽中，以避免冲突的任务重叠）。

- **欧拉路径**恰好访问每条边一次。它们仅在图中恰好有0或2个奇度节点时存在。**汉密尔顿路径**恰好访问每个节点一次。确定是否存在汉密尔顿路径是一个NP完全问题——计算机科学中的经典难题之一。这种对比（欧拉：多项式，汉密尔顿：NP完全）说明了看似相似的问题在计算复杂性上可以相差巨大。

## 递归关系

- 递归关系定义了一个序列，其中每个项都依赖于前面的项。它们自然地从递归算法中出现。

- 最简单的例子：$T(n) = T(n-1) + 1$和$T(0) = 0$。展开：$T(n) = T(n-1) + 1 = T(n-2) + 2 = \cdots = n$。这是$O(n)$，简单循环的时间复杂度。

- **归并排序**给出 $T(n) = 2T(n/2) + O(n)$：将数组分成两半（两个子问题大小为 $n/2$），递归地对每个子数组进行排序，然后合并（ $O(n)$ 工作）。解决方案是 $T(n) = O(n \log n)$。

- 大根定理用于解决形式为 $T(n) = aT(n/b) + O(n^d)$ 的递推关系。

    - 如果 $d > \log_b a$： $T(n) = O(n^d)$（每一层的工作占主导）
    - 如果 $d = \log_b a$： $T(n) = O(n^d \log n)$（工作在各层之间平衡）
    - 如果 $d < \log_b a$： $T(n) = O(n^{\log_b a})$（子问题的数量占主导）

- 对于归并排序： $a = 2, b = 2, d = 1$。由于 $d = \log_2 2 = 1$，我们处于平衡情况： $T(n) = O(n \log n)$。

- 斐波那契递推 $F(n) = F(n-1) + F(n-2)$ 在 $F(0) = 0, F(1) = 1$ 有解析解 $F(n) = \frac{\phi^n - \psi^n}{\sqrt{5}}$ 哪里 $\phi = \frac{1+\sqrt{5}}{2}$ 黄金分割率 $\psi = \frac{1-\sqrt{5}}{2}$这表明斐波那契数列以指数级增长。 $O(\phi^n)$因为朴素递归的斐波那契算法是指数级慢的。

- 组合数学（排列、组合、二项式定理和包含排除原则）在第5章（概率）中讨论。这些计数技术对于算法分析至关重要（有多少可能的输入？有多少比较？），但我们不会在这里重复它们。

## 可计算性

- 不是所有问题都能被计算。这是数学中最重要的结果之一，它揭示了计算机所能做的最根本限制。

- 一个 **图灵机** 是一种抽象的计算模型：一张无限长的单元格（每个单元格都包含一个符号），一个读写头，以及一个有限的状态集和转换规则。尽管它的简单性，图灵机可以执行任何真实计算机都可以执行的任务。这就是 **图灵-丘奇假设**：任何可有效计算的函数都可以通过图灵机来计算。

- 每种编程语言（如 Python、C 和 Haskell）都是 **图灵完备** 的：它能模拟图灵机，因此可以计算任何可计算的东西。不同语言之间的差异在于方便性、速度和安全性，而不是它们所能真正计算的内容。

- **停机问题**询问：给定一个程序和输入，程序最终是否会停止，还是会永远运行？图灵（1936年）证明了没有算法可以解决这个问题的一般情况。证明是通过反证法进行的：假设存在一个停机检测器 $H(P, x)$。构造一个程序 $D$，它运行 $H(D, D)$ 并做与 $H$ 相反的事情。如果 $H$ 说 $D$ 停止，$D$ 会永远循环。如果 $H$ 说 $D$ 循环，$D$ 会停止。矛盾。

- 这不是当前技术的限制；它是数学上的不可能。无论计算能力多么强大，聪明程度如何，人工智能也无法解决一般情况下的停机问题。它与哥德尔不完备性定理在计算机科学中具有相似的意义。

- 实际后果：你无法编写一个完美的死锁检测器、完美的病毒扫描器或完美的优化编译器。每个这些都需要解决通用的停机问题（或等价的不可解问题）。现实工具使用 heuristic 和近似值，它们在常见情况下工作得很好，但不能保证对所有输入都正确。

- 一个问题 **可解** 如果存在一个算法总是以正确的 yes/no 答案终止。如果不存在这样的算法，则该问题 **不可解**。停机问题是不可解的。大多数编程语言中的类型检查是可解的（设计上）。

## 复杂性理论

- 在可计算问题中，有些问题比其他问题要复杂得多。**复杂性理论**通过分析解决问题所需资源（时间、空间）来对问题进行分类。

![P、NP和NP完全：P包含在NP中，NP完全位于边界上，P是否等于NP是中心开放问题](../images/p_np_complexity.svg)


- 多项式时间：可解问题 $O(n^k)$ 时间到了，该设定一些常数。 $k$排序（$O(n \log n)$最短路径（）$O(|V|^2)$矩阵乘法（）$O(n^3)$这些被认为是“高效”或“可处理”的。

- 非确定性多项式时间（NP）问题是指，一个提出的解决方案可以在多项式时间内验证，即使找到该解决方案可能需要指数时间。例如，给定一个声称的哈密顿路径，你可以通过多项式时间来验证它。 $O(n)$ 通过检查每条边。但找到一条可能需要尝试指数级的可能情况。

- 每个 P 类问题都属于 NP 类（如果可以快速解决，那么也可以快速验证解决方案）。核心问题是：$P = NP$: 是否所有可以通过快速验证的解都可以快速求解？这是计算机科学中最重要且未解的问题之一，拥有 \$1 亿美元的 Clay Millennium 奖励。

- 大多数专家认为 $P \neq NP$，意味着某些问题本质上比验证它们要难得多。如果 $P = NP$，加密会崩溃（破解加密是 NP 类问题），优化、调度和药物设计也会变得 trivial易行。

- NP完全问题是最难的NP问题。一个问题是NP完全问题，如果：（1）它在NP中，（2）任何其他NP问题都可以通过多项式时间转换为它。如果你能高效地解决任何一个NP完全问题，你就能解决所有这些问题（和$P = NP$）。

- **简化**将一个问题转换为另一个问题。如果问题A可以简化为问题B，则问题B至少与问题A一样难。Cook（1971）证明了**SAT**（布尔可满足性：给定一个逻辑公式，是否存在一种变量赋值使其为真？）是NP完全的。Karp（1972）证明了21个经典问题都是NP完全的，通过将SAT简化为每个问题。

- 一些著名的NP完全问题：
    - **旅行商问题（TSP）**：找到访问所有城市恰好一次的最短路线。
    - **图着色**：用$k$种颜色给节点染色，使得相邻节点不能同色（$k \geq 3$）。
    - **子集和**：给定一个整数集合，是否存在一个子集其和等于目标值？
    - **布尔可满足性（SAT）**：逻辑公式是否有满足的真假赋值？
    - **哈密顿路径**（在图论中提到过）。

- 当你在实践中遇到NP完全问题时，你不会对大型输入进行精确求解。相反，你会使用：**近似算法**（找到一个最优解的保证因子内的解决方案），**启发式方法**（贪心、局部搜索、模拟退火等），或**特殊情况解法器**（许多NP完全问题在受限输入下容易解决）。例如，现代SAT求解器，比如那些能够处理数百万变量的实例，尽管其最坏复杂度为指数级，但通过利用实际实例中的结构，它们仍然能高效地解决问题。

- NP-hard问题至少与NP完全一样困难，但不一定属于NP（它们的解可能甚至不能在多项式时间内验证）。NP完全问题的优化版本通常是NP-hard：例如，“找到最短TSP路径”是NP-hard的，而“是否存在一个比$k$更短的TSP路径？”是NP-complete的。

1. 构建一个真值表生成器。给定一个逻辑表达式，枚举所有输入组合并计算输出。
```python
import itertools

def truth_table(n_vars, expr_fn):
    """Generate truth table for a boolean function of n_vars variables."""
    headers = [f"p{i}" for i in range(n_vars)]
    print(" | ".join(headers + ["result"]))
    print("-" * (len(headers) * 4 + 10))
    for vals in itertools.product([False, True], repeat=n_vars):
        result = expr_fn(*vals)
        row = [str(v)[0] for v in vals] + [str(result)[0]]
        print(" | ".join(f"{r:>2}" for r in row))

# De Morgan's law: NOT(p AND q) == (NOT p) OR (NOT q)
print("De Morgan's Law verification:")
truth_table(2, lambda p, q: (not (p and q)) == ((not p) or (not q)))
```

3. 使用 Master 定理解决归并排序的递推关系，并通过计数操作 empirically验证。
```python
import jax.numpy as jnp

def merge_sort_ops(n):
    """Count comparisons in merge sort (recurrence: T(n) = 2T(n/2) + n)."""
    if n <= 1:
        return 0
    half = n // 2
    return merge_sort_ops(half) + merge_sort_ops(n - half) + n

for n in [8, 64, 512, 4096, 32768]:
    ops = merge_sort_ops(n)
    predicted = n * jnp.log2(n)
    ratio = ops / predicted
    print(f"n={n:5d}  ops={ops:>10d}  n log n={int(predicted):>10d}  ratio={ratio:.3f}")
```
