# 度量与范数

*范数衡量向量的大小，度量衡量两个向量之间的距离。本文件介绍 $L_1$、$L_2$ 和 $L_\infty$ 范数、欧几里得距离、曼哈顿距离与汉明距离，以及这些选择如何影响机器学习中的 kNN、聚类和检索。*

**编者注：**原文简介还提到余弦距离，但正文没有介绍。

- 向量有大小和方向。范数可以量化单个向量的大小，度量可以量化两个向量之间的距离。

- 对于标量，我们可以直接比较 $10 > 5$。向量没有单一的大小数值，范数提供了这种量化方式。

- 最熟悉的范数是欧几里得范数（L2），它就是前面介绍的模：

$$\|\mathbf{v}\|_2 = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$$
- 但还有其他方式来测量大小。想象你在一个只有街道和建筑物的城市中。你不能通过建筑穿过街道，所以你的旅程的“长度”是沿着每条街道走的总块数。这是曼哈顿范数（L1）：

$$\|\mathbf{v}\|_1 = |v_1| + |v_2| + \cdots + |v_n|$$
- 有时只需关注绝对值最大的分量，忽略其他分量。这就是最大范数（L∞）：

$$\|\mathbf{v}\|_\infty = \max(|v_1|, |v_2|, \ldots, |v_n|)$$
- 对 $p \geq 1$，一般 $L_p$ 范数定义为：

$$\|\mathbf{v}\|_p = (|v_1|^p + |v_2|^p + \cdots + |v_n|^p)^{1/p}$$
- 取 $p = 2$ 得到欧几里得范数，取 $p = 1$ 得到曼哈顿范数；当 $p \to \infty$ 时得到最大范数。随着 $p$ 增大，最大分量的影响越来越大。

- 每个范数都必须满足三条性质：

    - **非负性**： $\|\mathbf{v}\| \geq 0$，且 $\|\mathbf{v}\| = 0$ 只有在 $\mathbf{v} = \mathbf{0}$ 时。大小永远不会为负，只有零向量的大小为零。

    - **绝对齐次性**： $\|c\mathbf{v}\| = |c| \cdot \|\mathbf{v}\|$。将向量加倍，其大小也加倍。

    - **三角不等式**：$\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$。直达路径不会比绕路更长。

- **度量**用于测量两个向量之间的距离，也就是回答“这两个点相距多远”。

- 由范数构造度量的最简单方法，是对两个向量的差取范数：$d(\mathbf{u}, \mathbf{v}) = \|\mathbf{u} - \mathbf{v}\|$。从一个向量中减去另一个向量，然后测量剩余部分的大小。

- 使用欧几里得范数，我们得到了熟悉的 **欧几里得距离**：

$$d(\mathbf{u}, \mathbf{v}) = \sqrt{(u_1 - v_1)^2 + (u_2 - v_2)^2 + \cdots + (u_n - v_n)^2}$$
- 使用曼哈顿范数则得到 **曼哈顿距离**，即沿每个轴的总差值，类似于两个地点之间计数城市街区的距离。

- 每个度量都必须满足四条性质：

    - **非负性**：$d(\mathbf{u}, \mathbf{v}) \geq 0$。距离不会为负。

    - **同一性**：$d(\mathbf{u}, \mathbf{v}) = 0$ 当且仅当 $\mathbf{u} = \mathbf{v}$。零距离表示同一个点。

    - **对称性**：$d(\mathbf{u}, \mathbf{v}) = d(\mathbf{v}, \mathbf{u})$。从 A 到 B 的距离等于从 B 到 A 的距离。

    - **三角不等式**：$d(\mathbf{u}, \mathbf{w}) \leq d(\mathbf{u}, \mathbf{v}) + d(\mathbf{v}, \mathbf{w})$。直达路径不会比绕路更长。

- 范数衡量一个向量，度量衡量两个向量之间的差异。每个范数都能通过测量差向量来构造一个度量，但并非每个度量都来自范数。

- 例如，**汉明距离**统计两个二进制向量中对应分量不同的位置数。它满足度量的性质；对二进制向量而言，汉明距离等于差向量的 $L_1$ 范数。**编者注：**原文称汉明距离不能由任何范数导出，这对二进制向量并不成立。

- 在机器学习中，范数和度量的选择会改变相似度、聚类结果和检索结果。

- $L_2$ 距离先将各维差值平方后求和，再开方。平方会放大较大的差值，因此单个大差异可能主导结果。

- $L_1$ 距离对各维绝对差求和，各维权重相同；相比 $L_2$，它不会因平方而额外放大大差值的影响。

## 编程任务（使用 Colab 或笔记本）

1. 计算向量的 L1 和 L2 范数。尝试改变数值，比较两种范数对较大分量和多个较小分量的响应。再计算不同 $p$ 值（例如 1、2、5、10、50、100）下的 $L_p$ 范数，观察它如何逐渐接近 $L_\infty$ 范数。
```python
import jax.numpy as jnp

v = jnp.array([3.0, -4.0, 1.0])

l1 = jnp.sum(jnp.abs(v))
l2 = jnp.sqrt(jnp.sum(v ** 2))

print(f"L1: {l1}, L2: {l2:.2f}")
```

2. 计算两个向量的欧几里得距离和曼哈顿距离。尝试改变向量间的距离，观察这两种度量的变化有何不同。
```python
import jax.numpy as jnp

u = jnp.array([1.0, 2.0, 3.0])
v = jnp.array([4.0, 0.0, 1.0])

euclidean = jnp.sqrt(jnp.sum((u - v) ** 2))
manhattan = jnp.sum(jnp.abs(u - v))

print(f"Euclidean: {euclidean:.2f}, Manhattan: {manhattan}")
```
