# 度量与范数

*范数衡量向量的大小，度量衡量两个向量之间的距离。本篇介绍 L1、L2 和 L-无穷范数、欧氏距离与余弦距离，以及为什么选择正确的距离函数对机器学习中的 kNN、聚类和检索至关重要。*

- 我们知道向量有大小和方向。但怎样实际衡量一个向量“有多大”，或两个向量“相距多远”？这正是**范数**和**度量**发挥作用的地方。

- 对标量来说，我们知道 $10 > 5$，因为它们的数值可以量化它们；但怎样量化向量？答案是**范数**：它衡量单个向量的大小。

- 最熟悉的范数是**欧氏范数**（L2），也就是我们已经知道的大小公式：

$$\|\mathbf{v}\|_2 = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2}$$

- 当然也可以用其他方式衡量大小。想象你在街道呈网格状的城市中行走，不能穿过建筑物斜着走，因此旅程的“长度”就是沿每条街走过的街区总数。这就是**曼哈顿范数**（L1）：

$$\|\mathbf{v}\|_1 = |v_1| + |v_2| + \cdots + |v_n|$$

- 或者你可能只关心最大的单个分量，忽略其余分量。这就是**最大范数**（L-无穷）：

$$\|\mathbf{v}\|_\infty = \max(|v_1|, |v_2|, \ldots, |v_n|)$$

- 这三种范数都是**一般 Lp 范数**的特殊情形：

$$\|\mathbf{v}\|_p = (|v_1|^p + |v_2|^p + \cdots + |v_n|^p)^{1/p}$$

- 令 $p = 2$ 得到欧氏范数，$p = 1$ 得到曼哈顿范数，而当 $p \to \infty$ 时得到最大范数。随着 $p$ 增大，最大分量的贡献越来越大，最终只剩它起作用。

- 每个范数都必须遵守三条规则：

    - **非负性**：$\|\mathbf{v}\| \geq 0$，且只有当 $\mathbf{v} = \mathbf{0}$ 时才有 $\|\mathbf{v}\| = 0$。大小不会为负，只有零向量的大小为零。

    - **缩放**：$\|c\mathbf{v}\| = |c| \cdot \|\mathbf{v}\|$。向量加倍，大小也加倍。

    - **三角不等式**：$\|\mathbf{u} + \mathbf{v}\| \leq \|\mathbf{u}\| + \|\mathbf{v}\|$。走捷径不会比绕远路更长。

- 现在看**度量**：它衡量的是两个向量*之间*的距离。也就是在问：“这两个点相距多远？”

- 获得度量的最简单方法，是对差向量使用范数：$d(\mathbf{u}, \mathbf{v}) = \|\mathbf{u} - \mathbf{v}\|$。先减去两个向量，再衡量剩下部分的大小。

- 使用欧氏范数便得到熟悉的**欧氏距离**：

$$d(\mathbf{u}, \mathbf{v}) = \sqrt{(u_1 - v_1)^2 + (u_2 - v_2)^2 + \cdots + (u_n - v_n)^2}$$

- 使用曼哈顿范数得到**曼哈顿距离**：沿每条轴的差异之和，就像计算城市中两个地点之间的街区数。

- 每个度量都必须遵守四条规则：

    - **非负性**：$d(\mathbf{u}, \mathbf{v}) \geq 0$。距离不会为负。

    - **同一性**：当且仅当 $\mathbf{u} = \mathbf{v}$ 时，$d(\mathbf{u}, \mathbf{v}) = 0$。距离为零意味着是同一个点。

    - **对称性**：$d(\mathbf{u}, \mathbf{v}) = d(\mathbf{v}, \mathbf{u})$。从 A 到 B 的距离与从 B 到 A 的距离相同。

    - **三角不等式**：$d(\mathbf{u}, \mathbf{w}) \leq d(\mathbf{u}, \mathbf{v}) + d(\mathbf{v}, \mathbf{w})$。直达不会比绕道更长。

- 那么二者有什么关系？范数衡量一个向量，度量衡量两个向量之间的间隔。每个范数都能自然地产生一个度量（衡量差向量的大小），但并非每个度量都来自某个范数。

- 例如，**汉明距离**计算两个向量中取值不同的位置数。它是合法的度量，但不是由任何范数产生的。

- 在机器学习中，选择合适的范数或度量很重要。

- L2 距离会先将每个差值平方再求和，因此一个很大的差值会主导结果。

- L1 距离将绝对差值相加，对每个差值一视同仁。与 L2 相比，一个很大的差值对它的影响较小。

## 编程任务（使用 Colab 或 notebook）

1. 计算同一个向量的 L1 和 L2 范数。尝试改变数值，观察哪种范数对大分量与许多小分量更敏感。然后计算不断增大的 $p$（例如 1、2、5、10、50、100）对应的 Lp 范数，观察它逐渐收敛到 L-无穷范数的值。
```python
import jax.numpy as jnp

v = jnp.array([3.0, -4.0, 1.0])

l1 = jnp.sum(jnp.abs(v))
l2 = jnp.sqrt(jnp.sum(v ** 2))

print(f"L1: {l1}, L2: {l2:.2f}")
```

2. 计算两个向量之间的欧氏距离和曼哈顿距离。尝试让向量更接近或更远，观察两种距离的响应有何不同。
```python
import jax.numpy as jnp

u = jnp.array([1.0, 2.0, 3.0])
v = jnp.array([4.0, 0.0, 1.0])

euclidean = jnp.sqrt(jnp.sum((u - v) ** 2))
manhattan = jnp.sum(jnp.abs(u - v))

print(f"Euclidean: {euclidean:.2f}, Manhattan: {manhattan}")
```
