# 向量性质

*向量性质描述决定向量行为的几何和代数特征。本文件涵盖模、方向、单位向量、相等性、平行性、正交性和线性独立性，这些概念构成机器学习特征空间的基础。*

- **模**（或长度）表示向量从起点延伸出的距离，可以把它想成箭头的长度。对于向量 $\mathbf{a} = (a_1, a_2, a_3)$，其模为：

$$\|\mathbf{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$
- 这是勾股定理在高维空间中的推广，表示从原点到该点的直线距离。

- **方向**表示向量指向哪里，可以把它想成从原点连接到该坐标点的直线。

- 如果没有明确指定原点，尤其在可视化中，通常默认原点为 $(0,0,\ldots,0)$。

- 向量表示位移，与绘制位置无关：从原点绘制的 $(3, 2)$ 向量和从其他点绘制的同一向量仍然相等。

![向量相等：从两个不同起始点绘制的相同（3,2）向量](../images/vector_equality.svg)


- 两个向量可以具有相同的长度但指向完全不同的方向，或者指向相同的方向但长度不同。

![同方向、不同大小（v 和 2v），以及同大小、不同方向](../images/magnitude_direction.svg)


- 两个向量如果且仅当它们的对应分量匹配时才相等；同样长度、相同方向，即完全相同的箭头。

$$\mathbf{a} = \mathbf{b} \iff a_i = b_i \text{ 对所有 } i$$
- 如果一个向量是另一个向量的标量倍数，两个向量就平行。它们位于同一条直线上，方向相同或相反。

$$\mathbf{a} \parallel \mathbf{b} \iff \mathbf{a} = k\mathbf{b} \text{，其中 } k \neq 0 \text{ 为某个标量}$$
![平行向量：a和b指向相同方向，a和-b指向相反方向](../images/parallel_vectors.svg)


- 如果 $k > 0$，它们指向相同的方向。如果 $k < 0$，它们指向相反的方向。无论哪种方式，它们都通过原点位于同一条直线上。

- 从直观上讲，平行向量不提供新的方向信息；一个只是另一个的拉伸或翻转版本。

- 两个向量若相互垂直，就称为**正交**。沿一个向量移动，在另一个向量方向上的投影为零。机器学习中会用到正交性。

![正交向量：u和v在直角处相交](../images/orthogonal_vectors.svg)


- 向北和向东是正交方向：向北走多远都不会增加向东的位移。

- 在机器学习中，正交特征有助于减少表示中的冗余。**编者注：**正交（内积为零）本身不能推出统计独立。

- 任意两个非零向量之间都有夹角 $\theta$，范围为 $0°$ 到 $180°$。**编者注：**零向量没有方向，因此与零向量的夹角无定义。

- 这个角度描述了两个方向的关系：$0°$ 表示同向平行，$180°$ 表示反向平行，$90°$ 表示正交，其余角度介于这些情况之间。

- 许多机器学习中的向量关系都落在这个范围内；后续会用点积和余弦相似度计算夹角。

- 如果集合中的某个向量可以由其他向量经过缩放和相加得到，这组向量就**线性相关**。这个向量没有为集合提供新的信息。

- 例如，若 $\mathbf{c} = 2\mathbf{a} + 3\mathbf{b}$，那么 $\mathbf{c}$ 是冗余向量；关于它的信息已经包含在 $\mathbf{a}$ 和 $\mathbf{b}$ 中。

- 平行向量总是线性相关的，因为一个只是另一个的缩放副本。包含零向量的任何集合也都是线性相关的。

- 若向量组中没有一个向量能由其余向量线性表示，这组向量就**线性无关**。每个向量都带来新的方向信息。若一组向量两两正交且均非零，它们就线性无关。**编者注：**原文省略了非零条件；含零向量的正交组不一定线性无关。

- 把人表示成向量时，如果某类样本被过度采样，统计结果可能偏向这类样本。设计训练 AI 的数据集时，要考虑样本分布。**编者注：**原文把线性相关与过度采样联系起来；线性相关本身不能说明样本被过度采样。

- 在二维中，两个线性独立的向量可以到达平面上的任何点。在三维中，你需要三个。这个关于“需要多少个独立向量”的想法直接与维度相关联。

- 当向量的大多数分量为零时，它是**稀疏**的；大多数分量非零时，它是**稠密**的。

$$\mathbf{s} = [0, 0, 3, 0, 0, 0, 1, 0, 0, 0]$$
- 稀疏性对存储和计算都有影响。稀疏向量可以通过只跟踪非零分量来更高效地存储和处理。

- **单位向量**的模长为 1，只表示方向，不保留长度信息。非零向量除以其模长后，就得到单位向量。**编者注：**零向量不能归一化。

$$\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|}$$
- 这个过程称为**归一化**：它去除长度信息，只保留方向信息。

- 标准单位向量沿着每个轴指向：$\hat{\mathbf{i}} = (1, 0, 0)$，$\hat{\mathbf{j}} = (0, 1, 0)$，$\hat{\mathbf{k}} = (0, 0, 1)$。任何向量都可以用这些向量的线性组合表示，例如 $(3, 2, 4) = 3\hat{\mathbf{i}} + 2\hat{\mathbf{j}} + 4\hat{\mathbf{k}}$.

## 编程任务（使用 Colab 或笔记本）

1. 计算向量的模，并验证结果是否符合勾股定理，然后修改代码来计算单位向量。
```python
import jax.numpy as jnp

a = jnp.array([3.0, 4.0])

magnitude = jnp.sqrt(jnp.sum(a ** 2))
print(f"Magnitude of a: {magnitude}")
```

2. 检查两个向量是否平行，通过测试其中一个是否是另一个的标量倍数来实现。
```python
import jax.numpy as jnp

a = jnp.array([2, 4, 6])
b = jnp.array([1, 2, 3])

ratios = a / b
print(f"Ratios: {ratios}")
print(f"Parallel: {jnp.allclose(ratios, ratios[0])}")
```
