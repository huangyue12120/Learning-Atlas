# MDP、状态、动作与奖励

> 马尔可夫决策过程由五项内容组成：状态、动作、转移、奖励和折扣。强化学习中的一切，包括 Q-learning、PPO、DPO、GRPO，都在这种结构上进行优化。掌握一次，就能读懂后续强化学习内容。

**类型：** 学习  
**学习实现：** Python  
**前置课程：** Phase 1 第 06 课（概率与分布）、Phase 2 第 01 课（机器学习分类）  
**预计时间：** 约 45 分钟

## 问题

你可能正在编写国际象棋机器人、库存规划器、交易智能体，或者训练推理模型的 PPO 循环。这四个领域截然不同，却有一项出人意料的共同点：它们都能化为同一个数学对象。

监督学习提供 `(x, y)` 对，要求你拟合函数。强化学习不提供标签，只提供状态流、你采取的动作和一个标量奖励。这个棋步赢得比赛了吗？补货决策省钱了吗？交易盈利了吗？大语言模型刚输出的词元是否从评审处获得了更高奖励？

在形式化之前，你无法从这条数据流中学习。“我看到了什么”“我做了什么”“接下来发生了什么”“结果有多好”，每一项都必须变成可以推理的对象。这套形式化就是马尔可夫决策过程。本阶段的每种强化学习算法，包括末尾的 RLHF 与 GRPO 循环，都在这种结构上进行优化。

## 概念

![马尔可夫决策过程：状态、动作、转移、奖励、折扣](../assets/mdp.svg)

**五个对象。**

- **状态** `S`。智能体决策所需的一切信息。在 GridWorld 中是格子；在国际象棋中是棋盘；在大语言模型中是上下文窗口和所有记忆。
- **动作** `A`。可以做出的选择。向上 / 下 / 左 / 右移动，走一步棋，输出一个词元。
- **转移** `P(s' | s, a)`。给定状态 `s` 与动作 `a`，下一状态的分布。国际象棋中的转移是确定性的；库存场景中的转移是随机的；大语言模型解码中的转移近乎确定。
- **奖励** `R(s, a, s')`。标量信号。胜利 = +1，失败 = -1；收入减成本；GRPO 中的对数似然比项。
- **折扣** `γ ∈ [0, 1)`。未来奖励相对于当前奖励的权重。`γ = 0.99` 对应约 100 步的视野；`γ = 0.9` 对应约 10 步。

**马尔可夫性质** 为 `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`。未来只依赖当前状态。如果这一点不成立，说明状态表示不完整，而不是方法失效。

**策略与回报。** 策略 `π(a | s)` 把状态映射为动作分布。回报 `G_t = r_t + γ r_{t+1} + γ² r_{t+2} + …` 是未来奖励的折扣和。状态价值 `V^π(s) = E[G_t | s_t = s]` 表示从 `s` 开始遵循策略 `π` 的期望回报。动作价值 `Q^π(s, a) = E[G_t | s_t = s, a_t = a]` 表示先执行指定动作再继续时的期望回报。每种强化学习算法都会估计二者之一，再据此改进 `π`。

**Bellman 方程。** 本阶段所有内容都会使用以下不动点方程：

`V^π(s) = Σ_a π(a|s) Σ_{s', r} P(s', r | s, a) [r + γ V^π(s')]`  
`Q^π(s, a) = Σ_{s', r} P(s', r | s, a) [r + γ Σ_{a'} π(a'|s') Q^π(s', a')]`

它们把期望回报拆成“本步奖励”与“落点的折扣价值”，具有递归形式。Phase 9 中的每种算法都会选择一种处理方式：迭代该方程直到收敛（动态规划）、从中采样（蒙特卡洛），或者只自举一步（时序差分）。

## 动手构建

### 第 1 步：微型确定性 MDP

创建一个 4×4 GridWorld。智能体从左上角出发，右下角为终止状态；每步奖励为 -1；动作集合为 `{上, 下, 左, 右}`。参见 `code/main.py`。

```python
GRID = 4
TERMINAL = (3, 3)
ACTIONS = {"up": (-1, 0), "down": (1, 0), "left": (0, -1), "right": (0, 1)}

def step(state, action):
    if state == TERMINAL:
        return state, 0.0, True
    dr, dc = ACTIONS[action]
    r, c = state
    nr = min(max(r + dr, 0), GRID - 1)
    nc = min(max(c + dc, 0), GRID - 1)
    return (nr, nc), -1.0, (nr, nc) == TERMINAL
```

五行代码就是整个环境：确定性转移、固定步惩罚、吸收终止状态。

### 第 2 步：按策略展开轨迹

策略是从状态到动作分布的函数。最简单的策略是均匀随机。

```python
def uniform_policy(state):
    return {a: 0.25 for a in ACTIONS}

def rollout(policy, max_steps=200):
    s, total, steps = (0, 0), 0.0, 0
    for _ in range(max_steps):
        a = sample(policy(s))
        s, r, done = step(s, a)
        total += r
        steps += 1
        if done:
            break
    return total, steps
```

运行随机策略 1000 次。在这个 4×4 棋盘上，平均回报约为 -60 到 -80。最优回报为 -6，也就是向下、向右走直线路径。Phase 9 的全部内容都在缩小这项差距。

### 第 3 步：通过 Bellman 方程精确计算 `V^π`

对于小型 MDP，Bellman 方程是一组线性方程。枚举状态、计算期望并反复迭代，直到价值停止变化。

```python
def policy_evaluation(policy, gamma=0.99, tol=1e-6):
    V = {s: 0.0 for s in all_states()}
    while True:
        delta = 0.0
        for s in all_states():
            if s == TERMINAL:
                continue
            v = 0.0
            for a, pi_a in policy(s).items():
                s_next, r, _ = step(s, a)
                v += pi_a * (r + gamma * V[s_next])
            delta = max(delta, abs(v - V[s]))
            V[s] = v
        if delta < tol:
            return V
```

这种方法称为迭代式策略评估。它是 Sutton 与 Barto 教科书中的第一个算法，也是后续每种强化学习方法的理论基础。

### 第 4 步：`γ` 是具有物理含义的超参数

有效视野约为 `1 / (1 - γ)`。`γ = 0.9` → 10 步，`γ = 0.99` → 100 步，`γ = 0.999` → 1000 步。

取值太低，智能体会目光短浅；取值太高，信用分配会充满噪声，因为许多早期步骤都要为很远的未来奖励共同负责。大语言模型 RLHF 通常使用 `γ = 1`，因为回合短且有界。控制任务使用 `0.95–0.99`。长视野策略游戏使用 `0.999`。

## 常见问题

- **非马尔可夫状态。** 如果必须结合最近三次观测才能决策，“状态”就不能只包含当前观测。解决方法：堆叠帧（Atari DQN 堆叠 4 帧），或使用循环状态（在观测上运行 LSTM/GRU）。
- **稀疏奖励。** 在巨大状态空间中，只提供胜利奖励会让学习近乎不可能。可以塑造奖励（提供中间信号），或先使用模仿学习进行自举（Phase 9 第 09 课）。
- **奖励投机。** 优化代理奖励经常产生病态行为。OpenAI 的赛艇智能体没有完成比赛，而是原地绕圈，永远收集加速道具。应根据目标结果定义奖励，不能根据代理量定义。
- **折扣设定错误。** 在无限视野任务中使用 `γ = 1`，会让所有价值变成无穷。必须设置有限视野或使用 `γ < 1`。
- **奖励尺度。** 奖励 `{+100, -100}` 与 `{+1, -1}` 产生相同最优策略，但梯度大小截然不同。送入 PPO/DQN 前，应归一化到大致 `[-1, 1]`。

## 使用方法

2026 年的每条强化学习流水线都应先化为 MDP，再编写代码：

| 情形 | 状态 | 动作 | 奖励 | γ |
|------|------|------|------|---|
| 控制（运动、操纵） | 关节角 + 速度 | 连续力矩 | 任务专用塑形奖励 | 0.99 |
| 游戏（国际象棋、围棋、扑克） | 棋盘 + 历史 | 合法着法 | 胜=+1 / 负=-1 | 1.0（有限） |
| 库存 / 定价 | 库存 + 需求 | 订购数量 | 收入 - 成本 | 0.95 |
| 大语言模型 RLHF | 上下文词元 | 下一词元 | 末尾的奖励模型分数 | 1.0（回合约 200 个词元） |
| 推理 GRPO | 提示词 + 部分回答 | 下一词元 | 末尾的验证器 0/1 | 1.0 |

编写训练循环之前，先写出这五元组。多数“强化学习不起作用”的缺陷报告，最终都能追溯到纸面上已经破损的 MDP 表述。

## 练习

1. **简单。** 在 `code/main.py` 中实现 4×4 GridWorld 和随机策略展开。运行 10,000 个回合，报告回报的均值与标准差，并与最优回报（-6）比较。
2. **中等。** 对均匀随机策略分别使用 `γ ∈ {0.5, 0.9, 0.99}` 运行 `policy_evaluation`。把每个 `V` 打印为 4×4 网格。解释 `γ` 增大时，终止状态附近的状态价值为何增长得更快。
3. **困难。** 把 GridWorld 改为随机环境：每个动作以概率 `p = 0.1` 滑向相邻方向。重新评估均匀策略。`V[start]` 变好还是变差？为什么？

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| MDP | “强化学习设置” | 满足马尔可夫性质的五元组 `(S, A, P, R, γ)`。 |
| 状态 | “智能体看到的内容” | 在选定策略类别下，足以描述未来动态的统计量。 |
| 策略 | “智能体行为” | 条件分布 `π(a \| s)` 或确定性映射 `s → a`。 |
| 回报 | “总奖励” | 从当前步骤开始的折扣和 `Σ γ^t r_t`。 |
| 状态价值 | “一个状态有多好” | 从 `s` 开始遵循 `π` 的期望回报。 |
| 动作价值 | “一个动作有多好” | 从 `s` 开始先执行 `a`、再遵循 `π` 的期望回报。 |
| Bellman 方程 | “动态规划递归” | 把价值 / Q 分解为一步奖励与折扣后继价值的不动点。 |
| 折扣 `γ` | “未来与现在” | 对远期奖励施加的几何权重；有效视野约为 `1/(1-γ)`。 |
