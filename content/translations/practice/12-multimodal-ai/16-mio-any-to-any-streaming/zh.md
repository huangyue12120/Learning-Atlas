# MIO 与任意到任意的流式多模态模型

> GPT-4o 发布了一种大多数开放模型无法复刻的产品：一个能听到语音、看到视频并实时回应的智能体。到 2024 年末，开放生态给出的答案是 MIO（Wang 等，2024 年 9 月）。MIO 将文本、图像、语音和音乐分词，在交错序列上训练一个因果 Transformer，并生成任意模态到任意模态的输出。AnyGPT（Zhan 等，2024 年 2 月）是概念验证；MIO 是规模化版本；Unified-IO 2（Allen AI，2023 年 12 月）是加入视觉 + 动作定位的近亲。本课阅读任意到任意模式——四个分词器、一个 Transformer、适合流式解码。

**类型：** 学习
**语言：** Python（标准库，四模态词元分配器 + 流式解码循环）
**前置课程：** Phase 12 · 11（Chameleon）、Phase 6（语音与音频）
**预计时间：** 约 120 分钟

## 学习目标

- 设计一个共享词汇，在避免冲突的情况下容纳文本、图像、语音和音乐词元。
- 从压缩与重建取舍方面比较 SEED-Tokenizer（图像）与 SpeechTokenizer 残差 VQ（语音）。
- 解释构建任意到任意生成能力的四阶段课程。
- 说出三个开放任意到任意方案及其主要取舍：MIO、AnyGPT、Unified-IO 2。

## 问题

声称一个统一多模态模型很容易，但要在规模上构建它很难。直到 2024 年，大多数“任意到任意”系统都是流水线：视觉模型 → 文本表示 → 语音模型 → 音频。每一次跳转都会丢失信息、增加延迟并使训练更复杂。GPT-4o 的演示视频展示了一个响应时间低于一秒的单模型替代方案，而开放系统落后了几个月。

工程挑战包括：

- 每种模态都必须有分词器，能够以足够接近无损的方式压缩以便重建，并以 Transformer 能够消费的速率产生词元。
- 单一词汇必须为文本（32k+）、图像（16k+）、语音（4k+）和音乐（8k+）分配空间，最低需要 4 万多个条目。
- 训练数据必须覆盖每一组输入—输出组合（文本→图像、图像→语音、语音→图像等），否则模型必须自行组合。
- 推理必须足够快地流式输出词元，才能达到对话延迟（首个音频字节时间 <500ms）。

## 概念

### 四种模态的四个分词器

MIO 的分词器堆栈：

- 文本：标准 BPE，词汇约 32000。
- 图像：SEED-Tokenizer（2023）——带离散码本的量化 VAE，每张图像有 4096 个条目、32x32 个词元。
- 语音：SpeechTokenizer 残差 VQ（2023）——将 16kHz 波形编码成 8 个层级码本；第一级是粗粒度内容，后续层加入韵律和说话人身份。
- 音乐：类似的残差 VQ（Meta 的 MusicGen / Encodec 家族），4–8 个码本。

每种模态都会产生整数词元。它们在共享词汇中使用互不重叠的 ID 范围：

```
text:   0..31999
image:  32000..36095  (4096 image tokens)
speech: 36096..40191  (4096 speech base tokens, plus residual layers)
music:  40192..48383  (8192 music tokens)
sep:    48384..48390  (<image>, <speech>, <music>, </...>, etc.)
```

总计约 48k 词汇。输入嵌入和输出投影覆盖全部词汇。

### 流式解码

语音生成使用残差 VQ。Transformer 预测基础层（第 0 层）的语音词元，随后由并行解码的残差量化器预测其他层。每个第 0 层词元大约对应 16kHz 音频的 50ms。

流式模式如下：

1. 用户对着麦克风说话，实时音频分词器每 50ms 产生语音词元。
2. MIO 在词元到达时消费它们（提示词预填充 + 增量前向）。
3. 输出词元生成后立即流出，并由并行语音解码器以约 50–150ms 延迟将它们转换为音频样本。
4. 首个音频字节时间：MIO 论文约为 300–500ms，接近 GPT-4o 的约 250ms。

Mini-Omni（arXiv:2408.16725）、GLM-4-Voice（arXiv:2412.02612）和 Moshi（arXiv:2410.00037）是互补的流式语音 LLM 设计。尤其是 Moshi，在单个 GPU 上达到了 160ms 往返延迟。

### 四阶段课程

MIO 的训练课程：

1. 第一阶段——对齐。大规模模态对语料：文本—图像、文本—语音、文本—音乐。每个对使用自己的词汇片段，训练共享词汇。
2. 第二阶段——交错。多模态交错文档（带图像 + 视频的博客、带转录的播客等），训练跨模态上下文。
3. 第三阶段——语音增强。额外的音频数据提升语音质量，同时不损失文本能力。
4. 第四阶段——SFT。跨模态指令微调：VQA、标题生成、旁白、语音到语音对话。

缺少一个阶段会损害特定能力：跳过第二阶段，模型会失去跨模态上下文；跳过第三阶段，语音质量会很差。

### 视觉思维链

MIO 引入了视觉思维链：模型将中间图像词元作为推理步骤输出。对于“猫在爬树吗？”，模型会：

1. 输出渲染场景的 `<image>` 词元（来自输入图像或一张草图）。
2. 输出分析草图的文本。
3. 输出最终答案。

渲染出的中间图像充当草稿纸。在空间推理任务上，基准成绩得到提升。这一想法对应文本推理中的思维链。

### 任意到任意的竞争者

- AnyGPT（arXiv:2402.12226）：4 种模态（文本、图像、语音、音乐），设计相似。
- Unified-IO 2（arXiv:2312.17172）：增加视觉动作输出、深度、法线。任务更多，规模更小。
- NExT-GPT（arXiv:2309.05519）：LLM + 模态特定扩散解码器，不是单模型方案。
- CoDi（arXiv:2305.11846）：可组合扩散，通过共享潜变量实现任意到任意。

MIO 最接近纯词元的任意到任意方案，AnyGPT 是它的概念祖先。

### 延迟预算

对于对话产品，每个组件的延迟都很重要：

- 麦克风到音频词元：约 50ms。
- 预填充（音频词元 + 历史）：8B 模型上约 100ms。
- 第一个输出词元：约 50ms。
- 并行残差 VQ + 语音解码器：约 100–150ms。

首个音频字节时间至少约 300ms。GPT-4o 声称约 250ms，Moshi 声称 160ms。MIO/AnyGPT 根据公开基准每次约为 400–600ms。

### 为什么任意到任意仍然困难

即使到了 2026 年，开放任意到任意模型仍然在两个轴上落后于闭源模型：

- 语音质量。残差 VQ 分词器是有损的；与 ElevenLabs 级别的声音相比，对话语音听起来像机器人。
- 跨模态推理。让模型“为你看到的内容唱一首歌”仍然比纯视觉任务更容易失败。

这些是开放研究问题。Qwen3-Omni（第 12.20 课）是 2025 年最先进的开放尝试。

## 练习

1. 你的产品接收语音输入并返回语音输出。端到端延迟预算目标是多少？列出消耗时间的组件。

2. SpeechTokenizer 残差 VQ 使用 8 个码本。说明为什么残差层必须并行解码（而不是顺序解码），以及这能节省多少延迟。

3. 词汇有 32k 文本 + 4k 图像 + 4k 语音。再加入 8k 音乐和约 10 个分隔符。在隐藏维度 4096 时，嵌入矩阵的参数成本是多少？

4. 视觉思维链会输出中间图像。哪些问题会受益？哪些问题会因额外词元而受损？

5. 阅读 Moshi（arXiv:2410.00037）。描述它的“内心独白”技巧，并与 MIO 的视觉思维链比较。

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| 任意到任意 | “多模态输入/输出” | 一个可以以任意方向接收和输出文本、图像、语音和音乐的单一模型 |
| 残差 VQ | “语音分词器堆栈” | 多码本分词，每一层增加信息；基础层是内容，后续层是韵律 |
| SEED-Tokenizer | “图像编码” | MIO 使用的、带 4096 条目码本的离散图像分词器 |
| 视觉思维链 | “视觉草稿纸” | 模型在最终回答之前生成中间图像作为推理步骤 |
| 首个音频字节时间 | “TTFAB” | 从用户语音到第一个音频输出的延迟；对对话体验应低于 500ms |
| 四阶段课程 | “训练方案” | 按顺序执行对齐 → 交错 → 语音增强 → SFT |
