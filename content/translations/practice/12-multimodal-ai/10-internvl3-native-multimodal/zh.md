# InternVL3：原生多模态预训练

> 在 InternVL3 之前，所有开放 VLM 都遵循同一个三步方案：取一个在数万亿文本词元上训练的文本 LLM，接上视觉编码器，再微调连接处。这种方法有效，但会积累对齐债务——文本 LLM 把完整的预训练预算都花在纯文本上，并不原生理解视觉词元。事后加入视觉能力时，LLM 必须重新学习如何把视觉输入与文本推理联系起来，同时还不能遗忘文本能力。InternVL3（Zhu 等，2025 年 4 月）拒绝事后拼接：从第一步开始就让文本和多模态内容交错，进行一次预训练。结果是，开放的 780 亿参数模型在 MMMU-Pro 上匹敌 Gemini 2.5 Pro。本课阅读原生预训练的理由，以及采用它之后会发生什么变化。

**类型：** 学习
**语言：** Python（标准库，训练语料混合器）
**前置课程：** Phase 12 · 05、Phase 12 · 07（方案）
**预计时间：** 约 120 分钟

## 学习目标

- 解释事后 VLM 训练为什么会积累对齐债务，并指出三个可测量的症状（灾难性遗忘、答案漂移、视觉—文本不一致）。
- 描述 InternVL3 的原生预训练语料混合，以及文本 : 交错 : 标题比例为什么重要。
- 比较 V2PE（可变视觉位置编码）与 Qwen2-VL 的 M-RoPE。
- 说出视觉分辨率路由器（ViR）和解耦视觉—语言（DvD）部署优化。

## 问题

事后 VLM 训练是默认做法。LLaVA、BLIP-2、Qwen-VL、Idefics——它们都取一个已经预训练好的 LLM（Llama、Vicuna、Qwen、Mistral），再增加视觉能力。训练阶段通常如下：

1. 冻结 LLM + 冻结视觉编码器 + 可训练投影器，在标题对上训练以对齐嵌入。
2. 解冻 LLM，在指令数据（LLaVA-Instruct、ShareGPT4V）上训练。
3. 可选的任务特定微调。

对齐债务会表现为三个症状：

- 灾难性遗忘。事后加入视觉的 VLM 会忘记文本能力。GSM8K 分数下降 5–10 个百分点，Hellaswag 分数下降，纯文本智能体退化。
- 答案漂移。对同一个视觉问题稍微改变措辞，就可能得到不同答案。视觉编码器与 LLM 的连接比 LLM 自身词元之间的绑定更弱。
- 视觉—文本不一致。VLM 可以正确描述一张图像，却回答出与自己描述矛盾的问题。视觉词元没有像文本词元那样参与 LLM 的内部一致性检查。

这些症状已经有充分记录。MM1.5 第 4 节对其进行了量化，LLaVA-OneVision 的消融也提示了它们。原生预训练就是答案。

## 概念 <!-- learning-atlas: the-concept -->

### 原生多模态预训练

InternVL3 从头开始，在一个从第一步起就原生多模态的语料上训练。配比如下：

- 40% 纯文本数据（FineWeb、Proof-Pile-2 等）。
- 35% 交错图像—文本数据（OBELICS、MMC4 风格）。
- 20% 配对图像—标题数据。
- 5% 视频—文本数据。

从第一次梯度更新开始，视觉词元、文本词元和跨模态交互都参与同一个损失。不需要对齐预训练，不需要冻结投影器的阶段，也不需要恢复灾难性遗忘。

基础模型只有一个训练阶段。之后仍进行指令微调，但基础模型已经把视觉词元理解为一等公民。

### V2PE（可变视觉位置编码）

Qwen2-VL 使用固定轴分配的 M-RoPE。InternVL3 引入 V2PE：位置编码随模态类型（文本、图像、视频）变化，并带有可学习缩放。实际表现为：

- 文本词元获得一维位置（文本索引）。
- 图像块获得二维位置（行、列）。
- 视频帧获得三维位置（时间、行、列）。

三种模态共享同一个 RoPE 频率基，但各分区的隐藏维度分配是可学习参数，而不是固定切分。预训练过程中可以在时间频率分辨率和空间频率分辨率之间自由权衡。

V2PE 的消融结论是：在算力相同的情况下，视频基准提升 1–2 个百分点。它不是革命，却更干净。

### 视觉分辨率路由器（ViR）

这是部署优化。并非所有图像都需要全分辨率编码。一张细节很少、只有一个物体的照片，如果以 1280px 原生分辨率编码，会浪费词元。ViR 是一个小型分类器，在编码之前预测回答问题所需的最低分辨率。

路由分为三个层级：低分辨率（256 个词元）、中分辨率（576 个词元）、高分辨率（2048+ 个词元）。生产流量中有 60% 的查询只需要低分辨率或中分辨率。净效果是在质量相同的情况下，吞吐量提高 2–3 倍。

### 解耦视觉—语言部署（DvD）

服务大型 VLM 时，视觉编码器每张图像运行一次，而 LLM 会为每个输出词元自回归运行。两部分的瓶颈不同（视觉侧是卷积 + 注意力的 GPU 内存带宽，LLM 侧是 KV 缓存）。DvD 将两者拆到不同 GPU 上，并在它们之间流式传输。

对于 8B + 400M 编码器模型，和放在同一处相比，DvD 大致可以让每节点吞吐量翻倍。

### 单阶段与多阶段质量

InternVL3 的主要基准声明是：78B 参数时匹敌 Gemini 2.5 Pro 的 MMMU-Pro，38B 时匹敌 GPT-4o，8B 时领先开放 8B 排行榜。全部使用单阶段预训练 + 指令微调方案。

对齐债务假说是可测量的：与 Qwen2.5-VL-7B 相比，InternVL3-8B 在视觉基准收益相同的情况下，损失的文本基准分数更少（MMLU、GSM8K）。因为训练是一个整体而不是两个阶段，这个模型更像通才。

### InternVL3.5 与 InternVL-U

InternVL3.5（2025 年 8 月）扩展了这套方案。原生预训练方法相同，数据更多，参数更多，MMMU 的提升是渐进的。

InternVL-U（2026）加入统一生成能力——在同一骨干之上增加 MMDiT 头来输出图像。“U”代表“理解 + 生成”，追赶 Transfusion 风格的统一模型（第 12.13 课）。同一个原生预训练骨干同时支持理解头和生成头。

### 原生预训练的取舍

原生预训练并不是免费的：

- 算力。从头训练一个新 VLM 的成本与训练文本 LLM 相同——数百万 GPU 小时。事后适配可以复用现有 LLM 权重，节省大部分成本。
- 数据。大规模交错图像—文本语料很少。OBELICS 有 1.41 亿份文档，MMC4 有 5.71 亿份；纯文本却有 15T 个词元。多模态预训练数据的稀缺是硬约束。
- 复用基础 LLM。原生预训练放弃了日后直接替换 LLM 的选项。事后方案可以把 Llama-3.1 换成 Llama-4，只重新训练适配器。

InternVL3 的押注是：对齐债务比复用损失更糟。基准支持这一说法，但生产成本会阻止未来的实验室轻易复制它。事后 VLM 仍会继续存在，因为对大多数项目来说，它们更便宜。

## 使用它

`code/main.py` 是训练语料混合器和 ViR 路由器模拟器。它会：

- 接收目标语料配比（%文本、%交错、%标题、%视频），计算每种模态预期的训练步数。
- 在一批查询上模拟 ViR 路由（分布：50% 低细节、30% 中等、20% 高细节），并报告平均词元数。
- 根据编码器与 LLM 的 FLOPs 报告 DvD 吞吐量估计。
- 并排打印事后预训练与原生预训练在参数、算力、数据和预期对齐债务症状上的比较。

## 练习

1. 估计 InternVL3-8B（原生预训练）与 LLaVA-OneVision-7B（事后方案）之间的算力差异。GPU 小时大约相差多少倍？差距由什么解释？

2. InternVL3 报告 40% 文本 / 35% 交错 / 20% 标题 / 5% 视频。如果目标任务偏重视频，提出一个新配比，并说明为什么基础模型仍需要大量文本和标题数据。

3. 阅读 MM1.5 第 4 节关于遗忘的内容。说出事后训练退化最大的确切基准，以及退化了多少。

4. ViR 将 60% 的流量路由到低分辨率编码。它会误路由哪些查询（本应需要高分辨率却被送到低分辨率）？提出三种路由器失败模式。

5. DvD 将视觉和 LLM 拆到不同 GPU 上。在什么流量模式下，DvD 会损害吞吐量而不是提升它？

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| 原生多模态预训练 | “从头一起训练” | 从第 1 步开始文本 + 图像 + 视频词元就参与损失，而不是事后拼接 |
| 对齐债务 | “事后代价” | 把视觉能力接到冻结 LLM 上导致的文本技能和答案一致性可测量退化 |
| V2PE | “可变视觉位置编码” | 按模态分配可学习位置编码；InternVL3 的 M-RoPE 后继方案 |
| ViR | “分辨率路由器” | 在编码前为每个查询选择所需的最低分辨率，以节省推理词元的小型分类器 |
| DvD | “解耦部署” | 视觉编码器在一个 GPU 上、LLM 在另一个 GPU 上运行，并通过流传递；对大型 VLM 可以使吞吐量翻倍 |
| InternVL-U | “统一理解 + 生成” | 2026 年的后续版本，在原生预训练骨干上增加图像生成头 |
| 交错语料 | “OBELICS / MMC4” | 按自然阅读顺序包含文本和图像的文档；原生预训练的原材料 |
