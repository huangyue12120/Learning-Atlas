# 开放权重 VLM 方案：真正重要的因素

> 2024–2026 年的开放权重 VLM 文献是一片由消融表组成的森林。Apple 的 MM1 测试了 13 种图像编码器、连接器和数据混合组合。Allen AI 的 Molmo 证明详细的人类标题胜过 GPT-4V 蒸馏。Cambrian-1 运行了 20 多种编码器比较。Idefics2 将五个轴的设计空间形式化。Prismatic VLMs 在受控基准上比较了 27 种训练方案。在所有这些噪声中，有一小组结果跨论文成立：图像编码器比连接器架构更重要，数据配比比前两者都重要，详细的人类标题胜过蒸馏的合成数据。本课阅读这些表格，让你不必亲自逐一阅读。

**类型：** 学习 + 实验
**语言：** Python（标准库，消融表解析器 + 方案选择器）
**前置课程：** Phase 12 · 05（LLaVA 基线）
**预计时间：** 约 180 分钟

## 学习目标

- 说出 VLM 的五轴设计空间：图像编码器、连接器、LLM、数据混合和分辨率计划。
- 阅读 MM1 / Idefics2 / Cambrian-1 的消融表，并预测哪个控制杆会改变给定基准测试的结果。
- 在给定计算预算和任务混合的情况下，为新 VLM 选择一套方案（编码器、连接器、数据、分辨率）。
- 解释在词元数量相同的情况下，详细的人类标题为什么胜过 GPT-4V 蒸馏。

## 问题

开放权重 VLM 已经有数百个。大多数“优秀”和“最先进”之间的差距并不来自架构，而来自数据、分辨率计划和编码器选择。当模型表现不佳时，知道先调哪个控制杆，可以避免一次耗费 500 万 GPU 小时的错误。

2023 年的浪潮（LLaVA-1.5、InstructBLIP、MiniGPT-4）运行的是标题对预训练 + LLaVA-Instruct-150k。它是一个很好的基线，但在 MMMU 上大约止步于 35%。

2024 年的浪潮（MM1、Idefics2、Molmo、Cambrian-1、Prismatic VLMs）运行了穷举式消融。结果既出人意料，又很实用。

## 概念

### 五轴设计空间

Idefics2（Laurençon 等，2024）命名了这些轴：

1. 图像编码器。CLIP ViT-L/14、SigLIP SO400m/14、DINOv2 ViT-g/14、InternViT-6B。编码器在图像块大小、分辨率和预训练目标上各不相同。
2. 连接器。MLP（2–4 层）、Q-Former（32 个查询 + 交叉注意力）、Perceiver 重采样器（64 个查询）、C-Abstractor（卷积 + 双线性池化）。
3. 语言模型。Llama-3 8B / 70B、Mistral 7B、Phi-3、Gemma-2、Qwen2.5。LLM 大小是主要的参数成本。
4. 训练数据。标题对（CC3M、LAION）、交错数据（OBELICS、MMC4）、指令数据（LLaVA-Instruct、ShareGPT4V、PixMo、Cauldron）。
5. 分辨率计划。固定 224/336/448、AnyRes、原生动态分辨率。训练期间逐步提升，或保持不变。

每个生产 VLM 都会在每个轴上做选择。MMMU 分数的大部分方差由第 1、4、5 轴解释，而不是由连接器的具体选择解释。

### 轴 1：编码器 > 连接器

MM1 第 3.2 节表明：从 CLIP ViT-L/14 换成 SigLIP SO400m/14，MMMU 提升了 3 个以上百分点；把连接器从 MLP 换成 Perceiver 重采样器，提升不到 1 个百分点。Idefics2 复现了这一结论：SigLIP > CLIP，在词元数相同的情况下，Q-Former ≈ MLP ≈ Perceiver。

Cambrian-1 的“Cambrian Vision Encoders Match-Up”（Tong 等，2024）在一个以视觉为中心的基准（CV-Bench）上运行了 20 多种编码器。排行榜顶部由 DINOv2 和 SigLIP 混合组成；CLIP 居中；ImageBind 和 ViT-MAE 更低。从 CLIP ViT-L 到 DINOv2 ViT-g/14，在 CV-Bench 上的差距约为 5–7 个百分点。

2026 年开放 VLM 的默认编码器是用于语义 + 稠密特征的 SigLIP 2 SO400m/14；如果需要分割/定位，有时会与 DINOv2 ViT-g/14 特征拼接（Cambrian 的“Spatial Vision Aggregator”就是这样做的）。

### 轴 2：连接器设计基本打平

MM1、Idefics2、Prismatic 和 MM-Interleaved 都得出了同一个结论：在视觉词元数量固定时，连接器架构几乎不重要。在相同词元预算下，图像块平均池化上的两层 MLP，表现与 32 查询的 Q-Former 相差不到 1 个百分点。

真正重要的是词元数量。更多视觉词元意味着更多 LLM 计算，性能会在某一点之前提升，随后收益递减。每张图像 64 个词元对于 OCR 太少；576–1024 个词元是大多数开放 VLM 的最佳区间；2048+ 只对文档和图表有帮助。

Q-Former 对比 MLP 是成本问题，而不是质量问题：无论图像分辨率如何，Q-Former 都把词元数限制在 32–64；MLP 则输出全部图像块词元。高分辨率输入下，Q-Former 节省 LLM 上下文；低分辨率下，差异只是噪声。

### 轴 3：LLM 大小决定上限

在每一篇 VLM 论文中，把 LLM 从 7B 加倍到 13B，都能可靠地让 MMMU 提升 2–4 个百分点。达到 70B 后，大多数基准会饱和。VLM 的多模态推理上限就是 LLM 的文本推理上限——视觉编码器只能把信息提供给它，不能替它进行推理。

这就是 Qwen2.5-VL-72B 和 Claude Opus 4.7 能在 MMMU-Pro 与 ScreenSpot-Pro 上大幅领先的原因：语言大脑很大。7B VLM 无法通过巧妙的连接器设计替代 70B VLM。

### 轴 4：数据——详细的人类标题胜过蒸馏

Molmo + PixMo（Deitke 等，2024）是所有人都应该阅读的 2024 年结果。Allen AI 让人类标注者用 1–3 分钟的密集语音转文本过程描述图像，得到 712k 张详细标题图像。训练数据中完全没有 GPT-4V 蒸馏。

Molmo-72B 在 11 个基准中的 11 个都超过了 Llama-3.2-90B-Vision。差距不在架构，而在标题质量。详细的人类标题每张图像包含的信息量是简短网络标题的 5–10 倍，而且在 GPT-4V 蒸馏产生幻觉的地方仍然保持事实根据。

ShareGPT4V（Chen 等，2023）和 Cauldron（Idefics2）沿用了混合人类 + GPT-4V 标题的做法。趋势很清楚：对于 2026 年的前沿模型，标题密度 > 标题数量 > 蒸馏便利性。

### 轴 5：分辨率及其计划

Idefics2 的消融结果：384 → 448 提升 1–2 个百分点；通过图像切分从 448 → 980，在 OCR 基准上再提升 3–5 个百分点。固定分辨率训练会在中等准确率处平台期；分辨率逐步提升（从 224 开始，最后到 448 或原生分辨率）训练更快、最终结果更高。

Cambrian-1 运行了分辨率与词元的权衡：在计算固定时，可以在低分辨率下使用更多词元，或在高分辨率下使用更少词元。更高分辨率对 OCR 更好；低分辨率 + 更多词元对一般场景理解更好。

2026 年的生产方案是：第一阶段使用固定 384 训练，第二阶段为 OCR 密集型任务使用最高 1280 的动态分辨率。

### Prismatic 受控比较

Prismatic VLMs（Karamcheti 等，2024）控制了所有轴。使用相同的 13B LLM、相同的指令数据、相同的评估，每次只改变一个轴。结果如下：

- 每张图像的视觉词元数量解释了约 60% 的方差。
- 编码器选择解释约 20%。
- 连接器架构解释约 5%。
- 其余所有因素（数据混合、调度器、学习率）解释剩余约 15%。

这是粗略的分解，但它是文献中对“我应该先消融什么”最清晰的回答。

### 2026 年的选择器

根据这些证据，2026 年新项目的默认开放 VLM 方案是：

- 编码器：原生分辨率、带 NaFlex 的 SigLIP 2 SO400m/14；如果需要分割/定位，则与 DINOv2 ViT-g/14 的稠密特征拼接。
- 连接器：在图像块词元上使用两层 MLP。除非受词元限制，否则跳过 Q-Former。
- LLM：Qwen2.5 / Llama-3.1 / Gemma 2；为了成本选择 7B，为了质量选择 70B，再根据目标延迟确定。
- 数据：PixMo + ShareGPT4V + Cauldron，再补充任务特定的指令数据。
- 分辨率：动态（长边最小 256、最大 1280 像素）。
- 计划：第一阶段对齐（仅投影器），第二阶段完整微调，第三阶段任务特定微调。

这些默认值中的每一个，都能追溯到本课末尾所引用论文中的实测消融。

## 使用它

`code/main.py` 是消融表解析器和方案选择器。它编码了 MM1 与 Idefics2 的消融表（压缩版），并允许你查询：

- “给定预算 X 和任务 Y，哪套方案胜出？”
- “如果在 7B Llama 上把 SigLIP 换成 CLIP，预期 MMMU 差值是多少？”
- “为了得到 80% 置信度的答案，我应该先消融哪个轴？”

输出是带有预期基准差值的方案排序列表，以及“先消融”建议。

## 交付成果

本课生成 `outputs/skill-vlm-recipe-picker.md`。给定目标任务混合、计算预算和延迟目标，它会输出完整方案（编码器、连接器、LLM、数据混合、分辨率计划），并为每项选择附上对应消融的引用。这样每次新的 VLM 项目开始时，工程师不必重新发明 Idefics2 的消融表。

## 练习

1. 阅读 MM1 第 3.2 节。在 50M 张图像、固定 2B LLM 的预算下，哪个编码器胜出？如果 LLM 是 13B，答案会反转吗？为什么？

2. Cambrian-1 发现，拼接 DINOv2 + SigLIP 在以视觉为中心的基准上超过任一单独编码器，但在 MMMU 上没有增加信号。预测哪些基准会提升，哪些会持平。

3. 你的目标是在 2B LLM 上运行移动 UI 智能体。选择编码器、连接器、分辨率和数据混合。用具体的消融表为每项选择辩护。

4. Molmo 发布了 4B 和 72B 模型。4B 能与闭源 7B VLM 竞争；72B 在 11/11 个基准上超过 Llama-3.2-90B-Vision。这说明了什么？它如何影响 LLM 大小平台期假说？

5. 设计一张消融表，在 7B VLM 上隔离数据混合质量与编码器质量。至少需要多少次训练运行？提出四组轴设置。

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| 消融 | “调一个控制杆” | 运行多次训练，每次只改变设计空间中的一个轴，其他因素保持不变 |
| 连接器 | “桥” / “投影器” | 将视觉编码器输出映射到 LLM 词元空间的可训练模块（MLP、Q-Former、Perceiver） |
| 详细人类标题 | “稠密标题” | 通常包含 80–300 个词元、比网络替代文本更丰富的多句人类描述 |
| 蒸馏 | “GPT-4V 标题” | 由更强的专有 VLM 生成的训练数据；方便，但容易继承幻觉 |
| AnyRes / 动态分辨率 | “高分辨率路径” | 通过平铺或 M-RoPE 输入大于编码器原生分辨率的图像的策略 |
| 分辨率递增 | “课程学习” | 从低分辨率开始并逐步提高的训练计划，可加速对齐学习 |
| 视觉中心基准 | “CV-Bench / BLINK” | 强调细粒度视觉感知，而不是语言密集型推理的评估 |
| PixMo | “Molmo 的数据” | Allen AI 的 712k 张详细标题图像数据集；人类语音转写为稠密标题 |
