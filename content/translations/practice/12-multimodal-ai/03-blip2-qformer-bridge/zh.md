# 从 CLIP 到 BLIP-2——Q-Former 作为模态桥

> CLIP 能对齐图像和文本，却不能生成标题、回答问题或进行对话。BLIP-2（Salesforce，2023）用一个小型可训练桥解决了这个问题：32 个可学习查询向量通过交叉注意力关注冻结 ViT 的特征，然后直接插入冻结 LLM 的输入流。这个 1.88 亿参数的桥把一个 110 亿参数 LLM 与 ViT-g/14 连接起来。到 2026 年，所有基于适配器的 VLM——MiniGPT-4、InstructBLIP、LLaVA 的同类模型——都是它的后代。本课阅读 Q-Former 的架构，解释它的两阶段训练，并构建一个把视觉词元送入冻结文本解码器的玩具版本。

**类型：** 构建
**语言：** Python（标准库，交叉注意力 + 可学习查询演示）
**前置课程：** Phase 12 · 02（CLIP）、Phase 7（Transformer）
**预计时间：** 约 180 分钟

## 学习目标

- 解释冻结视觉编码器与冻结 LLM 之间的可训练瓶颈为什么在成本和稳定性上优于端到端微调。
- 实现一个交叉注意力块，让固定的一组可学习查询关注外部图像特征。
- 走完 BLIP-2 的两阶段预训练：表示学习（ITC + ITM + ITG），再到生成学习（使用冻结解码器的 LM 损失）。
- 将 Q-Former 与 LLaVA 使用的更简单 MLP 投影器进行比较，并论证各自适用的场景。

## 问题

你有一个冻结的 ViT，它为每张图像产生 256 个、每个 1408 维的图像块词元。你还有一个冻结的 70 亿参数 LLM，它需要 4096 维的词元嵌入。显而易见的桥——从 1408 到 4096 的线性层——确实可行，但把全部 256 个图像块词元送入 LLM 上下文，会让每张图像额外消耗 256 个词元。对于一个包含 32 张图像的批量，仅视觉模态就消耗 8192 个词元。

BLIP-2 的问题是：能否把 256 词元的图像表示压缩成少得多的词元（例如 32 个），同时保留足够的信息，让 LLM 能够描述图像、回答问题并进行推理？能否在不触碰冻结骨干的情况下训练这座桥，把训练成本限制为桥自身的参数？

答案是 Q-Former。32 个可学习的“查询”向量通过交叉注意力关注 ViT 的图像块词元，产生一个由 32 个词元组成的视觉摘要供 LLM 使用。它总共有 1.88 亿个参数。在接触 LLM 之前，它先通过对比、匹配和生成目标进行训练。

## 概念

### 可学习查询

Q-Former 的核心技巧是：不要让 LLM 的文本词元去关注图像块，而是引入一组新的 32 个可学习查询向量 `Q`，让它们去关注图像块。查询是模型参数——它们在训练过程中学习，并且对每张图像都使用同一组 32 个查询。

交叉注意力之后，每个查询都保存了图像的压缩摘要——“描述主要物体”“描述背景”“数一数物体”等。查询并不会真正专门对应某个语义标签；它们会学习任何能让下游损失下降的编码方式。

### 架构

Q-Former 是一个小型 Transformer（12 层、约 1 亿参数），包含两条路径：

1. 查询路径：32 个查询向量先经过相互之间的自注意力，再对冻结 ViT 的图像块词元做交叉注意力，最后经过 FFN。
2. 文本路径：类似 BERT 的文本编码器与查询路径共享自注意力和 FFN 权重。文本路径禁用交叉注意力。

训练时两条路径都会运行。查询与文本通过共享的自注意力交互，因此查询可以针对需要文本条件的任务（ITM、ITG）进行条件化。用于 VLM 交接的推理阶段只让查询流动，输出 32 个视觉词元。

### 两阶段训练

BLIP-2 分两个阶段预训练：

第一阶段：表示学习（没有 LLM）。三个损失：
- ITC（图文对比）：在池化查询词元与文本 CLS 词元之间使用 CLIP 风格的对比损失。
- ITM（图文匹配）：二分类器，判断图像—文本对是否匹配；使用困难负样本挖掘。
- ITG（图像引导的文本生成）：以查询为条件的文本因果 LM 头，迫使查询编码可由文本生成的内容。

只有 Q-Former 训练，ViT 保持冻结，不涉及 LLM。

第二阶段：生成学习。接入一个冻结的 LLM（例如 OPT-2.7B 或 Flan-T5-XL）。通过一个小型线性层把 32 个查询输出投影到 LLM 的嵌入维度，并将它们置于文本提示词前面。只训练线性投影和 Q-Former，目标是在拼接的提示词 + 图像 + 标题序列上计算 LM 损失。

第二阶段之后，Q-Former + 投影就是完整的视觉适配器。推理路径为：图像 → ViT → Q-Former → 线性投影 → 置于文本前面 → 冻结 LLM 生成输出。

### 参数经济性

使用 ViT-g/14（11 亿，冻结）+ OPT-6.7B（67 亿，冻结）+ Q-Former（1.88 亿，训练）的 BLIP-2，总计 80 亿参数，其中 1.88 亿参数参与训练。仅 Q-Former 就约占完整堆栈参数的 2.4%。训练成本也反映了这一点：在少数 A100 上只需要几天，而端到端训练需要几周。

质量方面，BLIP-2 在零样本 VQA 上能够匹敌或超过 Flamingo-80B，同时小 50 倍。这个桥确实有效。

### InstructBLIP 与理解指令的 Q-Former

InstructBLIP（2023）为 Q-Former 增加了一个额外输入：指令文本本身。在交叉注意力阶段，查询现在同时可以访问图像块和指令。查询可以针对每条指令专门化（“数汽车”“描述情绪”），而不是学习一个固定摘要。在留出的任务上，基准成绩得到提升。

### MiniGPT-4 与仅投影器方案

MiniGPT-4 保留 Q-Former，但只训练输出线性投影，其他部分全部冻结。成本低，但质量也因此付出代价——这些查询来自 BLIP-2，而不是为你的任务学习的。它适合快速迭代，却不是最佳架构。

### LLaVA 为什么走向简单方案

LLaVA（2023，第 12.05 课）用一个普通的两层 MLP 取代 Q-Former，把每个 ViT 图像块词元投影到 LLM 空间——对于 24x24 网格，就是每张图像 576 个词元，全部送入 LLM。压缩更弱，却让 LLM 可以关注原始图像块。当时这很有争议；到 2023 年末它成为主流，因为视觉指令数据（LLaVA-Instruct-150k）证明 MLP 可以被训练到保留足够信号。取舍是：LLaVA 的上下文填得更快，但它可以自然地扩展到多图像和视频。

到 2026 年，领域分成两支：在词元预算重要的地方（长视频、多图像）仍然使用 Q-Former；在每个词元的原始质量优先的地方，MLP 投影器占主导。

### 门控交叉注意力：Flamingo，早期祖先

Flamingo（第 12.04 课）早于 BLIP-2，使用了同一个交叉注意力想法，但它把交叉注意力放在每一层冻结 LLM 中，而不是只作为单个桥。BLIP-2 证明，只在输入层压缩一次也能奏效。Gemini 和 Idefics 把两者结合起来：交错输入词元，再配合可选的门控交叉注意力，以支持上下文少样本。

### 2026 年的后代

- Q-Former：BLIP-2、InstructBLIP、MiniGPT-4，以及出于词元预算考虑的大多数视频—语言模型。
- Perceiver 重采样器：Flamingo 的变体（第 12.04 课）；Idefics 家族、Eagle、OmniMAE。
- MLP 投影器：LLaVA、LLaVA-NeXT、LLaVA-OneVision、Cambrian-1。
- 注意力池化：VILA、PaliGemma。

四种方案都成立。决定性问题是：你的约束来自词元预算，还是来自每个词元的质量？

## 使用它

`code/main.py` 构建一个标准库 Q-Former 风格的交叉注意力：

1. 模拟 256 个图像块词元（维度 128）。
2. 实例化 32 个可学习查询（维度 128）。
3. 运行缩放点积交叉注意力（Q 来自查询，K/V 来自图像块）。
4. 通过线性层投影到 LLM 维度（512）。
5. 输出 32 个可直接供 LLM 使用的视觉词元。

所有数学都用纯 Python 实现（对向量使用嵌套循环）。这是玩具实现，但形状正确。程序会打印注意力权重矩阵，让你看到每个查询从哪些图像块中提取了信息。

## 练习

1. 用 PyTorch 实现交叉注意力块。验证在 32 个查询和 256 个 key/value 的情况下，注意力权重矩阵为 32 x 256，并且 softmax 后每一行的和为 1。

2. 在 BLIP-2 第一阶段，Q-Former 同时运行三个损失：ITC、ITM、ITG。用伪代码写出每个损失的 forward 签名。哪一个需要文本编码器路径处于激活状态？

3. 比较参数量：Q-Former（12 层，768 隐藏维度）与两层 MLP 投影器（1408 → 4096，共两层）。LLM 规模达到多大时，1.88 亿参数的 Q-Former 成本能通过训练效率收回？

4. 阅读 BLIP-2 论文第 3.2 节（arXiv:2301.12597），了解 Q-Former 如何初始化。解释为什么从 BERT-base 初始化（而不是随机初始化）会加速收敛。

5. 一个 10 分钟的视频按 1 FPS 抽样得到 60 帧，计算采用（Q-Former → 每帧 32 个词元）与（MLP 投影器 → 每帧 576 个词元）时每帧的词元成本。哪一种能放入 128k 词元的 LLM 上下文窗口？

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| Q-Former | “查询 Transformer” | 带有 32 个可学习查询向量的小型 Transformer，通过交叉注意力关注冻结 ViT 特征 |
| 可学习查询 | “视觉软提示词” | 作为交叉注意力查询侧的一组固定参数；按模型学习，并在所有输入间共享 |
| 交叉注意力 | “Q 从这里，K/V 从那里” | query、key、value 来自不同来源的注意力；查询从 ViT 图像块中提取信息的机制 |
| ITC | “图文对比” | 应用于 Q-Former 池化查询与文本 CLS 的 CLIP 风格损失 |
| ITM | “图文匹配” | 在困难负样本挖掘的图文对上运行的二分类器；迫使查询区分细粒度不匹配 |
| ITG | “图像引导文本生成” | 以查询为条件生成文本的因果 LM 损失；迫使查询编码可由文本解码的内容 |
| 两阶段预训练 | “先表示、后生成” | 第一阶段单独训练 Q-Former（ITC/ITM/ITG）；第二阶段接入冻结 LLM，只训练投影 + Q-Former |
| 冻结骨干 | “不要微调” | 视觉编码器和 LLM 的权重固定，只有桥训练 |
| 投影头 | “线性映射到 LLM 维度” | 把 Q-Former 输出映射到 LLM 嵌入维度的最终线性层 |
| Perceiver 重采样器 | “Flamingo 版本” | 类似的可学习查询交叉注意力；Flamingo 在每层使用它，而不是把它作为单个桥 |
