# Chameleon 与仅使用早期融合词元的多模态模型

> 到目前为止，我们见过的每个 VLM 都把图像和文本分开处理。视觉词元来自视觉编码器，经过投影器，再在 LLM 内部与文本相遇。视觉词汇和文本词汇从不重叠。Chameleon（Meta，2024 年 5 月）提出：如果它们重叠呢？训练一个 VQ-VAE，把图像变成共享词汇中的离散词元序列。现在，每份多模态文档都是一个序列——文本词元和图像词元交错，使用一个自回归损失。副作用是：模型可以生成混合模态输出——在一次推理调用中交替生成文本词元和图像词元。本课阅读早期融合论点，并端到端构建一个玩具版本。

**类型：** 构建
**语言：** Python（标准库，VQ-VAE 分词器 + 交错解码器）
**前置课程：** Phase 12 · 05、Phase 8（生成式 AI）
**预计时间：** 约 180 分钟

## 学习目标

- 解释共享词汇 + 单一损失为什么会改变模型能够完成的事情。
- 描述 VQ-VAE 如何把图像分词成与 Transformer 下一词元目标兼容的离散序列。
- 说出 Chameleon 的训练稳定性技巧：QK-Norm、dropout 放置位置、LayerNorm 顺序。
- 比较 Chameleon 与 BLIP-2 的 Q-Former 方案，并说明各自适用的选择场景。

## 问题

基于适配器的 VLM（LLaVA、BLIP-2、Qwen-VL）把文本和图像视为两种不同的东西。文本词元经过 `embed(text_token)`；图像经过 `visual_encoder(image) → projector → ... pseudo_tokens`。模型有两条输入路径，在中途某处才合并。

这会带来三个后果：

1. LLM 只能消费图像，不能输出图像。输出只有文本。
2. 混合模态文档（段落和图像交替出现的文章）处理起来很别扭——你要么在模型外解析多模态输入，要么串联多次生成。
3. 分布不匹配。视觉词元和文本词元位于隐藏空间的不同区域，产生细微的对齐问题。

Chameleon 否定了这个前提：图像只是来自共享词汇的离散词元序列。在交错文档上训练模型，使用一个损失和一个自回归解码器，就能免费解锁混合模态生成。

## 概念

### VQ-VAE 作为图像分词器

这个分词器是一个向量量化变分自编码器。架构如下：

- 编码器：CNN + ViT，将图像映射为一个空间特征图，例如 32x32 个、每个 256 维的特征。
- 码本：由 K 个向量组成的学习词汇（Chameleon 使用 8192），每个向量也是 256 维。
- 量化：对于每个空间特征，按 L2 距离查找最近的码本条目。用整数索引替换连续特征。
- 解码器：CNN，将量化特征还原为像素。

训练使用 VAE 重建损失 + 承诺损失 + 码本损失。码本索引构成图像的离散字母表。

对于 Chameleon，一张图像变成 32*32 = 1024 个词元，它们来自大小为 8192 的词汇。再与文本词元（来自 LLM 的 BPE 词汇，假设为 32000）拼接。最终词汇量为 40192。Transformer 看到的是一个序列和一个损失。

### 共享词汇

Chameleon 的词汇结合了文本词元、图像词元和模态分隔符。每个词元都有一个 ID。输入嵌入层将每个 ID 映射到 D 维隐藏向量，输出投影将隐藏向量映射回词汇 logits。softmax 选择下一个词元，不论它属于哪个模态。

分隔符很重要：`<image>` 和 `</image>` 标签包住图像词元序列。生成时，如果模型输出 `<image>`，下游软件就知道接下来的 1024 个词元是要发送给解码器、用于渲染像素的 VQ 索引。

### 混合模态生成

推理就是在共享词汇上进行下一词元预测。例如提示词是“Draw a cat and describe it.”，Chameleon 输出：

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

模型自主选择顺序——可能先生成图像再生成文本，也可能先文本后图像，或者交错生成。同一个解码器、同一个损失。

与只能生成文本的适配器 VLM 相比，Chameleon 重新打开了模型输出模态的问题。

### 训练稳定性——QK-Norm、dropout、LayerNorm 顺序

早期融合训练在规模化时不稳定。Chameleon 论文记录了三个技巧：

- QK-Norm。在注意力内部的 query 和 key 投影上应用 LayerNorm，再计算点积。防止深度增加时 logits 范数爆炸。2024 年之后的多个大模型都使用它。
- Dropout 放置位置。在每次残差相加之后使用 dropout，而不只是放在注意力和 MLP 之后。当图像词元的梯度可能占主导时，需要更强的正则化。
- LayerNorm 顺序。在残差分支使用 Pre-LN（标准做法），并在最后一个块的跳连上再加一个 LN。稳定最后一层的梯度流。

没有这些技巧，340 亿参数的 Chameleon 训练会在多个检查点发散；有了它们，训练就能收敛。这套训练方案和架构本身一样重要。

### 分词器的重建上限

VQ-VAE 是有损的。对于 8192 个码本条目、512x512 图像的 1024 个词元，重建 PSNR 的上限约为 26–28 dB。这足以生成可辨认的图像，但明显差于连续空间扩散（Stable Diffusion 3 达到 32+ dB）。

分词器是瓶颈。更好的分词器（MAGVIT-v2、IBQ、SBER-MoVQGAN）可以抬高上限。Emu3（第 12.12 课）只靠更好的分词器就实现了 SDXL 级别的生成质量。

### Chameleon 对比 BLIP-2 / LLaVA

Chameleon（早期融合，共享词汇）：
- 一个损失，一个解码器。
- 生成混合模态输出。
- 分词器是质量上限。
- 成本高：推理路径中每生成一张图像都要运行一次 VQ-VAE 解码器。

BLIP-2 / LLaVA（后期融合，独立的塔）：
- 视觉输入，只有文本输出。
- 复用预训练 LLM。
- 理解不受分词器瓶颈限制。
- 成本低：单次前向传播。

根据任务选择。如果需要图像生成，选择 Chameleon 家族；如果只需要理解，适配器 VLM 更简单，而且能复用更多预训练计算。

### Fuyu 与 AnyGPT

Fuyu（Adept，2023）是相关方法：完全跳过独立视觉编码器，把原始图像块通过 LLM 的输入投影送入，仿佛它们就是词元，不使用分词器。它比 Chameleon 简单，但失去了共享词汇的输出生成能力。

AnyGPT（Zhan 等，2024）把 Chameleon 扩展到四种模态：文本、图像、语音、音乐。每种模态使用相同的 VQ-VAE 技巧，共享 Transformer，实现任意到任意的生成。第 12.16 课会更深入地介绍。

## 使用它

`code/main.py` 构建一个端到端的早期融合玩具模型：

- 一个微型 VQ-VAE 风格量化器，将 8x8 图像块映射为码本索引（K=16）。
- 一个共享词汇，由（文本 ID 0..31）+（图像 ID 32..47）+（分隔符 48、49）组成。
- 一个玩具自回归解码器（bigram 表），在合成标题 + 图像词元序列上训练。
- 给定提示词后输出交替文本 + 图像词元的采样循环。

代码刻意将 Transformer 保持得很小（使用 bigram），让你能够端到端追踪信号流。

## 练习

1. Chameleon 使用 K=8192 的码本和每张 512x512 图像 1024 个词元。估算与 24 位 RGB 图像相比的压缩比。这是有损的吗？损失有多大？

2. 对同样的 VQ-VAE 密度，一张 4K 图像（3840x2160）会产生多少图像词元？Chameleon 风格的模型能在一次推理调用中生成 4K 图像吗？首先会损坏什么——上下文、分词器质量还是 KV 缓存？

3. 用纯 Python 实现 QK-Norm。给定一个 64 维 query 和 key，展示 LayerNorm 前后的点积。为什么控制范数对深层模型很重要？

4. 阅读 Chameleon 第 2.3 节关于训练稳定性的内容。描述论文在没有 QK-Norm 的 34B 模型上观察到的确切失败模式。所谓“范数爆炸”的特征是什么？

5. 扩展玩具解码器，使它能根据纯文本提示词输出混合模态响应。给定训练数据分布为 60% 先文本 / 40% 先图像，测量模型选择先图像还是先文本的频率。

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| 早期融合 | “统一词元” | 从第一步起，图像被转换为与 Transformer 共享词汇的离散词元 |
| VQ-VAE | “图像分词器” | 将图像映射为 Transformer 可以预测的整数索引的 CNN + ViT + 码本 |
| 共享词汇 | “一本词典” | 覆盖文本 + 图像 + 模态分隔符的单一词元 ID 空间 |
| QK-Norm | “注意力稳定器” | 在 query 与 key 做点积前应用 LayerNorm，防止范数爆炸 |
| 混合模态生成 | “文本 + 图像输出” | 一次推理中自主生成交错文本和图像词元的过程 |
| 码本大小 | “K 个条目” | VQ-VAE 可以量化到的离散向量数量；在压缩率与保真度之间取舍 |
| 分词器上限 | “重建限制” | 解码 VQ 词元能够达到的最佳 PSNR；限定模型的图像质量 |
