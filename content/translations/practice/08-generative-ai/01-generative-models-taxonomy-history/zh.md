# 生成模型——分类与历史

> 每个图像、文本、视频和 3D 模型都属于五大类别之一。选错类别，你会和数学原理纠缠数周；选对类别，过去十二年的领域进展就能在脑中形成清晰脉络。

**类型：** 学习  
**学习实现：** Python  
**前置课程：** Phase 2（机器学习基础）、Phase 3（深度学习核心）、Phase 7 第 14 课（Transformer）  
**预计时间：** 约 45 分钟

## 问题

生成模型只做一件事：给定从某个未知分布 `p_data(x)` 抽取的训练样本，输出看起来也来自同一分布的新样本。人脸、句子、MIDI 文件、蛋白质结构，抽象来看都是同一个问题。

难点在于，`p_data` 所在的空间有数百万个维度（一张 512×512 的 RGB 图像约有 78.6 万维），样本只落在该空间内部的一个薄流形上，而你手里可能只有 1000 万个样本。用暴力方法求密度没有希望。每种生成模型都在做取舍：把一个难题换成另一个稍容易的难题。

过去十二年间有五类方法经受住了考验。理解每一类所作的取舍，你就能看出它为何在某些任务中胜出、又为何在另一些任务中崩溃。

## 概念 <!-- learning-atlas: the-concept -->

![按建模对象划分的五类生成模型](../assets/taxonomy.svg)

**1. 显式密度，可精确求解。** 把 `log p(x)` 写成可以实际计算的和。自回归模型（PixelCNN、WaveNet、GPT）将其分解为 `p(x) = ∏ p(x_i | x_<i)`。归一化流（RealNVP、Glow）通过简单基础分布的可逆变换构造 `p(x)`。优点：似然精确，训练损失清晰。缺点：自回归推理是串行的（长序列很慢），归一化流需要可逆架构（架构限制较多）。

**2. 显式密度，近似求解。** 为 `log p(x)` 构造下界（ELBO）并优化该下界。VAE（Kingma，2013）使用带变分后验的编码器—解码器。扩散模型（DDPM，Ho，2020）训练去噪器，隐式优化加权 ELBO。到 2026 年，扩散已成为图像、视频和 3D 生成的主流骨干。

**3. 隐式密度。** 完全跳过密度计算；学习一个生成样本的生成器 `G(z)`，再学习一个判断真假的判别器 `D(x)`。这种方法称为 GAN（Goodfellow，2014）。推理很快（一次前向传播），但训练以不稳定闻名。即使到了 2026 年，StyleGAN 1/2/3 在固定领域的照片级真实感任务（人脸、卧室）上仍属最先进方法。

**4. 基于得分 / 连续时间。** 直接学习对数密度的梯度 `∇_x log p(x)`，也就是得分（score）。Song 与 Ermon（2019）证明，得分匹配可以通过随机微分方程（SDE）推广扩散。流匹配（flow matching，Lipman，2023）是 2024—2026 年的热点：训练无需仿真，路径更直，采样速度比 DDPM 快 4～10 倍。Stable Diffusion 3、Flux 和 AudioCraft 2 都采用流匹配。

**5. 对离散编码进行基于词元的自回归建模。** 使用 VQ-VAE 或残差量化器把高维数据压缩成较短的离散词元序列，再用 Transformer 建模该序列。Parti、MuseNet、AudioLM、VALL-E 和 Sora 的图块分词器都采用这种方法。它相当于第 1 类方法加上一个学习得到的分词器。

## 简史

| 年份 | 模型 | 重要性 |
|------|------|--------|
| 2013 | VAE（Kingma） | 第一个拥有可用训练损失的深度生成模型。 |
| 2014 | GAN（Goodfellow） | 隐式密度，不用似然，却能生成惊人清晰的样本。 |
| 2015 | DRAW、PixelCNN | 顺序生成图像。 |
| 2017 | Glow、RealNVP | 可逆流；利用深层网络获得精确似然。 |
| 2017 | Progressive GAN | 首次生成百万像素级人脸。 |
| 2019 | StyleGAN / StyleGAN2 | 在照片级人脸这一特定领域仍然很难被超越。 |
| 2020 | DDPM（Ho） | 扩散模型变得实用。 |
| 2021 | CLIP、DALL-E 1、VQGAN | 文生图进入主流。 |
| 2022 | Imagen、Stable Diffusion 1、DALL-E 2 | 潜空间扩散 + 文本条件控制成为通用方案。 |
| 2022 | ControlNet、LoRA | 对预训练扩散模型进行精细控制。 |
| 2023 | SDXL、Midjourney v5、流匹配 | 扩大规模，改善训练动态。 |
| 2024 | Sora、Stable Diffusion 3、Flux.1 | 视频扩散兴起；流匹配胜出。 |
| 2025 | Veo 2、Kling 1.5、Runway Gen-3、Nano Banana | 达到生产级的视频生成。 |
| 2026 | 一致性模型 + 修正流 | 从扩散骨干实现单步采样。 |

## 五问分类法

看到一篇新的生成模型论文时，先回答下面五个问题，再读方法部分。

1. **模型在建模什么？** 像素、潜变量、离散词元、3D 高斯、网格还是波形？
2. **密度是显式还是隐式的？** 作者是否写出了 `log p(x)`？
3. **采样是一步完成还是反复迭代？** 迭代通常意味着推理较慢；一步完成通常依赖对抗训练或蒸馏。
4. **条件是什么：无条件、类别、文本、图像还是姿态？** 这一选择决定损失与架构骨架。
5. **如何评估：FID、CLIP score、IS、人类偏好还是任务准确率？** 每种指标都有已知的失效模式（见第 14 课）。

本阶段的每一课都会重新回答这五个问题。学完后，你应当能下意识地完成这套判断。

## 动手构建

本课代码提供了一个轻量可视化：从样本拟合一维高斯混合分布，分别采用三种玩具方法（核密度、离散直方图和类似 GAN 的“最近样本”生成器），让你在一个屏幕就能打印完的问题上看清显式密度与隐式密度的区别。

运行 `code/main.py`。程序从双峰高斯混合中抽取 2000 个样本，然后输出：

```
显式密度（直方图）：p(x in [-0.5, 0.5]) ≈ 0.38
近似密度（KDE）：   p(x in [-0.5, 0.5]) ≈ 0.41
隐式（最近样本生成）：打印 20 个新样本，没有 p(x)
```

请注意：前两种方法允许你询问“这个点出现的可能性有多大？”，第三种则做不到。这项*显式与隐式*之分会贯穿后续每一课。

## 使用方法

到 2026 年，不同任务应选择哪一类方法？

| 任务 | 最佳类别 | 原因 |
|------|----------|------|
| 窄领域的照片级人脸 | StyleGAN 2/3 | 仍然最清晰，推理最快。 |
| 通用文生图 | 潜空间扩散 + 流匹配 | SD3、Flux.1、DALL-E 3。 |
| 快速文生图 | 修正流 + 蒸馏 | SDXL-Turbo、SD3-Turbo、LCM。 |
| 文生视频 | 扩散 Transformer + 流匹配 | Sora、Veo 2、Kling。 |
| 语音与音乐 | 基于词元的 AR（AudioLM、VALL-E、MusicGen）或流匹配（AudioCraft 2） | 离散词元能以较低成本扩展规模。 |
| 3D 场景 | 高斯泼溅拟合、扩散先验 | 3D-GS 用于重建，扩散用于新视角。 |
| 密度估计（无需采样） | 归一化流 | 唯一能提供精确 `log p(x)` 的类别。 |
| 仿真 / 物理 | 流匹配、得分 SDE | 路径近似直线，向量场平滑。 |

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| 生成模型 | “它能创造新东西” | 学习 `p_data(x)` 的采样器，也可以选择暴露 `log p(x)`。 |
| 显式密度 | “可以求值” | 模型提供闭式或可计算的 `log p(x)`。 |
| 隐式密度 | “GAN 风格” | 只提供采样器，无法计算给定点的 `p(x)`。 |
| ELBO | “证据下界” | `log p(x)` 的一个可计算下界；VAE 和扩散模型会优化它。 |
| 得分 | “对数密度的梯度” | `∇_x log p(x)`；扩散和 SDE 模型学习这一向量场。 |
| 流形假设 | “数据位于一个曲面上” | 高维数据集中在低维流形上；这解释了降维为何有效。 |
| 自回归 | “预测下一个片段” | 把联合分布分解为条件分布的乘积。 |
| 潜变量 | “压缩编码” | 解码器可以据此重建输入的低维表示。 |

## 生产说明：五类模型，五种推理形态

每一类模型都对应不同的推理服务器成本曲线。生产推理文献把大语言模型推理分为预填充（prefill）与解码（decode）；同一套分解也适用于这里：

- **自回归（第 1 类和第 5 类）。** 串行解码决定主要延迟；KV 缓存、连续批处理和推测解码都能直接应用。
- **VAE / 扩散 / 流匹配（第 2 类和第 4 类）。** 这里没有大语言模型意义上的解码。成本 = `num_steps × step_cost`，而 `step_cost` 是在完整潜空间分辨率上执行一次 Transformer 或 U-Net 前向传播。生产调节项包括步数（DDIM / DPM-Solver / 蒸馏）、批大小和精度（bf16 / fp8 / int4）。
- **GAN（第 3 类）。** 一次前向传播。没有调度过程，也没有 KV 缓存。首词元时间（TTFT）约等于总延迟。因此，StyleGAN 在窄领域的用户体验中仍然占优。

当你在论文摘要里看到“比扩散更快”时，把它换算成“更少的步数 × 相同的单步成本”或“相同的步数 × 更低的单步成本”。其余说法多半只是营销话术。
