# 视觉自回归建模（VAR）：下一尺度预测

> 扩散模型沿时间迭代采样，也就是逐步去噪。VAR 沿尺度迭代采样：先预测 1x1 词元，再预测 2x2、4x4，直到最终分辨率；每个尺度都以上一尺度为条件。2024 年的论文表明，VAR 在图像生成中符合 GPT 式缩放定律，并在相同算力预算下胜过 DiT。本课将构建它的核心机制。

**类型：** 构建  
**学习实现：** Python（使用 PyTorch）  
**前置课程：** Phase 7 第 03 课（多头注意力）、Phase 8 第 06 课（DDPM）  
**预计时间：** 约 90 分钟

## 问题

自回归生成长期主导语言建模，因为它可以预测规模效应：算力越多、参数越多，困惑度越低，输出越好。2024 年以前，图像生成有两条主要 AR 路线：PixelRNN/PixelCNN（逐像素）和 DALL-E 1 / Parti / MuseGAN（在 VQ-VAE 编码上逐词元生成）。

两者都受生成顺序问题困扰。像素与词元排列在二维网格中，AR 模型却必须按一维光栅顺序访问它们。早期生成的角落像素不知道图像最终会变成什么。其生成质量随规模增长得不如文本 GPT，在匹配算力下也始终达不到扩散模型的质量。

VAR 通过改变生成对象来解决顺序问题。它不逐个预测空间中的图像词元，而是以不断提高的分辨率预测整张图像。第 1 步：预测一个 1x1 词元，也就是整张图像的“摘要”。第 2 步：预测 2x2 词元网格，表示较粗特征。第 3 步：预测 4x4 网格。第 K 步：预测最终的 (H/8)x(W/8) 网格。

每个尺度都会关注此前的所有尺度，在“尺度顺序”上保持因果；同一尺度内部则并行处理。顺序问题由此消失：第 k 个尺度的整张图像只需一次 Transformer 前向传播就能生成。

## 概念

### VQ-VAE 多尺度分词器

VAR 需要一个 **多尺度离散分词器**。对于图像 x，它会生成一系列分辨率逐渐增大的词元网格：

```
x -> 编码器 -> 潜变量 f
f -> 在 1x1 上分词：形状为 (1, 1) 的词元网格 z_1
f -> 在 2x2 上分词：形状为 (2, 2) 的词元网格 z_2
...
f -> 在 (H/p)x(W/p) 上分词：形状为 (H/p, W/p) 的词元网格 z_K
```

每个 z_k 使用同一个码本，典型大小为 4096～16384。各尺度的分词并不独立，训练目标是让各尺度残差之和重建 f：

```
f ≈ upsample(embed(z_1), target_size) + ... + upsample(embed(z_K), target_size)
```

这是一种**残差 VQ** 变体。尺度 k 捕获尺度 1..k-1 遗漏的内容。解码器接收所有尺度嵌入之和并生成图像。

多尺度 VQ 分词器只训练一次，与 VQGAN 相同，然后被冻结。全部生成工作都由上层自回归模型完成。

### 下一尺度预测

生成模型是一个 Transformer，它观察此前所有尺度的词元，并预测下一尺度的词元。

输入序列结构：
```
[START, z_1 词元, z_2 词元, z_3 词元, ..., z_K 词元]
```

位置嵌入同时编码尺度索引和尺度内空间位置。注意力在尺度顺序上具有因果性：尺度 k、位置 (i, j) 的词元可以关注尺度 1..k 的所有词元，也可以关注尺度 k 内按照某种尺度内顺序排在前面的词元（VAR 使用固定位置注意力，没有尺度内因果性，同一尺度的所有位置并行预测）。

训练损失：在每个尺度 k，根据此前所有尺度词元预测 z_k。对离散 VQ 编码计算交叉熵损失。结构与 GPT 相同，只是“序列”改成了按尺度组织。

### 生成

推理时：
```
生成 z_1 = 从 p(z_1) 采样                    # 1 个词元
生成 z_2 = 从 p(z_2 | z_1) 采样              # 并行生成 4 个词元
生成 z_3 = 从 p(z_3 | z_1, z_2) 采样         # 并行生成 16 个词元
...
解码：f = 对尺度 1..K 执行嵌入、上采样并求和
图像 = VAE_decoder(f)
```

当 K = 10 个尺度时，生成需要 10 次 Transformer 前向传播。每次传播并行生成完整尺度，不在尺度内逐词元自回归。对于 256x256 图像，这约等于 10 次传播；DiT 则需要 28～50 次。

### 下一尺度为何胜过下一词元

它具有三项结构优势：
1. **由粗到细符合自然图像统计。** 人类视觉感知和图像数据集都表现出依赖尺度的规律：低频结构稳定且易预测；高频细节以低频内容为条件。下一尺度预测利用了这项规律。
2. **尺度内并行生成。** VAR 与 GPT 式词元 AR 不同，它用一步生成某一尺度的全部词元。有效生成长度按对数而非线性增长。
3. **没有生成顺序偏差。** 尺度 k 的词元能看到尺度 k-1 的全部内容，不存在强迫早期词元在获得后期上下文之前作出承诺的“左侧”或“上方”偏差。

### 缩放定律

Tian 等证明，VAR 在 ImageNet 上的 FID 遵循幂律缩放曲线，与 GPT 的困惑度规律相似。把参数量或算力翻倍，会稳定地让误差减半。这是第一个像语言模型一样清楚表现出此类缩放行为的图像生成模型。因此，可以根据算力预测 VAR 规模下的结果，无需为每种架构依靠经验猜测。

### 与扩散的关系

VAR 与扩散采用相同的数据压缩思路：都把生成问题拆成一系列较简单的子问题。

- 扩散：逐渐加入噪声，学习撤销一个步骤。
- VAR：逐渐提高分辨率，学习预测下一尺度。

两者沿不同轴拆解问题，也都得到可求解的条件分布。经验结果表明，VAR 推理更快（传播次数更少，每个尺度内完全并行），并在类别条件 ImageNet 上达到或胜过 DiT。文本条件 VAR（VARclip、HART）仍是活跃研究方向。

## 动手构建

在 `code/main.py` 中，你将：
1. 在合成“图像”数据（二维高斯环）上构建微型 **多尺度 VQ 分词器**。
2. 训练一个执行下一尺度词元预测的 **VAR 式 Transformer**。
3. 调用 Transformer 4 次（4 个尺度）完成采样并解码。
4. 验证按尺度训练会让尺度内生成并行执行。

这是玩具实现，重点是亲眼看到按尺度组织的注意力掩码和尺度内并行生成真正运行。

## 练习

1. **尺度数量消融。** 分别使用 4、6、8、10 个尺度训练 VAR。测量重建质量与自回归传播次数之间的关系。尺度越多，残差越细，质量越好，但传播次数也越多。

2. **码本大小。** 使用大小为 512、4096、16384 的码本训练分词器。更大的码本带来更好的重建，但更难预测。找出拐点。

3. **尺度内并行检查。** 对训练好的 VAR 明确测量注意力模式。在尺度 k 内，模型是否会关注跨尺度位置，但不关注尺度内位置？验证掩码实现。

4. **VAR 与 DiT 缩放。** 对同一个 ImageNet 类别条件任务，以匹配的参数预算（例如 33M、130M、458M）训练 VAR 与 DiT。绘制 FID 与算力的关系。VAR 应在每个规模都领先 DiT；请在小规模上复现论文结果。

5. **文本条件控制。** 扩展 VAR，通过 adaLN 把文本嵌入（CLIP 池化输出）作为额外条件输入，形成 HART 方案。进行文本对齐采样时，FID 改善了多少？

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|----------|----------|
| VAR | “Visual AutoRegressive” | 在 VQ 词元网格金字塔上执行下一尺度预测的图像生成方法 |
| 下一尺度预测 | “先粗后细预测” | 模型按逐渐增大的分辨率尺度预测词元，并以此前全部尺度为条件 |
| 多尺度 VQ 分词器 | “残差 VQ” | 产生 K 个分辨率递增词元网格的 VQ-VAE，解码器对全部尺度求和 |
| 尺度 k | “金字塔第 k 层” | K 个分辨率层级之一，从 k=1 时的 1x1 到 k=K 时的 (H/p)x(W/p) |
| 尺度内并行 | “每尺度一次前向传播” | 尺度 k 的全部词元由一次 Transformer 传播预测，而非自回归逐个预测 |
| 跨尺度因果 | “按尺度排序的注意力” | 尺度 k 的词元可以关注尺度 1..k 的全部内容，但不能关注尺度 k+1..K |
| 残差 VQ | “相加式分词” | 每个尺度的词元编码低尺度留下的残差；解码器对所有尺度嵌入求和 |
| VAR 缩放定律 | “图像 GPT 缩放” | FID 随算力遵循可预测的幂律，与语言模型困惑度相似 |
| HART | “VAR + 文本混合体” | 文本条件 VAR 变体，把 MaskGIT 式迭代解码与 VAR 尺度结构结合起来 |
| 尺度位置嵌入 | “(尺度, 行, 列) 三元组” | 位置编码同时携带尺度索引和尺度内空间坐标 |
