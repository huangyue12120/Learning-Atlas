# 心智社会与多智能体辩论

> Minsky 在 1986 年提出的前提——智能是一个由专家组成的社会——每十年都会被重新发现。2023 年，Du 等人将它变成具体算法：多个 LLM 实例提出答案，阅读彼此答案、批评并更新。经过 N 轮后，它们收敛到的共识，在六项推理和事实性任务上胜过零样本 CoT 与反思。两个发现很重要：**多个智能体**与**多轮交流**都独立贡献效果。心智社会胜过单智能体独白；多轮交换胜过一次性投票。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 04（原语模型）
**用时：** 约 60 分钟

## 问题

自一致性——从同一个模型采样多次并取多数答案——是你能附加的最廉价推理改进。它有效，但很快饱和。将采样数翻倍，也可能看不到有意义的进一步提升。

辩论打破了这种饱和。N 个智能体不再是同一模型的 N 个独立样本，而是阅读彼此的推理并修订。样本间的相关性下降（它们不再是 i.i.d.），而收敛点常常正确，哪怕 i.i.d. 投票曾自信地得出错误结论。

## 概念

### Du 等人 2023 年算法

来自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体分别为问题给出初始答案。
2. 对第 r = 2..R 轮：向每个智能体展示其他智能体在第 r-1 轮的答案，并要求“综合这些信息，给出更新后的答案”。
3. R 轮后，对最终答案进行多数投票。

论文在 MMLU、GSM8K、传记、MATH 和事实性基准上测试。辩论持续胜过 CoT 与 Self-Reflection。

### 两个独立旋钮

同一论文的消融结果：

- **仅增加智能体数量**（1 轮，N 个答案多数投票）在多数任务上胜过单智能体，但会平台化。
- **仅增加轮数**（一个智能体看到自己的先前推理）几乎无帮助——这是反思已知的弱点。
- **两者结合**才产生显著提升。多个智能体之间的多轮交换带来增益。

### 为什么有效

有两种机制：

1. **暴露于分歧。** 当智能体看到另一个智能体的推理链得出不同结论时，它要么证明自己，要么更新自己。无论哪种，第 r+1 轮的上下文都比第 r 轮丰富。
2. **降低相关错误。** 在自一致性中，所有样本来自同一模型，错误相关——平均后得到一个自信但错误的答案。不同模型或不同随机种子能去相关；不同的*辩论观点*进一步去相关。

### 异构辩论

A-HMAD 及相关后续工作让不同智能体使用*不同的基础模型*。Llama + Claude + GPT 的辩论减少单一模型家族的坍缩（第 26 课），因为一个模型家族的相关错误不会由其他家族共享。

缺点是：参与辩论的弱模型可能把共识拉向错误答案（参见 “Should we be going MAD?”, arXiv:2311.17371）。

### NLSOM —— 129 智能体扩展

Zhuge 等人（“Mindstorms in Natural Language-Based Societies of Mind”，arXiv:2305.17066）将这一思路扩展到由 129 名成员组成的社会。结果是，专业化和自组织会随规模出现，系统在视觉问答等任务上优于单智能体。

### 失效模式

- **谄媚级联。** 所有智能体都服从听起来最自信的智能体，辩论坍缩为最大嗓门。提示对抗角色（“一个智能体必须论证反方”）有所帮助。
- **主题漂移。** 多轮辩论会偏离原始问题。缓解措施：每一轮都重新注入问题。
- **算力膨胀。** N 个智能体 × R 轮 = N·R 次 LLM 调用，每次上下文还会增长。一场 5 智能体、5 轮的辩论是 25 次上下文不断增长的调用。单题成本可超过一次 CoT 调用的 10 倍。

## 动手构建

`code/main.py` 就一道数学题运行 3 个智能体 × 3 轮的辩论，每个智能体以不同（可能错误）的答案开始。智能体是脚本化的——每个智能体以脚本化置信度加权邻居答案的平均值来“更新”。逐轮日志中可见收敛。

演示展示两项关键效应：

- 一轮交换会让智能体更接近正确答案。
- 超过第 2 轮的额外轮次显示边际收益递减（与 Du 等人的平台期相符）。

运行：

```
python3 code/main.py
```

## 实际使用

`outputs/skill-debate-configurator.md` 为新任务配置辩论：智能体数、轮数、异构性（同一模型还是混合模型）、角色分配（对称还是一名对抗者）。它还会在运行前估计 token 成本。

## 交付物

若要交付辩论：

- **轮数上限为 3。** Du 等人表明 3 轮已覆盖大部分收益。更多轮带来的是成本，不是质量。
- **智能体上限为 5。** 超过 5 后，上下文膨胀和成本占主导。
- **默认异构。** 池中至少有两种不同基础模型。
- **对抗槽位。** 一个智能体被提示无论如何都要不同意，以打破谄媚。
- **记录每一轮。** 隐藏中间轮次的辩论系统无法调试或审计。

## 练习

1. 运行 `code/main.py`，再将轮数设为 5，观察边际收益递减。哪一轮开始不再有额外收敛？
2. 增加第四名具有对抗角色的智能体：它始终反对当前多数。这会破坏还是改善收敛？
3. 绘制（打印）每轮的一致性得分（站在多数答案上的智能体比例）。它何时达到 1.0？这是否等同于“正确”？
4. 阅读 Du 等人第 4 节的消融。用这份代码复现“仅智能体”与“仅轮数”及“两者都有”的结果。
5. 阅读 “Should we be going MAD?”（arXiv:2311.17371），列出两种轮流发言之外的辩论变体，例如法官主导、辩论链、对抗式。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|---|---|---|
| 心智社会 | “Minsky 的想法” | 智能由互动的专家组成；1986 年框架如今通过 LLM 辩论变为可操作方法。 |
| 多智能体辩论 | “智能体争论” | N 个智能体提出、互相批评、经过 R 轮修订，再多数投票。 |
| 共识 | “它们一致” | 不是认识论真相——只是多数答案所占比例；仍可自信地错。 |
| 轮次 | “交换步骤” | 一轮 = 每个智能体阅读他人一次并更新一次。 |
| 异构辩论 | “混合模型家族” | 使用不同基础模型来降低错误相关性。 |
| 谄媚级联 | “所有人同意最大嗓门” | 智能体不论正确性，都服从最自信智能体的辩论失效。 |
| NLSOM | “129 智能体社会” | 自然语言心智社会；Zhuge 等人的规模化版本。 |
| 相关错误 | “同模型、同 bug” | 自一致性为何饱和；不同观点间的辩论可去相关。 |
