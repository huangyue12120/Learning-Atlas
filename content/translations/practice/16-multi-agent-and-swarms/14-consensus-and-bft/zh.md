# 面向智能体的共识与拜占庭容错

> 经典分布式系统 BFT 遇上随机 LLM。2025–2026 年出现三条研究路线：**CP-WBFT**（arXiv:2511.10400）按置信度探针为每张选票加权；**DecentLLMs**（arXiv:2507.14928）采用无领导者的并行工作者提案和几何中位数聚合；**WBFT**（arXiv:2505.05103）将加权投票与层次结构聚类结合，拆分 Core 和 Edge 节点。“Can AI Agents Agree?”（arXiv:2603.01213）的诚实实证结论是：即使标量一致在今天也很脆弱——单个欺骗性智能体就能破坏 Mixture-of-Agents。BFT 是必要但不充分的。本课构建最小 BFT 协议，注入三种智能体特有攻击（拜占庭谎言、谄媚从众、相关错误单一文化），并测量每种共识变体的应对方式。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 07（心智社会与辩论），第 16 阶段 · 13（共享记忆）
**用时：** 约 75 分钟

## 问题

有 N 个 LLM 智能体，每个都产出一个答案，它们彼此不同意。多数投票选错，因为两个智能体相关（相同基础模型、相同训练数据、相同失效模式）。第三个智能体碰巧以新方式出错——因此多数是虚假多数。

再加入一个欺骗性智能体：它故意撒谎；或者一个谄媚智能体：它同意最后发言者。在经典 BFT 中，假设拜占庭节点占比 `f < n/3` 并任意行动。2026 年的现实是，即使诚实的 LLM 节点也随机、跨模型相关，还会受彼此输出影响。你不能把它们当作独立 Bernoulli 投票者。

经典 BFT（PBFT，1999）处理任意比特翻转，却还无法处理“三个诚实智能体因共享训练数据而共享一个幻觉”。本课从 PBFT 基础出发，加入三项 2025–2026 年适配。

## 概念

### 经典 BFT 给了什么

实用拜占庭容错（Practical Byzantine Fault Tolerance，Castro 与 Liskov，OSDI 1999）容忍 `f < n/3` 个拜占庭节点。协议具有三个阶段（pre-prepare、prepare、commit）和两种原语（签名消息、法定人数证书），在 `n >= 3f + 1` 个诚实或恶意节点中就一个单值达成一致。

保证很强，但假设：

1. **独立故障。** 拜占庭节点不协调。
2. **诚实节点确实诚实。** 诚实输出的正确性不是问题；协议只对齐分歧。
3. **问题有真实答案。** 就错误事实达成共识仍是共识。

LLM 智能体违反全部三项。运行同一基础模型的两个智能体共享故障；“诚实”的 LLM 仍会幻觉；而在模糊问题上，“真相”是智能体决定的内容，并无外部神谕。

### 三种 LLM 特有攻击

**拜占庭谎言。** 一个智能体故意输出错误答案。若 `f < n/3`，经典 BFT 能处理。

**谄媚从众。** 一个智能体在投票前读取其他答案，并与最后发言者保持一致。它并非恶意，却与最大嗓门相关。经典 BFT 不会阻止它，因为智能体能通过所有签名检查。

**相关错误单一文化。** 三个智能体共享基础模型，并幻觉出同一个错误答案。多数错了。经典 BFT 无能为力，因为这三个智能体是“诚实地”同意。

### 2025–2026 年的回应

**CP-WBFT**（arXiv:2511.10400）——置信度探针加权 BFT。每个投票者为答案附加置信度探针（自报概率，或独立校准模型的预测）。选票权重随置信度缩放。在完整图上报告了 +85.71% 的 BFT 改进。缓解：谄媚从众（从众智能体对自愿立场往往置信度低）。

**DecentLLMs**（arXiv:2507.14928）——无领导者。工作者智能体并行提出方案，评估者智能体为方案评分，最终答案是评分位置的几何中位数。在 `f < n/2` 时稳健。缓解：拜占庭谎言与相关错误（几何中位数对异常值稳健，会被拉向稠密集群，而非模型偏差平均值）。

**WBFT**（arXiv:2505.05103）——带层次结构聚类的加权 BFT。投票权重由回答质量加上从历史学习的信任分数组成。将智能体聚成 Core 与 Edge；Core 智能体必须先达成共识，Edge 智能体随后跟随。缓解：可扩展性（Core 共识小而快），并在一定程度上缓解单一文化（Core 可按多样性选择）。

### 实证：“Can AI Agents Agree?”（arXiv:2603.01213）

论文在多个前沿模型上测量标量一致（LLM 智能体就一个数值达成一致）。发现令人不安：

- 即使没有对手，LLM 智能体在多项基准的标量问题上也以超过 30% 的比率发生分歧。
- 采用欺骗人格的一个智能体可将 Mixture-of-Agents 共识从诚实基线拉偏 40 多个百分点。
- 分歧率与模型多样性相关——异构集成分歧更多（好：错误不相关），但漂移也更慢（坏：达成一致所需时间更长）。

要点是：BFT 提供对齐输出的机制，却不告诉你已对齐的输出是否正确。应将其与验证（第 16 阶段 · 08 角色专业化）、多样性（第 16 阶段 · 15 辩论变体）和评估者智能体（第 16 阶段 · 24 基准）结合。

### 去掉细节的核心协议

面向 LLM 智能体的最小 BFT 轮：

```
1. task arrives; each agent i produces answer a_i
2. each agent attaches confidence probe c_i in [0, 1]
3. aggregator collects (a_i, c_i) from all n agents
4. aggregator groups by semantic cluster (equivalent answers)
5. aggregator computes weight for each cluster C:
     w(C) = sum_{i in C} c_i
6. winner = cluster with max weight, if max > threshold * sum(c_i)
   else: retry or escalate
7. minority clusters logged with provenance for post-hoc audit
```

语义聚类步骤是 LLM 特有的转折。答案“研究报告 4.2%”和“提高 4.2%”属于同一簇。朴素字符串相等检查会漏掉这一点。生产中使用廉价嵌入模型或显式规范化。

### 阈值调优

`threshold` 参数决定何时接受、何时重试。太低：接受弱多数；太高：永不接受。经验范围是对 `n=5-7` 个智能体取 0.5–0.67；较小的 `n` 取更高值。低于阈值时，升级给人类或不同智能体集成。

### 共识无能为力之处

- **模糊问题。** 若问题没有真实答案，共识只是观点，应这样称呼它。
- **复合问题。** “写代码并解释它”有两个答案；分别投票。
- **对抗性的多轮。** 若智能体可观察先前轮次并模仿（Du 2023 辩论），它们会不顾真相而互相同意。限制轮数（通常 2–3）。

## 动手构建

`code/main.py` 实现：

- `AgentVoter`——带有（答案、置信度）的脚本化策略。
- `MajorityVote`——经典相对多数。
- `CPWBFT`——带语义聚类的置信度加权投票。
- `DecentLLMs`——对评分提案进行几何中位数聚合。
- `Scenario`——在三种攻击模式下运行每种聚合器。

已实现的攻击模式：

1. `byzantine`：一个智能体高置信度撒谎。
2. `sycophancy`：一个智能体复制它看到的第一个答案，并有匹配置信度。
3. `monoculture`：三个智能体以中等置信度共享错误答案（相关错误）。

运行：

```
python3 code/main.py
```

预期输出：一张（攻击、聚合器）→ 最终答案的表，突出正确答案。相对多数在单一文化案例中失败；CPWBFT 的置信度加权缓解谄媚；当单一文化少于总体的一半时，DecentLLMs 的几何中位数被拉向诚实簇。

## 交付物

交付任意共识机制前：

- **至少用上述三种模式进行攻击测试。** 你的协议应可预测地失败，而非静默失败。
- **记录每个少数簇。** 少数簇及其来源是发现相关错误的早期预警系统。
- **强制有界轮数。** 不要“持续辩论直到一致”——这会奖励谄媚。
- **分离一致与正确性。** 共识输出交给验证者；验证者独立于集成。
- **监控一致率。** 骤升意味着从众偏差；骤降意味着模型漂移。

## 练习

1. 运行 `code/main.py`。确认相对多数在单一文化攻击上失败，但当单一文化置信度低于 0.7 时，CPWBFT 可部分缓解。
2. 添加第四种攻击：**沉默弃权**——一个智能体拒绝回答（“我不知道”）。每种聚合器应如何处理弃权？实现你的选择。
3. 将语义聚类从字符串规范化改为嵌入相似性（使用任意开源嵌入模型）。谄媚攻击会发生什么？
4. 阅读 CP-WBFT（arXiv:2511.10400）。实现置信度探针校准步骤（独立校准模型检查每个智能体的自报置信度）。测量单一文化场景的准确率增益。
5. 阅读 “Can AI Agents Agree?”（arXiv:2603.01213）。复现一个简化标量一致实验：三个智能体、一个标量问题、欺骗人格提示。CPWBFT 或 DecentLLMs 能捕捉它吗？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|---|---|---|
| BFT | “拜占庭容错” | Castro-Liskov 1999 年的协议，可在 `f < n/3` 个任意故障下达成共识。 |
| 拜占庭 | “任何坏行为” | 可撒谎、丢弃消息、静默失败的节点——除了安全崩溃以外的任何行为。 |
| 置信度探针 | “你有多确定？” | 附加在投票上的自报概率或校准器预测的概率。 |
| 语义聚类 | “答案相同，表述不同” | 在计票前将等价答案分组。 |
| 几何中位数 | “稳健中心” | 最小化到样本点距离和的点；不像均值一样受异常值影响。 |
| 单一文化 | “同模型，同失败” | 智能体共享训练数据或基础模型时出现的相关错误。 |
| 谄媚从众 | “同意最大嗓门” | 智能体的投票偏向第一个/最响亮的发言者。 |
| Core/Edge | “层级 BFT” | WBFT 的拆分：小型 Core 先达成共识，Edge 节点跟随；限制延迟。 |
