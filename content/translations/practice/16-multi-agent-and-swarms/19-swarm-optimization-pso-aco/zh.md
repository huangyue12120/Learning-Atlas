# 面向 LLM 的群体优化（PSO、ACO）

> 受生物启发的优化正在 LLM 领域回潮。**LMPSO**（arXiv:2504.09247）使用粒子群优化（PSO）：每个粒子的速度是提示词，LLM 生成下一个候选项；它很适合数学表达式和程序等结构化序列输出。**Model Swarms**（arXiv:2410.11163）把每个 LLM 专家视作模型权重流形上的 PSO 粒子，在仅 200 个实例下，报告了在 9 个数据集上相对 12 个基线的**平均 13.3% 提升**。**SwarmPrompt**（ICAART 2025）将 PSO 与灰狼优化混合，用于提示词优化。**AMRO-S**（arXiv:2603.12933）受蚁群优化（ACO）启发，为多智能体 LLM 路由构建信息素专家机制：实现 **4.7 倍加速**、可解释的路由证据，以及将推理与学习解耦的质量门控异步更新。本课将在提示参数空间上实现 PSO，并在智能体路由上实现 ACO，衡量这些经典算法为何适配 LLM 时代，以及何时不适配。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 09（并行群体网络），第 16 阶段 · 14（共识与 BFT）
**用时：** 约 75 分钟

## 问题

你有一条提示词，在任务评测上的得分为 62%。你想改进它。朴素做法是无梯度的手工微调，但它难以扩展；强化学习需要奖励信号和足够多的 rollout；对提示词做反向传播也不可行，因为提示词是离散字符串，不是可微参数。

经典的受生物启发优化正是为这个场景设计的：PSO 用于连续搜索空间，ACO 用于路径选择；它们不依赖梯度、基于种群，且每次评估成本低。将它们与 LLM 配对以完成无梯度搜索，便得到一个颇实用的优化器。

相同模式也适用于多智能体系统中的智能体*路由*。ACO 风格的信息素轨迹记录哪个智能体最擅长哪类任务，使路由器能够利用轨迹，并通过信息素衰减让路由能够被重新发现。

## 概念

### PSO 回顾（Kennedy 与 Eberhart，1995）

粒子群优化：在连续搜索空间中维护一组粒子。每个粒子具有位置 `x_i` 和速度 `v_i`。每次迭代：

```text
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中，`p_best` 是粒子自身的最好结果，`g_best` 是群体的最好结果，`w`、`c1`、`c2` 分别是惯性、认知和社会权重，`r1`、`r2` 是随机因子。

### 将 PSO 用于 LLM 输出——LMPSO

arXiv:2504.09247 将 PSO 适配到 LLM 生成的结构化输出（数学表达式、程序）。每个粒子是一个候选输出；速度是描述如何将当前输出朝个人最好/全局最好结果修改的*提示词*。LLM 根据该速度提示词生成新输出；速度中的“惯性”可以是“只做小幅增量修改”这类提示。

它在以下情况表现良好：

- 输出是结构化的（可解析、可评估）。
- 适应度可自动获得（测试运行、算术求值）。
- 种群较小（约 10–30 个粒子），使总 LLM 调用数可控。

当适应度需要人工审查时，它表现不佳——每次迭代的成本会高得难以接受。

### Model Swarms

arXiv:2410.11163 将 PSO 从输出层移到*模型*层。每个“粒子”是一个专家 LLM（参数），群体通过无梯度更新让参数朝集体最佳值移动。报告结果为：每次迭代仅用 200 个实例，在 9 个数据集上相对 12 个基线平均提升 13.3%。

关键洞见是：LLM 专家模型本来就位于共享参数流形的邻近位置（适配器权重、LoRA 增量）。在这个低维子空间上运行 PSO 既便宜又有效。

### ACO 回顾（Dorigo，1992）

蚁群优化：蚂蚁在图上行进，每条路径有信息素轨迹。蚂蚁移动的概率按信息素强度加权；完成任务的蚂蚁按解的质量沉积信息素；信息素会随时间衰减。

### AMRO-S——面向智能体路由的 ACO

arXiv:2603.12933 将 ACO 用于多智能体路由。每个任务类型是一个“目的地”，每个智能体是一条可选路线；信息素会强化产生好输出的路线。主要贡献包括：

- **可解释的路由证据。** 信息素强度是人类可读的信号。
- **质量门控的异步更新。** 只有通过质量检查后才更新信息素，从而将推理解耦于学习。
- 在多智能体路由基准上达到 **4.7 倍加速**。

质量门控很重要：没有它，快速但错误的智能体会积累信息素，系统会锁定在错误路由上。

### 何时将 PSO / ACO 用于 LLM

**以下情况使用 PSO：**

- 搜索空间连续，或可映射到连续参数（提示嵌入、LoRA 权重、数值生成参数）。
- 适应度获取便宜且可自动化。
- 种群可以较小（10–30）。

**以下情况使用 ACO：**

- 你面对路由或路径选择问题。
- 决策会随时间强化（同一任务类型会反复出现）。
- 你需要对路由决策提供可解释证据。

**以下情况两者都不要使用：**

- 适应度需要人工审查（每次迭代成本过高）。
- 搜索空间以 PSO 无法覆盖的方式离散且组合化（改用遗传算法）。
- 实时决策需要严格延迟（PSO/ACO 相比单次启发式方法收敛较慢）。

### 为什么受生物启发的方法仍然取胜

基于梯度的方法需要可微信号。LLM 输出和路由决策并不天然可微。伪梯度方法（强化学习得到的路由器、DPO 风格提示词调优器）可以工作，但需要昂贵训练。

PSO 和 ACO 只需要一个*评估器*函数。只要你能为候选输出或路由决策打分，就能在该空间上优化；这大幅降低了适用门槛。

### 实际限制

- **种群预算。** N 个粒子 × T 次迭代 × 每次评估成本。若 LLM 评估约为每次调用 $0.02，20 粒子 PSO 运行 50 次迭代约需 $20；请据此规划。
- **探索与利用。** 信息素衰减率和 PSO 惯性之间存在权衡：衰减太快会遗忘解，太慢会卡在早期局部最优。
- **灾难性漂移。** 若适应度景观变化（新数据分布），两种算法都可能先收敛再发散；应监控最佳适应度的稳定性。

## 构建

`code/main.py` 实现：

- `LMPSO`——在数值提示参数（温度、`top_k` 权重）上的 PSO。每个粒子的“LLM 生成”由脚本化适应度函数模拟；算法运行 30 次迭代并展示 `g_best` 收敛。
- `AMRO_S`——ACO 风格的路由。3 个智能体、4 种任务类型、信息素矩阵、100 个已路由任务；打印随时间变化的（任务类型 → 智能体选择）分布，以展示轨迹形成。
- 对比：在相同任务流上比较随机路由与 ACO 路由，衡量质量和延迟。

运行：

```text
python3 code/main.py
```

预期输出：

- LMPSO：`g_best` 适应度会在 30 次迭代中从随机值提升到接近最优。
- AMRO-S：信息素表会稳定在每种任务类型对应的正确智能体上；ACO 路由相对随机路由将质量提升约 30–40%，且通过更少重试降低延迟。

## 使用

`outputs/skill-swarm-optimizer.md` 可帮助你在 LLM / 智能体优化问题中选择 PSO、ACO、遗传算法和基于梯度的优化器。

## 交付

- **从小规模开始。** 10–20 个粒子、20–50 次迭代；只有当收敛曲线显示明确收益时才扩展。
- **每次迭代记录信息素或 `g_best`。** 没有轨迹，群体优化器的调试会很痛苦。
- **质量门控更新。** 尤其是 ACO 路由：快速但错误的智能体绝不能积累信息素。
- **在分布变化时重置信息素衰减。** 评测分布改变时，陈旧信息素已经失效；重置它，或暂时将衰减率加倍。
- **限制每次迭代成本。** 输出“单次迭代成本”指标。每次迭代花 $500 却只提升 0.5% 的 PSO 无法交付。

## 练习

1. 运行 `code/main.py`，观察 LMPSO 收敛。将种群大小改为 5、10、20、50；在哪个大小时，收敛所需时间开始饱和？
2. 实现“灾难性漂移”实验：第 30 次迭代后改变适应度函数。PSO 适应得多快？重置 `p_best` 是否有帮助？
3. 为 AMRO-S 加入质量门：仅在评测分数 > 0.7 的运行中沉积信息素。与无门控版本相比，收敛如何变化？
4. 阅读 LMPSO（arXiv:2504.09247），将论文中的“速度即提示词”映射回你的数值速度。模拟损失了什么，又保留了什么？
5. 阅读 AMRO-S（arXiv:2603.12933），实现带异步信息素更新的解耦“推理快速路径”。在持续负载下，系统延迟如何变化？

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------|----------|
| PSO | “粒子群优化” | Kennedy–Eberhart 于 1995 年提出的、基于种群的无梯度优化器。 |
| ACO | “蚁群优化” | Dorigo 于 1992 年提出的、通过信息素轨迹进行路径/路由优化的方法。 |
| LMPSO | “带 LLM 生成的 PSO” | arXiv:2504.09247；速度是提示词，LLM 生成候选项。 |
| Model Swarms | “在专家权重上运行 PSO” | arXiv:2410.11163；在模型参数子空间上做无梯度更新。 |
| AMRO-S | “面向智能体路由的 ACO” | arXiv:2603.12933；任务类型 × 智能体上的信息素矩阵。 |
| `p_best` / `g_best` | “个人 / 全局最好” | 目前发现的逐粒子最佳解与全群体最佳解。 |
| 信息素 | “路由记忆” | 一条边上的强度，随时间衰减，并按质量沉积。 |
| 质量门控更新 | “只从好运行中学习” | 以质量检查为条件的信息素沉积。 |
| 灾难性漂移 | “分布变化” | 适应度景观改变，旧 `p_best` 与信息素变得陈旧。 |
