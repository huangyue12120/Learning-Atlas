# 投票、自一致性与辩论拓扑

> 最廉价的聚合方式是：采样 N 个独立智能体，再多数投票。Wang 等人 2022 年的自一致性以一个模型采样 N 次实现了这一点。多智能体以**异构**智能体扩展它来逃离单一文化——不同模型、不同提示词、不同温度、不同上下文。多数投票之外，辩论拓扑也很重要：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估星形 / 链形 / 树形 / 图形协调，发现**图形最适合研究**，但超过约 4 个智能体后有“协调税”。AgentVerse（ICLR 2024）记录了两种涌现模式——自愿行为与从众行为；从众既是特性（寻找共识），也是风险（群体思维，第 24 课）。本课绘制拓扑空间、构建每种变体，并测量协调税。

**类型：** 学习 + 构建
**语言：** Python（标准库）
**前置要求：** 第 16 阶段 · 07（心智社会与辩论），第 16 阶段 · 14（共识与 BFT）
**用时：** 约 75 分钟

## 问题

辩论可提升准确率（Du 等人，arXiv:2305.14325），也可降低准确率。辩论是否有帮助取决于四项结构选择：

1. 谁与谁交流（拓扑）。
2. 进行多少轮（Du 2023：轮数和智能体数各自独立重要）。
3. 智能体是否异构（不同基础模型打破单一文化）。
4. 是否存在对抗性声音（钢人论证还是稻草人论证）。

将“运行 5 个智能体再投票”硬接到任务上的团队，常常比单智能体退步。失败不是随机的，而是由拓扑与异构性决定。本课提供拓扑地图。

## 概念

### 自一致性：单模型基线

Wang 等人 2022 年（“Self-Consistency Improves Chain of Thought Reasoning”）在 temperature > 0 下对同一模型采样 N 次，并就推理路径答案多数投票。在 GSM8K 上，相较单次贪心解码，N=40 采样带来显著提升。自一致性是多智能体投票的单智能体前身。

限制是：自一致性只使用一个基础模型，错误天生相关。若模型有系统性偏差，N 个样本全都共享。

### 多智能体投票：异构扩展

将 N 个样本替换为 N 个*不同*智能体：不同基础模型（Claude、GPT、Llama）、不同提示词、不同工具访问。好处是不相关错误；代价是不同智能体成本不同，协调还会增加开销。

异构辩论在 2026 年常被称为**A-HMAD**——对抗性异构多智能体辩论。该名称并未普遍采用，但论文用它表示“不同模型辩论，从而减少单一文化坍缩的相关错误”。

### 四种拓扑

```
星形                链形               树形                图形

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           （全连接）
```

星形：一个中心，其他人只与中心交流；等价于没有侧信道的主管—工作者。
链形：线性结构，每个智能体看到前一个的输出，类似流水线。
树形：层级结构，用于层级智能体系统（第 06 课）。
图形：任意对任意，包括全连接团和任意 DAG。

### 协调税（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）在包含研究、编码和规划的任务套件上对星、链、树、图进行基准测试。关键测量结果：

- **图形**拓扑在研究任务上获胜。信息可以任意流动，智能体能互相批评。
- **星形**拓扑在快速问答的事实任务上获胜。中心过滤并整合。
- **链形**拓扑在逐步流水线上获胜（分阶段细化）。
- 图形拓扑在约 4 个智能体之后出现**协调税**。墙钟时间和 token 成本增长快于质量。

4 智能体上限是经验性的，不是基本定律。它反映 2026 年 LLM 上下文容量：每个智能体的上下文被同伴输出填满，一旦人人能看见所有人，加入第 N+1 个智能体的边际价值就下降。

### 多智能体辩论策略（“Should we be going MAD?”）

arXiv:2311.17371 是 2023 年 MAD 策略综述。其他人重复的关键发现是：在相同预算下，结构上*类似*自一致性（独立采样 + 聚合）的 MAD 变体常不如自一致性。智能体真正异构且辩论有对抗结构（一名智能体论证反方）时，MAD 最有帮助。

### AgentVerse 涌现模式

AgentVerse（ICLR 2024，https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf）记录了即使没有显式设计也会从多智能体辩论涌现的两种行为：

- **自愿。** 智能体未经提示就主动提供帮助（“我可以接下一步”）。好处是它将工作分配给最擅长子任务的智能体。
- **从众。** 即使批评者错误，智能体也会调整立场以匹配批评者。这属于辩论版本的谄媚（第 14 课）。

从众是“辩论直到一致”为何奖励霸凌者的原因。用有界轮次和单独法官缓解。

### 异构性：真正推动准确率的旋钮

实践文献中 2024–2026 年的模式是：将 N 个智能体中的一个换成不同基础模型，比将 N 增加 1 带来更大的准确率提升。直觉是单一文化——每一个新的独立错误源，比额外一个相关样本更有价值。

在极限情形，异构性胜过数量。对于大多数有清晰真实答案的任务，三个不同模型优于同一模型的五个副本。

### 陪审团方法

Sibyl 框架（见 Minsky-LLM 文献）将“陪审团”形式化——一小组专业智能体在每阶段通过投票细化答案。与普通多数投票不同，陪审团有角色：一个智能体交叉质询，一个提供上下文，一个评估似然。陪审团介于普通投票（便宜、易单一文化）与完整 MAD（昂贵、易从众）之间。

### 投票加辩论何时占优

- 问题有真实答案（事实、数学、代码行为），投票收敛有意义。
- 智能体可访问不同来源或工具（可获得异构性）。
- 轮次有界（通常 2–3）并有独立法官或验证者。
- 预算允许 3–5 个智能体。图形拓扑超过 5–7 个后，协调税占主导。

### 投票加辩论何时伤害

- 问题呈观点形，智能体会收敛到看起来最自信而非最正确的答案。
- 所有智能体共享基础模型，单一文化使共识没有意义。
- 轮次无界，从众每次都会获胜。
- 任务简单。对单智能体作 N=5 自一致性更便宜、同样准确。

## 动手构建

`code/main.py` 实现：

- `run_star(agents, hub, question)`——中心轮询每名工作者并聚合。
- `run_chain(agents, question)`——顺序细化。
- `run_tree(root, children, question)`——带深度 2 聚合的层级。
- `run_graph(agents, question, rounds)`——全连接辩论，轮次有界。
- 一个脚本化异构性旋钮：每个智能体具有表示系统性错误的 `error_bias`。
- 一个测量工具：对每种拓扑在 N=3、5、7 下运行，并报告（准确率、total_tokens、wallclock_simulated）。

运行：

```
python3 code/main.py
```

预期输出：一张 拓扑 × N →（准确率、token、延迟）的表。图形在 N=3–5 的研究型任务上获胜；星形在快速事实任务上获胜；N=7 的图形显示协调税（延迟膨胀快于准确率）。

`outputs/skill-topology-picker.md` 是一项读取任务描述并推荐拓扑（星 / 链 / 树 / 图）、N（智能体数量）、异构性画像（要使用的基础模型）和轮次上限的技能。

## 交付物

对任意集成：

- 以一款强基础模型、N=5 的**自一致性**开始，它是廉价基线。
- 若准确率重要，升级为 N=3 的**异构投票**，并测量差异。
- 仅当任务有结构（研究、多步骤）且能实现有界轮次时，再升级为**辩论拓扑**。
- 始终记录少数簇。当少数持续正确时，你获得多样性信号。
- 将墙钟时间和 token 与准确率一同基准测试。“10 倍成本换更高准确率”是商业决策。

## 练习

1. 运行 `code/main.py`。绘制图形拓扑的协调税曲线：准确率随 N、token 随 N。在什么 N 处曲线出现拐点？
2. 实现 A-HMAD：三个具有刻意不同偏差的智能体。相较第 14 课单一文化攻击上的全同偏差基线，A-HMAD 如何？
3. 向图形拓扑加入“法官”角色，它不投票，只评估最终共识。这是否改变涌现的从众行为？
4. 阅读 AgentVerse（ICLR 2024）。找出你的实现最强烈展现哪种涌现行为。能否通过提示词变化诱发相反行为？
5. 阅读 MultiAgentBench（arXiv:2503.01935）第 4 节（拓扑实验）。使用你的工具在论文一个任务上复现“图形胜研究”结果。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|---|---|---|
| 自一致性 | “采样 N 次，投票” | Wang 2022；单模型、N 个 temperature>0 样本，就推理路径多数投票。 |
| 异构性 | “不同模型” | 不同基础模型或提示词族构成的集成，打破单一文化。 |
| MAD | “多智能体辩论” | 智能体在多轮中交换批评的通用名称，见 Du 2023。 |
| A-HMAD | “对抗性异构 MAD” | 强调不同模型 + 对抗结构的 MAD 变体。 |
| 拓扑 | “谁与谁交流” | 星、链、树、图；决定信息流。 |
| 协调税 | “边际收益递减” | 图形上超过约 4 个智能体后，成本增长快于质量。 |
| 自愿行为 | “未经提示的帮助” | AgentVerse 涌现模式：智能体主动提出接手一步。 |
| 从众行为 | “压力下的一致” | AgentVerse 涌现模式：智能体向批评者对齐。 |
| 陪审团 | “小型专业小组” | Sibyl 式角色集成（质询者、上下文、评分者）。 |
