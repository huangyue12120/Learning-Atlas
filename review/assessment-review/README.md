## 性能

命令：`cd apps/local-learning && npm run benchmark`。预热一次后连续运行三组，每组 20 次；每组中位数均需低于 100 ms 才报告 `targetMet: true`。

| 测量 | I/O 线程 | 各组中位 ms | 100 ms 目标 |
| --- | ---: | --- | --- |
| 修改前工作区基线，20 次 | 16 | 272.320 | 未达 |
| 并发比较，20 次 | 64 / 128 | 141.656 / 136.429 | 均未达 |
| 最终工作区，三组各 20 次 | 64 | 148.909 / 142.271 / 138.220 | 未达 |
| 相同输入的临时本地副本，三组各 20 次 | 64 | 47.158 / 17.584 / 17.274 | 仅本地对照达标 |

采用 64 个 I/O 线程；翻倍到 128 的收益有限。每次仍检查全部 1019 个依赖路径，不使用 TTL 或 watcher 跳过来源门禁。剖析中 stat 检查跨度约 158 ms、回调处理约 7 ms，与本地副本对照一致表明存储检查是主要限制。工作区目标仍保留为未完成，不能拿本地副本代替验收。

本地对照可用 `node --env-file=runtime.env --experimental-strip-types scripts/benchmark-local-storage.ts` 重复：仅复制应用模块、542 份上游课程正文和中文目录输入，不复制个人数据库、模型配置或工作区，完成后删除临时副本。原始数值见 [performance.json](performance.json)。
