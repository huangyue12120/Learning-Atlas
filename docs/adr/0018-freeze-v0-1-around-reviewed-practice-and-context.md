# Freeze v0.1 around reviewed practice and contextual theory

v0.1 is a releasable local learning experience when all reviewed Phase 0 and Phase 1 practice lessons, assessments, Python workspaces, approved contextual theory cards, learning-data recovery, and first-use documentation are complete. Full Chinese translation of the theory compendium is valuable but is a separate content stream rather than a v0.1 release gate.

This preserves the practice-first learning sequence and prevents an incomplete parallel theory curriculum from delaying verified course delivery. Theory cards remain human-approved and retain links to their pinned upstream notes. A Chinese theory note may be added when a specific approved card needs more depth; the CLT sampling note for Phase 1 lesson 15 is the first such scoped addition.
