# Use Python as the learner-facing implementation language

Learning Atlas will present, maintain, and validate Python as the sole implementation language for practical lessons. Upstream repositories may contain other languages, but the product will not translate, exercise, or support those variants in its learner-facing path; learners can still access the attributed original source.

This narrows the curriculum's execution environment, test strategy, and workspace tooling to one language. It is preferred to parallel multi-language paths because the product serves a learner who will study and work primarily in Python, and maintaining equivalent examples across languages would dilute editorial and engineering effort.
