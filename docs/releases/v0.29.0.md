# Learning Atlas v0.29.0 发布说明

发布日期：2026-11-06。

本版继续处理审查建议项，保持 Phase 0–18 的 457 节实践课、20 章理论目录与既有人工理论关联范围不变。

- **按需 Python 环境**：基础依赖缩减为 marimo、NumPy、Matplotlib，训练、语音、视觉、数据、笔记本和模型客户端移入可选组；锁文件和根项目元数据同步。
- **目录性能**：逐请求并发检查依赖文件，去掉目录不需要的工具资源检查；正式启动提供 16 个文件 I/O 线程。20 次热请求此前中位 96.884 ms，最终复测为 255.975 ms；稳定低于 100 ms 的目标仍未达成。SHA-256 门禁与即时失效保留。
- **学习助理**：支持流式输出、停止生成、UTF-8/SSE 分片、失败/取消不保存半轮对话；证据按当前和相邻小节裁剪，历史保留有预算的完整轮次。原 JSON 接口兼容。
- **测验与回看试点**：首课 5 道题核对选项措辞和精确段落证据，反馈可直接回到对应段落。全量生成 1832 道题的候选证据和长度偏差优先清单；候选不自动发布。其余 1827 题的正式映射与题库批量改写仍待内容审核。
- **文档**：历史发布说明按版本、术语按领域归档并保留旧锚点入口；提示词工程课补充 15 个中文对照，不替换英文示例。
- **线上核验**：已验证覆盖率 push、Dependabot 的 SHA/版本注释更新和新版同步临时令牌推送；验收创建上游同步 PR #35，未合并。

验收详情、线上证据与剩余内容审核边界见[建议项跟踪](../review-followups.md)及[候选复核说明](../../review/followups/README.md)。本次没有修改学习者数据库或本地上游快照。
